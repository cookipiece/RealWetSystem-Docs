# 인게임 메뉴

**젖음** 메뉴(일본어 **濡れ**, 영어 **Wet**)는 기본으로 아바타의 메인 원형 메뉴에 따로 들어갑니다. 이 페이지는 메뉴의 구성과 각 버튼이 하는 일, 메뉴를 바꾸는 방법을 설명합니다.

{/* SHOT M01: main Wet page */}
[![인게임 젖음 메뉴](/img/guide/M01-ko.png)](/img/guide/M01-ko.png)

*<small>RealWetSystem만 설치한 추천 구성의 메뉴입니다. RealSweatSystem과 연동하면 메인 페이지에 **RealSweat 연동**과 <strong>젖음 양 (연동 해제 시)</strong>가 들어갑니다.</small>*

## 메뉴의 구성 {/* #layout */}

추천 구성(새 설치)의 메뉴는 다음과 같습니다. 고르지 않은 버튼은 들어가지 않습니다.

| 위치 | 들어가는 것 |
| --- | --- |
| **젖음** (메인 페이지) | **의상 젖음 보이기**, **젖음 양**(RealSweat과 함께 쓰면 **RealSweat 연동**과 <strong>젖음 양 (연동 해제 시)</strong>), **젖음 조절**, **빠른 건조**, <strong>현재 상태 고정 (촬영용)</strong>, **나에게만 표시**(단독 모드), **비침 보호**, **전체 영역 젖음** |
| **젖음 > 젖음 조절** | <strong>젖는 범위만 넓히기 (고급)</strong>, <strong>젖음 표현 (50%=기본)</strong>, <strong>젖은 광택 (50%=기본)</strong>, <strong>젖음 경계: 또렷하게 ↔ 부드럽게</strong>, <strong>비침 강도 (50%=기본)</strong>, **젖음 비침 모드**, **SSAO/그림자 완화**, <strong>최대 젖는 범위 (%)</strong> |
| **젖음 > 비침 보호** | **중요 부위 비침 보호**, <strong>비침 보호 범위 (50%=기본)</strong>, <strong>비침 보호 강도 (100%=완전히 막음)</strong> |
| **젖음 > 의상별 표시** | 의상 그룹마다 젖은 모습을 숨기는 토글(그룹을 만든 경우만) |

- 한 페이지는 8칸입니다. **젖음 조절**에 항목이 9개 이상이면 7개 뒤에 **다음**이 생기고 나머지가 이어집니다.
- 메인 페이지가 다 차면 **전체 영역 젖음**은 **젖음 조절**의 첫 칸에 들어갑니다.
- 비침 보호 다이얼을 넣지 않으면 **비침 보호** 페이지 대신 **중요 부위 비침 보호** 토글이 메인 페이지에 바로 들어갑니다.

## 버튼마다 하는 일 {/* #items */}

### 젖음 양과 연동

| 설치 상태 | 쓰는 버튼 |
| --- | --- |
| <ProductName />만 있음 | **젖음 양**으로 옷이 얼마나 젖을지 정합니다. |
| RealSweatSystem도 있고 **RealSweat 연동** 켜짐 | 옷이 피부의 최종 땀 수치를 따라 젖습니다. |
| RealSweatSystem도 있고 **RealSweat 연동** 꺼짐 | <strong>젖음 양 (연동 해제 시)</strong>로 옷만 따로 조절합니다. |

- 연동 중에는 젖음 양 다이얼이 RSS의 땀 수치를 따라갑니다. 직접 움직여도 RSS 수치로 돌아옵니다. 연동을 끄면 마지막으로 따라간 값부터 조절할 수 있습니다.
- <ProductName />의 다이얼은 RSS의 땀 수치를 바꾸지 않습니다.
- 양을 바꿔도 옷은 설정된 속도로 젖거나 마릅니다. 바로 바뀌지 않는 것이 정상입니다.

:::tip[RSS 자동 모드가 0%일 때 옷만 젖게 하려면]
**RealSweat 연동**을 끄고 <strong>젖음 양 (연동 해제 시)</strong>를 올려 주십시오. 연동을 바꿔도 이미 젖은 상태가 바로 초기화되지는 않습니다.
:::

### 메인 페이지의 토글

| 버튼 | 하는 일 | 처음 값 | 저장 |
| --- | --- | --- | --- |
| **의상 젖음 보이기** | 모든 의상의 젖은 모습을 보이거나 숨깁니다. 숨겨도 젖고 마르는 것은 계속되므로, 다시 켜면 남은 젖음이 보입니다. | 켜짐 | 저장 |
| **빠른 건조** | 켜 둔 동안 새 땀을 받지 않고 옷을 약 4초 만에 거의 말립니다. 다시 젖게 하려면 꺼 주십시오. | 꺼짐 | 저장 안 함 |
| <strong>현재 상태 고정 (촬영용)</strong> | 지금 젖은 모습을 그대로 멈춥니다. | 꺼짐 | 저장 안 함 |
| **나에게만 표시** | <ProductName />만 쓸 때 나옵니다. 켜면 옷의 젖은 모습이 나에게만 보입니다. | 꺼짐 | 저장 |
| **전체 영역 젖음** | 켜면 옷 전체가 고르게 젖습니다. 아래 [전체 영역 젖음](#whole-area)을 확인해 주십시오. | 꺼짐 | 저장 |

RealSweatSystem의 **땀 표시**와 **나에게만 보이기**는 피부 땀에만 적용됩니다. 의상 젖음은 숨기지 않으며, 다른 사람에게도 보입니다. 의상 젖음을 숨기려면 **의상 젖음 보이기**나 의상별 표시를 꺼 주십시오.

### 젖음 조절의 다이얼 {/* #tuning */}

| 다이얼 | 바뀌는 것 | 기준 |
| --- | --- | --- |
| <strong>최대 젖는 범위 (%)</strong> | 젖음이 퍼지는 최대 범위 | 처음 값은 Unity의 설정(새 설치 40%). 옷 전체 면적의 비율이 아닙니다. |
| <strong>젖는 범위만 넓히기 (고급)</strong> | 같은 젖음 양에서 옅은 젖음이 퍼지는 거리 | 0%는 설정 그대로, 100%는 최대로 넓힙니다. 이미 다 젖은 곳은 더 넓히지 않습니다. |
| <strong>젖음 표현 (50%=기본)</strong> | 젖은 색·채도·비침의 세기 | 50%가 설정 그대로입니다. 광택은 따로 조절합니다. |
| <strong>젖은 광택 (50%=기본)</strong> | <ProductName />이 더하는 젖은 반사 | 0%는 추가 광택 없음, 100%는 두 배입니다. 원래 머티리얼의 반사는 그대로입니다. |
| <strong>젖음 경계: 또렷하게 ↔ 부드럽게</strong> | 마른 곳과 젖은 곳 사이의 전환 | 50%가 Unity에서 정한 경계, 0%는 훨씬 또렷하게, 100%는 넓고 부드럽게입니다. 보호 영역의 경계는 바뀌지 않습니다. |
| <strong>비침 강도 (50%=기본)</strong> | 젖어서 더해지는 비침만 | 0%는 추가 비침 없음, 100%는 일부러 강하게(덜 젖은 곳과 어두운 옷도 더 빨리 비침)입니다. |

**50%=기본**은 원래 머티리얼을 50%만 보이게 한다는 뜻이 아닙니다. 50%가 Unity에서 설정한 모습입니다.

{/* SHOT R10: Wet Edge 0 / 50 / 100 % at wetness 50 % */}

:::tip[색은 진하게, 광택은 약하게]
**젖음 표현**을 올리고 **젖은 광택**을 내려 주십시오. 광택만 바꿔도 젖은 색·비침이나 젖는 위치는 변하지 않습니다.
:::

### 젖음 비침 모드 {/* #see-through */}

| 선택 | 결과 |
| --- | --- |
| **설정대로** (처음 값) | 파츠마다 정한 비침 방식을 씁니다. |
| **젖을 때 강제 비침** | 두꺼운 원단·어두운 원단도 젖은 부분이 비치게 합니다. 보호 영역은 그대로 막습니다. |
| **비치지 않음** | <ProductName />이 더한 비침을 끕니다. 젖은 색·광택과 원래 머티리얼의 투명도는 남습니다. |

{/* SHOT R05: As Configured / Force See-Through When Wet / No See-Through */}

원래 투명한 레이스나 디졸브로 사라진 부분을 채우는 기능은 아닙니다. **비치지 않음** 모드나 보호 영역에는 비침 강도를 올려도 비침이 생기지 않습니다.

### SSAO/그림자 완화

기본은 켜짐입니다. 각 파츠에 설정한 비침부 음영 완화를 씁니다. 끄면 <ProductName />이 더한 완화만 꺼집니다. 원래 셰이더의 SSAO·그림자 설정은 바꾸지 않습니다.

### 비침 보호 페이지 {/* #protection */}

| 버튼 | 하는 일 | 처음 값 | 저장 |
| --- | --- | --- | --- |
| **중요 부위 비침 보호** | 켜 둔 모든 보호 영역의 비침 막기를 한 번에 켜고 끕니다. 끄면 그 자리도 비칩니다. | **게임에서 처음부터 중요 부위 비침 보호 켜기**의 값(새 설치는 켜짐) | 저장 안 함 |
| <strong>비침 보호 범위 (50%=기본)</strong> | 보호가 막는 넓이입니다. 0%는 거의 막지 않음, 50%는 Unity에서 보이는 크기 그대로, 100%는 넓게 막습니다. | 50% | 저장 |
| <strong>비침 보호 강도 (100%=완전히 막음)</strong> | 보호가 막는 정도입니다. 100%는 완전히 막고, 50%는 막지 않을 때 비침의 약 3분의 1, 0%는 막지 않습니다. | 100% | 저장 |

자세한 내용은 [비침 보호](./see-through-protection.mdx#dials)를 확인해 주십시오.

## 전체 영역 젖음 {/* #whole-area */}

**젖음 > 전체 영역 젖음** 토글입니다.

| 토글 | 결과 |
| --- | --- |
| 꺼짐 (기본) | Unity에서 정한 대로 젖습니다. **땀나는 곳부터**, **몸에 닿는 곳부터**, **둘 다** 중 고른 방식에서 시작해 퍼집니다. |
| 켜짐 | 옷 전체가 고르게 젖습니다. 시작점과 퍼짐은 쓰지 않고, 얼마나 젖는지는 젖음 양(RealSweat 연동이면 땀 수치)이 정합니다. |

{/* SHOT R03: Whole Area OFF / ON */}
[![전체 영역 젖음 끔·켬](/img/renders/R03.jpg)](/img/renders/R03.jpg)

- 켜도 보호 영역은 그대로 보호됩니다. 비침·광택·젖은 색과 젖는·마르는 시간도 같습니다.
- 켜 둔 동안은 옷 전체가 젖으므로, 비치는 옷은 젖음 양이 많을수록 옷 전체가 비칩니다. 원하지 않으면 **비치지 않음** 모드나 보호 영역을 써 주십시오.
- 켜 둔 동안에는 <strong>최대 젖는 범위 (%)</strong>, **젖는 범위만 넓히기**, **의상별 편차 줄이기**, **젖음 경계**가 효과가 없습니다. 모두 젖는 위치를 정하는 조절이기 때문입니다. 단, 최대 젖는 범위가 0%면 켜 둔 동안에도 젖지 않습니다.
- RealRain의 빗방울·물줄기·비 퍼짐은 이 토글과 상관없이 그대로입니다.
- Unity에서는 미리보기 아래의 <strong>전체 영역 젖음 (인게임 메뉴)</strong> 체크로 켠 모습을 미리 볼 수 있습니다. 미리보기에만 쓰이며 저장된 설정은 바뀌지 않습니다.

## 메뉴에 기능 넣고 빼기 {/* #edit-menu */}

1. Hierarchy에서 `RealWet` 오브젝트를 선택하고 **인게임 메뉴** 탭을 엽니다.
2. 넣을 기능을 체크하고, 뺄 기능의 체크를 끕니다.
3. **런타임 메뉴 적용 / 갱신**을 누릅니다.
4. 다시 빌드한 아바타에서 확인합니다.

{/* SHOT U17: RealWet inspector, In-Game Menu tab */}
[![인게임 메뉴 탭](/img/guide/U17-ko.png)](/img/guide/U17-ko.png)

*<small>이 그림은 RealSweatSystem과 연동한 시험 아바타에서 찍었으므로 합계가 64비트입니다. 합계는 고른 항목에 따라 달라집니다. RealWetSystem만 쓰는 새 설치의 추천 구성은 87비트입니다.</small>*

- 메뉴 체크는 **버튼을 넣는 설정**입니다. 그 기능을 처음부터 켤지와는 다릅니다. 예를 들어 **의상별 편차 줄이기**는 기능 자체는 켜져 있지만, 버튼은 추천 구성에 없습니다.
- 체크를 끄면 그 인게임 조절이 빠질 뿐, Unity에서 저장한 외형·보호 설정은 그대로입니다. 버튼이 없는 기능은 Unity에서 정한 값으로 동작합니다.
- 체크를 모두 추천 구성으로 되돌리려면 설치창의 **권장 인게임 메뉴 복구**를 누릅니다.

### 메뉴 위치와 언어

- **위치:** `RealWet` 오브젝트의 **MA Menu Installer**에서 설치 대상 메뉴를 바꾸면 원하는 하위 메뉴 안에 **젖음** 메뉴를 넣을 수 있습니다. 이 위치는 메뉴를 갱신해도 유지됩니다.
- **언어:** 버튼 이름은 메뉴를 만들 때 고른 <ProductName /> 언어(English / 한국어 / 日本語)를 따릅니다. VRChat 안에서 자동으로 번역되지는 않으므로, 원하는 언어를 고르고 메뉴를 갱신한 뒤 다시 빌드해 주십시오.
- 메뉴 파일은 아바타마다 `Assets/CookiTools/Generated/RealWet/RuntimeMenus`에 만듭니다. 패키지 폴더를 덮어써도 지워지지 않습니다.
- 메뉴를 직접 옮기거나 다른 메뉴로 바꾸면 <ProductName />은 그 메뉴를 그대로 둡니다. 다시 만들려면 [메뉴가 안 보임](../troubleshooting.mdx#menu-missing)을 확인해 주십시오.

## 동기화 용량 {/* #sync-cost */}

**RealWet > 인게임 메뉴**나 설치창의 **최종 동기화 비용** 요약에서 지금 선택의 합계를 확인해 주십시오. 아래는 <ProductName />이 더하는 용량이며, RealSweatSystem이나 다른 도구가 쓰는 용량은 따로입니다.

| 구성 | 추가 동기화 용량 |
| --- | --- |
| 단독 기본 조작 (젖음 양 + 의상 젖음 보이기) | 9비트 |
| RSS 연동 기본 조작 (RealSweat 연동 + 연동 해제 시 젖음 양) | 9비트 |
| 최대 젖는 범위, 범위 넓히기, 젖음 표현, 젖은 광택, 경계, 비침 강도, 비침 보호 범위, 비침 보호 강도 | 다이얼마다 8비트 |
| 젖음 비침 모드 | 8비트 |
| 전체 영역 젖음, 상태 고정, 빠른 건조, SSAO/그림자 완화, 의상별 편차 줄이기 | 항목마다 1비트 |
| 의상 젖음 보이기 | RSS 연동에서 넣으면 1비트 (단독 모드는 기본 조작에 포함) |
| 의상별 표시 그룹 | 그룹마다 1비트 |
| 중요 부위 비침 보호 | 1비트 (보호 영역이 여러 개여도 토글 하나) |
| 나에게만 표시 | 단독 모드에서 넣으면 1비트 |

새 설치의 추천 메뉴는 RSS 연동일 때와 단독일 때 모두 **87비트**입니다. 의상별 표시 그룹 6개까지 모든 항목을 넣으면 94비트입니다. VRChat의 한도는 아바타 전체에서 256비트입니다. 다른 도구와 합쳐 한도를 넘으면 [메뉴·파라미터가 한도를 넘음](../troubleshooting.mdx#over-limit)을 확인해 주십시오.

## Unity와 인게임이 다를 때

- Unity 미리보기는 젖음 설정의 기본값을 씁니다. VRChat은 이전에 저장한 메뉴 값을 다시 쓸 수 있습니다.
- 비교할 때는 젖음 양뿐 아니라 연동, 전체 영역 젖음, 최대 젖는 범위, 의상별 편차 줄이기, 범위 넓히기, 경계, 비침 모드·강도, 비침 보호 범위·강도, 표현, 광택, 빠른 건조와 상태 고정도 맞춰 주십시오.
- 범위 넓히기의 처음 값은 0%, 경계·젖음 표현·젖은 광택·비침 강도·비침 보호 범위는 50%, 비침 보호 강도는 100%, 비침 모드는 **설정대로**입니다.
- 메뉴 구성이나 언어를 바꿨다면 **런타임 메뉴 적용 / 갱신** 후 다시 빌드해 주십시오. 이미 들어 있는 다이얼을 게임 안에서 움직이는 데는 다시 빌드할 필요가 없습니다.
- 시작점 공 하나하나를 게임 안에서 켜고 끄는 메뉴는 없습니다. 시작점 편집은 Unity에서 합니다.
