# 젖음 설정

아바타 전체의 기준은 **RealWet > 젖음 설정**에서 정하고, 한 벌의 젖은 모습은 **이 의상 설정 > 젖음 표현**에서 정합니다. 처음에는 의상 하나를 미리보기로 띄우고, 한 번에 한 항목씩 바꿔 주십시오.

{/* SHOT U16: RealWet inspector, Wetness Settings tab */}
[![젖음 설정 탭](/img/guide/U16-ko.png)](/img/guide/U16-ko.png)

*<small>예시 그림입니다. 시험 아바타라 **젖는 정도 선택**이 **사용자 지정**이고 **의상별 편차 줄이기**가 꺼져 있습니다. 새 설치에서는 **의상별 편차 줄이기**가 켜져 있습니다.</small>*

이 페이지에서 다루지 않는 것:

- 땀이 시작되는 공: [젖음 시작점](./wet-start-points.mdx)
- 가슴·사타구니의 비침 막기: [비침 보호](./see-through-protection.mdx)
- 의상 등록, 파츠, 겹옷 순서: [의상 설정](./outfit-settings.mdx)

## 젖기 시작하는 방식 {/* #start-mode */}

| 선택 | 보이는 결과 | 이럴 때 고릅니다 |
| --- | --- | --- |
| <strong>땀나는 곳부터 (추천)</strong> | 겨드랑이·가슴·등 같은 [젖음 시작점](./wet-start-points.mdx) 주변부터 번집니다. 새 설치의 기본값입니다. | 땀으로 젖은 모습을 원할 때 |
| **몸에 닿는 곳부터** | 옷이 피부에 붙어 있는 부분부터 젖습니다. | 몸에 달라붙는 옷의 접촉감을 살리고 싶을 때 |
| **둘 다** | 땀 지점에서 시작해 몸에 닿는 곳을 따라 번집니다. | 두 방식을 함께 쓰고 싶을 때 |

{/* SHOT R12: Sweat spots / Body contact / Both */}

- 비를 맞은 것처럼 옷 전체를 고르게 적시는 것은 이 선택이 아니라 인게임 [전체 영역 젖음](./in-game-menu.mdx#whole-area)입니다.
- 의상마다 다른 방식을 쓰려면 의상 화면에서 따로 고를 수 있습니다. 설치창에서 방식을 고르면 모든 의상이 같은 방식을 씁니다.

## 얼마나 넓게 젖는지 {/* #range */}

### 최대 젖는 범위와 젖음 양

| 설정 | 정하는 것 |
| --- | --- |
| <strong>최대 젖는 범위 (%)</strong> | 땀(젖음 양)이 100%일 때 젖음이 **어디까지** 퍼질 수 있는지 정합니다. 새 설치는 40%입니다. |
| **젖음 양** (인게임) | 그 범위 안에서 **얼마나 충분히** 젖을지 정합니다. 범위가 좁아도 양이 100%면 범위 안은 충분히 젖고, 설정한 비침까지 진행합니다. |

- **의상별 편차 줄이기**가 켜져 있으면, 최대 젖는 범위가 M%일 때 젖음 양 100%에서 각 의상은 물이 닿을 수 있는 부분 중 <strong>대략 M%</strong>가 젖습니다. 50%면 닿는 부분의 대략 절반입니다.
- 땀에서 멀어 물이 닿지 않는 부분은 100%로 올려도 젖지 않습니다. 그래서 이 값은 옷 전체 면적의 비율이 아닙니다.
- 범위를 낮춰도 비침의 최대 세기는 낮아지지 않습니다. 비침만 줄이려면 인게임 **비침 강도**를 씁니다.

{/* SHOT R02: Maximum Wet Range 20 / 40 / 70 / 100 % */}

### 젖는 정도 선택

**젖는 정도 선택**에서 **좁음 (조금 젖음)**, **표준 (보통)**, **넓음 (많이 젖음)**, **최대 (흠뻑 젖음)** 중 하나를 고를 수도 있습니다.

- 단계를 고르면 범위와 함께 젖는 시간, 퍼지는 거리, 도달 거리, 겹옷으로 전달되는 정도도 함께 바뀝니다.
- 범위만 바꾸려면 퍼센트를 직접 입력해 주십시오. 직접 바꾸면 **사용자 지정**으로 보입니다.
- 새 설치의 40%는 단계가 아니라 직접 정한 값입니다.

### 의상별 편차 줄이기 {/* #reduce-differences */}

**의상별 편차 줄이기**는 의상마다 젖는 넓이의 차이를 줄입니다. 새 설치에서는 켜져 있습니다.

- 몸에 붙어 빨리 젖는 의상은 늦추고, 헐렁해서 늦게 젖는 의상은 앞당깁니다.
- 의상 한 벌을 통째로 맞추므로, 같은 의상 안의 파츠 순서는 그대로입니다.
- 피부에서 너무 멀어 원래 젖지 않는 부분은 넓히지 않습니다. 범위 안의 젖은 정도나 비침도 바꾸지 않습니다.
- 미리보기에서 같은 수치로 켜고 끈 모습을 비교해 주십시오. 보정이 필요 없는 의상은 차이가 작거나 없습니다.
- 인게임 버튼은 기본 메뉴에 없습니다. 넣으려면 **RealWet > 인게임 메뉴**에서 고릅니다.

피부에서 크게 떨어진 겉옷처럼 물이 닿지 않는 파츠는 그 파츠의 **밀착도 프리셋**을 **밀착**으로 바꾸면 물이 닿는 거리가 늘어납니다. 기본값은 **보통**입니다.

:::note[넓게 퍼지는 것과 경계를 부드럽게 하는 것은 다릅니다]
인게임 <strong>젖는 범위만 넓히기 (고급)</strong>은 같은 젖음 양에서 옅은 젖음을 더 멀리 퍼뜨립니다. <strong>젖음 경계: 또렷하게 ↔ 부드럽게</strong>는 마른 곳과 젖은 곳 사이의 전환만 바꿉니다. 둘 다 젖음이 퍼지는 중간 상태에서 비교하면 차이를 찾기 쉽습니다.
:::

## 신체 메쉬 {/* #body-meshes */}

**RealWet > 젖음 설정 > 신체 메쉬**에는 젖음 계산에 쓰는 피부 메쉬를 등록합니다. 설치창의 **1. 신체 등록**과 같은 목록입니다.

- 기본 신체에 몸통·손·발이 빠져 있다면 추가 피부 메쉬에 넣어 주십시오. **RealSweat 후보 추가**로 RealSweatSystem에 등록된 후보를 가져올 수 있습니다.
- 의상이나 머리카락은 넣지 마십시오.
- 직접 등록한 메쉬는 꺼져 있어도 계산에 들어갑니다. 쓰지 않는 교체용 바디는 넣지 마십시오.
- 추가한 신체는 피부 근접 젖음, SSAO 완화, 겹옷 순서 계산에 함께 쓰입니다. 원본 신체 메쉬는 합치거나 고치지 않습니다.

## 비침 {/* #see-through */}

### 새 의상의 기본 비침

**새 의상의 젖은 모습**의 비침은 **모두 안 비침**, **모두 비침**, <strong>겉옷만 비침 (속옷은 안 비침) (권장)</strong> 중에서 고릅니다. 새 설치는 **겉옷만 비침**입니다. 새 의상을 등록할 때 그 의상 안의 실제 안팎 관계를 한 번 확인합니다.

- 가장 안쪽 파츠, 단독 파츠, 꺼진 파츠, 판정이 애매한 파츠는 **비치지 않음**으로 시작합니다.
- 다른 파츠보다 바깥쪽임이 확실한 파츠는 **자연스럽게 비침**으로 시작합니다.
- 머리카락과 모자·안경처럼 머리에 쓰는 파츠는 어느 기본값에서도 비치게 하지 않습니다. 비치게 하려면 그 파츠 칸에서 직접 골라 주십시오.
- 이미 등록한 의상과 원본 머티리얼은 바꾸지 않습니다.

### 의상의 비침 설정

**이 의상 설정 > 젖음 표현 > 이 의상의 젖은 모습**의 **젖으면 비침**에서 고릅니다.

| 설정 | 결과 |
| --- | --- |
| **비치지 않음 (두꺼운 원단)** | 젖은 색과 광택만 더합니다. |
| **자연스럽게 비침** | 젖음이 깊어지면 점차 비칩니다. 검은 원단은 상대적으로 덜 비칩니다. |
| **어두운 색도 비침** | 어두운 무늬나 검은 원단도 잘 비칩니다. 새로 고르면 **비치는 정도**가 60%에서 시작합니다(다른 방식은 35%). |
| **파츠마다 따로** | 파츠마다 저장한 비침 방식과 정도를 그대로 씁니다. |
| <strong>비치는 정도 (%)</strong> | 충분히 젖었을 때 얼마나 비칠지 정합니다. |
| <strong>어두운 부분 비침 (%)</strong> | **자연스럽게 비침**에서 검은 부분이 너무 비치면 낮춥니다. |

[![T셔츠 등을 비치지 않음과 자연스럽게 비침으로 비교한 모습](/img/booth/booth-see-through.jpg)](/img/booth/booth-see-through.jpg)

*<small>젖음 100%의 T셔츠 등을 <strong>비치지 않음 (두꺼운 원단)</strong>과 **자연스럽게 비침**으로 비교했습니다.</small>*

- **비치지 않음**은 <ProductName />이 더하는 비침만 끕니다. 원래 투명한 레이스의 구멍을 채우지는 않습니다.
- 게임 안에서는 **비침 강도** 다이얼과 **젖음 비침 모드**로 비침을 바꿀 수 있습니다. [인게임 메뉴](./in-game-menu.mdx#see-through)를 확인해 주십시오.
- 가슴·사타구니의 비침은 [비침 보호](./see-through-protection.mdx)가 막습니다.

## 젖은 모습 {/* #look */}

### 의상마다 고르게 젖어 보이게

**RealWet**의 <strong>의상마다 고르게 젖어 보이게 (새 외형)</strong>는 흰 옷, 매트캡이 강한 옷, 몸에 붙는 비치는 옷도 다른 옷과 비슷하게 젖어 보이게 합니다. 땀과 RealRain 비 젖음에 모두 쓰입니다.

- 모든 아바타에서 기본으로 켜져 있습니다.
- 예전 모습이 좋으면 **RealWet > 젖음 설정 > 젖는 정도**에서 꺼 주십시오. 한 번 끄면 이후에도 꺼진 채로 남습니다.
- 켜면 젖음 셰이더를 새로 만들므로, 처음 미리보기나 빌드에서 한 번 시간이 더 걸립니다.
- 색 있는 옷과 머리카락은 젖어서 어두워져도 채도를 지켜, 회색으로 빠지지 않습니다.

### 이 의상의 젖은 모습 카드

의상 루트의 **이 의상 설정 > 젖음 표현**을 엽니다. **이 의상의 젖은 모습** 카드에 위에서부터 **옷감 종류** → **젖은 느낌 강도** → **젖으면 비침** → **중요 부위 비침 보호**가 있습니다. 고른 값은 바로 저장되고 켜진 파츠 전체에 들어갑니다. Ctrl+Z로 되돌릴 수 있습니다.

{/* SHOT U19: outfit inspector, wet look card */}
[![이 의상 설정](/img/guide/U19-ko.png)](/img/guide/U19-ko.png)

*<small>예시 그림입니다. 파츠마다 비침을 직접 정해 두었으므로 **젖으면 비침**이 **파츠마다 따로**로 보입니다.</small>*

젖은 부분은 원래 색이 더 깊고 진해지고, 주 조명 쪽 주름을 따라 넓고 부드러운 물기 광택이 생깁니다. 광택은 그 장면의 흰색보다 밝아지지 않습니다. lilToon 옷과 Poiyomi 옷은 같은 모습으로 젖습니다.

### 옷감 종류

옷에 가까운 것을 골라 주십시오. 아래의 짙어지는 순서는 어두운 색 옷을 기준으로 한 것입니다.

| 옷감 종류 | 젖은 모습 |
| --- | --- |
| <strong>면·니트·데님 (추천)</strong> | 물을 머금는 천입니다. 어두운 옷에서 색이 가장 많이 짙어지고, 광택은 은은합니다. |
| **폴리·새틴·수영복** | 매끈한 천입니다. 조금 진해지고, 주름을 따라 넓고 밝은 물광이 잘 보입니다. |
| **라텍스·비닐·에나멜** | 물이 스며들지 않는 소재입니다. 색은 가장 적게 바뀌고, 표면에 얇은 물막 광택이 생깁니다. |
| **중간** | 잘 모르겠을 때 고릅니다. 폴리·새틴만큼 조금 진해지고, 광택은 면과 폴리 사이입니다. |

{/* SHOT R08: fabric types */}

밝은 색 옷에서는 이 순서가 달라질 수 있습니다. 밝은 옷은 이름만 보지 말고 미리보기로 비교해 골라 주십시오.

### 젖은 느낌 강도

| 선택 | 젖은 색 진하기 | 색 선명도 | 물기 광택 |
| --- | --- | --- | --- |
| **은은하게** | 63% | 50% | 40% |
| **기본** (새 설치) | 100% | 100% | 100% |
| **강하게** | 129% | 143% | 200% |

{/* SHOT R09: Subtle / Standard / Strong */}

**강하게**는 광택이 2배가 되므로, 매끈한 옷감에서는 화면에서 더 어둡게 보이지 않을 수 있습니다.

### 외형 고급 설정

카드 아래 **외형 고급 설정**을 열면 모든 숫자가 나옵니다. 색·광택 세 값은 100%가 **기본** 강도입니다.

| 설정 | 하는 일 |
| --- | --- |
| <strong>젖은 색 진하기 (%)</strong> | 젖은 부분의 색을 짙게 합니다. |
| <strong>색 선명도 (%)</strong> | 높일수록 색감이 선명해집니다. 흰색·회색 옷은 차이가 작습니다. |
| <strong>물기 광택 (%)</strong> | 젖은 광택의 세기입니다. 0%면 광택 없이 색 변화만 남습니다. |
| <strong>늦게 진해지기 (%)</strong> | 높일수록 옅은 젖음이 먼저 퍼지고, 진한 젖음이 안쪽에서 늦게 따라옵니다. |
| <strong>옅은→진한 연결 (%)</strong> | 젖은 곳 안에서 옅은 부분과 진한 부분을 잇는 폭입니다. 띠처럼 나뉘어 보이면 높여 주십시오. |
| <strong>얼룩진 정도 (%)</strong> | 젖은 경계가 얼마나 얼룩덜룩한지 정합니다. 0%는 매끈합니다. |
| **얼룩 촘촘함** | 낮으면 큰 얼룩, 높으면 작고 촘촘한 얼룩이 됩니다. |
| <strong>젖은 경계 부드러움 (%)</strong> | 마른 곳과 옅게 젖은 곳 사이의 부드러움입니다. |
| <strong>모든 머티리얼 젖음 표현 (%)</strong> | 켜진 머티리얼 전체의 젖은 색·광택·비침을 함께 줄입니다. 0%는 젖은 표현을 숨깁니다. |

- 여러 파츠의 값이 다르면 숫자 칸에 `—`가 보입니다. 값을 바꾸면 그 항목만 켜진 파츠 전체에 같은 값으로 들어갑니다.
- 검은 옷의 광택이 너무 넓거나 밝다면 <strong>물기 광택 (%)</strong>을 낮춰 보십시오. 비닐처럼 번쩍여 보이면 **옷감 종류**를 <strong>면·니트·데님 (추천)</strong>으로 바꿔 보십시오.

### 기본값으로 되돌리기

| 대상 | 버튼 |
| --- | --- |
| 의상 전체 | 카드 맨 아래 **이 의상 외형을 기본값으로…** |
| 머티리얼 하나 | 파츠 화면 슬롯 카드의 **고급 설정 > 이 슬롯 외형을 기본값으로…** |
| 한 파츠의 모든 슬롯 | 파츠 화면의 **이 파츠 외형을 기본값으로…** |
| 모든 의상 | **RealWet > 의상 관리**의 **모든 의상 외형을 새 기본값으로…** |

- 바뀌는 것은 옷감 종류, 젖은 느낌 강도, 얼룩·경계 값입니다.
- 비침, 보호, 최대 젖는 범위, 겹옷 순서, 원본 머티리얼은 그대로입니다.
- 잘못 눌렀다면 Ctrl+Z 한 번으로 되돌릴 수 있습니다.

## 바꾼 뒤에 할 일

- 색·광택 같은 외형 수치는 켜진 미리보기에 바로 반영됩니다.
- 비침 방식처럼 준비가 필요한 설정은 준비를 마친 뒤 표시합니다. 잠시 이전 모습이 보일 수 있습니다.
- Unity에서 바꾼 설정은 이미 업로드한 아바타에 자동으로 반영되지 않습니다. 확인한 뒤 다시 빌드·업로드해 주십시오.
