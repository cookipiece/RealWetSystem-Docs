# 젖음 시작점

**젖음 시작점**은 땀이 시작되는 자리를 나타내는 공입니다. 발한위치라고도 부릅니다. 겨드랑이, 가슴, 등처럼 땀이 잘 나는 곳에 놓여 있고, 옷은 이 공 주변부터 젖기 시작해 바깥으로 번집니다.

{/* SHOT S01: Scene, default start points, one selected with influence colours, front */}

## 언제 쓰입니까? {/* #when */}

| 젖기 시작하는 방식 | 시작점 |
| --- | --- |
| <strong>땀나는 곳부터 (추천)</strong> | 씁니다. 공 주변부터 젖습니다. |
| **둘 다** | 씁니다. 공에서 시작해 몸에 닿는 곳을 따라 번집니다. |
| **몸에 닿는 곳부터** | 쓰지 않습니다. 공을 옮겨도 젖는 자리가 바뀌지 않습니다. |

인게임 **전체 영역 젖음**을 켜 둔 동안에도 시작점은 쓰지 않습니다. 옷 전체가 고르게 젖습니다.

## 젖음이 퍼지는 방법 {/* #spread */}

1. 땀(젖음 양)이 오르면, 공 안쪽에 닿는 옷이 먼저 젖습니다. 이 자리를 **시작 영역**이라고 부릅니다.
2. 땀이 더 오르면 젖음이 시작 영역 밖으로 옷을 따라 번집니다.
3. 얼마나 멀리 번질지는 공마다의 **시작 영역 밖으로 젖는 거리**와 아바타 전체의 <strong>최대 젖는 범위 (%)</strong>가 함께 정합니다.

### 최대 젖는 범위와의 관계 {/* #max-range */}

<strong>최대 젖는 범위 (%)</strong>(새 설치 40%)는 땀이 100%일 때 젖음이 시작점에서 얼마나 멀리 갈 수 있는지 정합니다.

- **의상별 편차 줄이기**가 켜져 있으면(새 설치 기본), 최대 젖는 범위가 M%일 때 땀 100%에서 각 의상은 <strong>시작점에서 물이 닿을 수 있는 부분 중 대략 M%</strong>가 젖어 보입니다. 40%면 닿는 부분의 대략 40%, 100%면 닿는 부분 전체입니다.
- 시작점에서 너무 멀어 물이 닿지 않는 부분은 100%로 올려도 젖지 않습니다. 그래서 이 값은 옷 전체 면적의 비율이 아닙니다.
- 편차 줄이기를 끄면 이 값은 면적 비율이 아니라 퍼질 수 있는 한도입니다. 옷과 몸 사이의 거리에 따라 다르게 보입니다.
- 소매나 치마 끝이 젖지 않는다면, 범위를 올리거나 그 근처에 시작점을 더하거나, 인게임 **전체 영역 젖음**을 씁니다.

## 자동 배치 {/* #auto-layout */}

새로 설치하면 <ProductName />이 이 아바타의 몸에 맞춰 시작점을 놓습니다.

- 목 뒤, 등(위·가운데·아래), 가슴과 가슴골·밑가슴, 겨드랑이, 위팔 안쪽, 팔꿈치 안쪽, 배, 사타구니, 엉덩이, 허벅지(안쪽), 무릎 뒤·종아리, 발 같은 곳에 놓입니다.
- 본으로 부위와 방향을 정하고, 등록한 신체 메쉬의 피부 표면을 찾아 공을 놓습니다. 피부 바로 안쪽에 조금 들어가는 것은 정상입니다. 공의 범위가 피부와 닿게 하기 위해서입니다.
- 가슴·겨드랑이·위팔 안쪽·팔꿈치 안쪽·허벅지 안쪽·사타구니·무릎 뒤는 몸 메쉬의 **본 웨이트**로 자리를 찾습니다. 예를 들어 가슴 본 웨이트의 아래 경계를 밑가슴 주름으로, 위팔과 몸통 웨이트가 섞이는 가장 낮은 곳을 겨드랑이로 봅니다.
- 가슴 본이 없는 **평평한 가슴**(남성형 등)은 가슴근육 아래선에 공을 놓습니다.
- 웨이트로 확인하지 못한 부위, 좌우 중 한쪽만 찾은 부위, 옷 아래에서 몸을 지운 경계에 걸린 부위는 그 부위만 본 기준의 예전 배치로 놓습니다. 확인이 필요한 시작점은 설치 결과에 이름이 나옵니다.
- MA Merge Armature로 합친 키메라 바디는 본 이름으로 연결해 판단합니다.
- 숨기려고 크기를 0으로 만든 손가락·턱 같은 본은 배치를 막지 않습니다. 공을 붙일 본이나 그 부모가 0 스케일이면 그 본을 알려 주고 그 공은 만들지 않습니다.

## 편집기 열기 {/* #editor */}

1. Hierarchy에서 `RealWet` 오브젝트를 선택합니다.
2. **젖음 설정** 탭에서 <strong>젖음·보호 영역 편집…</strong>을 누릅니다. 의상 화면의 같은 버튼으로도 열 수 있습니다.
3. **젖음·보호 영역 편집기**가 열리면 **젖음 시작점** 탭을 고릅니다.

{/* SHOT U22: region editor, start point tab, armpit selected */}

- 위의 **선택 영역**에서 공을 고르거나 **목록·검색**을 열어 찾습니다. Scene의 이름표나 점을 눌러도 됩니다.
- 선택한 공의 영향이 몸과 옷에 색으로 보입니다. 파랑은 약한 영향, 청록·노랑을 거쳐 빨강은 강한 영향입니다. 공을 드래그하는 동안에도 바로 바뀝니다.
- **표시 설정**에서 **바디 영향도 · 기본**, **의상 영향도**, **바디 + 의상**을 고르고, **전체 이름표**와 **색상 불투명도**를 바꿉니다.
- 색은 **공 하나가 닿을 수 있는 가장 넓은 범위**입니다. 지금 땀 수치에서의 최종 젖음은 아닙니다. 실제 젖은 모습은 편집기 아래의 <strong>실제 젖은 모습 확인…</strong>에서 **의상 미리보기 시작**을 눌러 봅니다. 돌아오려면 **← 영역 편집으로 돌아가기**를 누릅니다.
- Scene에서는 W로 옮기고 R로 크기를 바꿉니다. Scene 안의 작은 패널은 제목줄을 드래그해 옮깁니다.

## 공의 속성 {/* #properties */}

오른쪽 속성은 **범위·강도**, **퍼짐·얼룩**, **고급**으로 나뉩니다.

### 범위·강도

| 항목 | 뜻 | 범위 |
| --- | --- | --- |
| **이 시작점 사용** | 끄면 이 공은 옷을 적시지 않습니다. 공은 남습니다. | — |
| <strong>공 크기 (반지름 cm)</strong> | 시작 영역의 크기입니다. 공 안에 닿는 옷이 먼저 젖습니다. | 0.5~15 cm |
| <strong>시작 영역 밖으로 젖는 거리 (cm)</strong> | 시작 영역 바깥으로 젖음이 번질 수 있는 거리입니다. 넓히면 더 멀리 젖습니다. | 0.5 cm~2 m |
| <strong>중심에 모이는 정도 (%)</strong> | 높이면 공 가까이가 더 진하게 젖고 바깥은 옅어집니다. 영향이 닿는 끝은 그대로입니다. | 0~100% |
| <strong>젖는 강도 (%)</strong> | 이 공에서 나오는 젖음의 세기입니다. 100%가 기본입니다. | 0~200% |
| <strong>젖기 시작하는 땀 (%)</strong> | 땀이 이 값을 넘어야 이 공이 젖기 시작합니다. 0%면 처음부터 젖습니다. | 0~90% |

### 퍼짐·얼룩

| 항목 | 뜻 | 범위 |
| --- | --- | --- |
| **가로 퍼짐** / **세로 퍼짐** | 아바타 기준 가로·세로 방향으로 퍼지는 거리의 배율입니다. 공 크기는 바꾸지 않습니다. 예: 겨드랑이에서 옆구리로 길게 번지게 하려면 세로를 올립니다. | 0.25~2배 |
| <strong>퍼짐 회전 (도)</strong> | 가로·세로 퍼짐의 방향을 아바타 앞쪽 축을 중심으로 돌립니다. 비스듬히 번지게 할 때 씁니다. | -180~180도 |
| <strong>퍼짐 진행 (느리게 / 빠르게)</strong> | 같은 땀에서 이 공의 젖음이 얼마나 빨리 번지는지입니다. | 0.25~2배 |
| <strong>바깥 퍼짐 불규칙도 (%)</strong> | 번지는 가장자리를 얼룩지게 합니다. 0%는 매끈합니다. | 0~100% |
| <strong>불규칙 무늬 크기 (cm)</strong> | 얼룩 하나의 크기입니다. | 2~30 cm |

**젖는 강도**와 퍼짐·얼룩 값은 **이 공의 젖음 커스텀**이 켜져 있을 때 그 공에 쓰입니다. 꺼져 있으면 기본값(강도 100%, 퍼짐 1배, 불규칙도 0%, 회전 0도)으로 젖습니다. 가로·세로 퍼짐이나 회전을 직접 바꾸면 커스텀이 저절로 켜집니다. 추천 배치의 일부 공(겨드랑이 등)은 처음부터 커스텀 값이 들어 있습니다.

<strong>항목별 초기화 ▾</strong>로 항목 하나씩 기본값(강도 100%, 퍼짐 진행 1배, 불규칙도 0%, 무늬 8 cm, 중심 50%, 시작 땀 0%, 가로·세로 1배, 회전 0도)으로 되돌릴 수 있습니다.

### 모양: 공·직선·곡선 {/* #shape */}

**모양·얼룩 조절**의 **모양**에서 고릅니다.

{/* SHOT U23: Shape = Curve, Advanced coordinates with Start / End / Middle */}
{/* SHOT S06: curve start point handles */}

| 모양 | 뜻 |
| --- | --- |
| **공** | 한 점을 중심으로 한 공입니다. 기본 모양입니다. |
| **직선** | **시작**과 **끝** 두 점을 잇는 굵은 막대(캡슐)입니다. 반지름은 공 크기와 같습니다. 옆구리처럼 길게 젖는 자리에 씁니다. |
| **곡선** | 직선에 **가운데** 점을 더해 휘게 만든 막대입니다. 밑가슴처럼 둥글게 젖는 자리에 씁니다. |

- 직선이나 곡선을 고르면 공이 길이 약 10 cm의 선이 됩니다. Scene에서 시작·끝 점(곡선은 가운데 점도)을 움직여 모양을 만듭니다.
- 시작 점과 끝 점은 각각 따라 움직일 관절(본)이 있습니다. <strong>고급 설정 (좌표·연결)</strong>에서 **기준 Transform**과 **시작** / **끝** / **가운데** 위치를 숫자로 고칠 수 있습니다.
- 다시 **공**을 고르면 그 모양의 가운데에 공 하나로 돌아갑니다.

### 고급

| 항목 | 뜻 |
| --- | --- |
| **이름** | 목록·Scene·Hierarchy에 보이는 이름입니다. 비우면 자동 이름으로 돌아갑니다. |
| **대칭 연결 상대** | 좌우 짝이 되는 공입니다. **좌우 대칭**이 켜져 있으면 한쪽을 바꿀 때 짝도 바뀝니다. |
| **공의 젖음 방식** | **땀 집중**은 공 근처에 젖음을 모읍니다. <strong>중심에 모이는 정도 (%)</strong>는 이 방식에서만 쓰입니다. **기존: 범위 확산**은 예전 방식입니다. 예전 방식 공은 <strong>기존 공을 땀 집중 방식으로 전환…</strong>으로 바꿀 수 있습니다. |

## 공 만들기·복제·삭제 {/* #create */}

| 버튼 | 하는 일 |
| --- | --- |
| **+ 시작점 추가** | 선택한 공 옆에 새 공을 만듭니다. 좁은 창에서는 **+ 영역 추가**로 보입니다. |
| **+ 좌우 한 쌍 추가** | 왼쪽과 오른쪽 거울 위치에 서로 연결된 공 2개를 만듭니다. |
| **반대쪽 만들기** | 짝이 없는 옆쪽 공의 반대쪽을 같은 설정으로 만들고 연결합니다. 가운데에 있는 공은 짝이 없어도 됩니다. |
| <strong>몸 부위에서 ▼</strong> | 팔꿈치·무릎·가슴 같은 부위를 고르면 그 뼈에 시작점을 만듭니다. 이미 있는 부위는 <strong>(있음)</strong>으로 보입니다. Humanoid 아바타에서만 보입니다. |
| **복제·삭제·초기화 > 이 시작점 복제** / **좌우 한 쌍 복제** | 선택한 공(또는 한 쌍)을 복제합니다. |
| **삭제…** 또는 Delete 키 | 확인창을 거쳐 지웁니다. 한 쌍이면 **이 시작점만 삭제**나 **좌우 2개 삭제**를 고릅니다. |

추가·복제·삭제는 모두 Ctrl+Z로 되돌릴 수 있습니다.

## 되돌리기와 다시 배치하기 {/* #reset */}

{/* SHOT U24: Duplicate / delete / reset section and the layout buttons */}

| 버튼 | 하는 일 |
| --- | --- |
| **위치 초기화** / **크기 초기화** / **위치+크기** | 선택한 공(대칭이면 한 쌍)의 위치나 크기를 기본값으로 되돌립니다. 크기에는 퍼짐 거리도 들어 있습니다. |
| **지금 위치를 기본값으로 저장…** | 지금 위치와 크기를 이 공의 기본값으로 삼습니다. 나중에 초기화하면 여기로 돌아갑니다. |
| **젖음 속성 초기화** | 강도·퍼짐·얼룩 같은 젖음 속성을 되돌립니다. |
| **전체 시작점 초기화** | 모든 공의 위치·크기·속성을 한꺼번에 되돌리는 메뉴입니다(**전체 위치 초기화…**, **전체 크기 초기화…**, **전체 위치 + 크기…**, **전체 시작점의 젖음 속성 초기화…**). |
| **기본 땀 분포로 배치…** | 지금 공을 모두 지금 버전의 추천 배치로 바꿉니다. 직접 고친 공도 바뀌므로 확인창을 읽고 실행해 주십시오. |
| **빠진 발한 시작점 보충** | 지금 배치는 두고, 추천 배치에 있는데 빠진 공만 더합니다. 빠진 공이 있을 때만 보입니다. |

- 모두 Ctrl+Z로 되돌릴 수 있습니다.
- 저장했거나 직접 옮긴 공은 업데이트만으로 움직이지 않습니다. 업데이트할 때 저장된 배치가 새 추천 배치와 다르면 설치창이 **발한위치 재설정** / **기존 설정 유지** 중 하나를 묻습니다.

## 자주 하는 조절 {/* #tips */}

| 하고 싶은 것 | 방법 |
| --- | --- |
| 겨드랑이 땀을 옆구리까지 길게 | 겨드랑이 공의 **세로 퍼짐**을 올리거나, 모양을 **직선**으로 바꿔 끝 점을 옆구리로 내립니다. |
| 등 가운데가 더 빨리 젖게 | 등 가운데 공의 **젖는 강도**나 **퍼짐 진행**을 올립니다. |
| 어떤 곳은 땀이 많이 날 때만 젖게 | 그 공의 <strong>젖기 시작하는 땀 (%)</strong>을 올립니다(예: 50%). |
| 가슴 아래 젖음을 둥글게 | 밑가슴 공을 **곡선**으로 바꾸고 가운데 점으로 휘게 합니다. |
| 한 곳만 젖지 않게 | 그 공의 **이 시작점 사용**을 끕니다. 지우지 않으므로 나중에 다시 켤 수 있습니다. |
| 헐렁한 옷이 잘 젖지 않음 | 공을 키우기보다 그 파츠의 **밀착도 프리셋**을 **밀착**으로 바꿔 보십시오. 몸에서 멀리 떨어진 천까지 물이 닿습니다. |
| 좌우를 함께 고치기 | **좌우 대칭**을 켜고 한쪽만 고칩니다. |

:::tip[한 번에 하나씩 바꾸십시오]
공을 하나 고친 뒤 미리보기를 50%와 100%로 확인하고, 다음 공으로 넘어가 주십시오. 여러 개를 한꺼번에 바꾸면 어떤 변경이 효과를 냈는지 알기 어렵습니다.

- 시작점 공 하나하나를 인게임에서 켜고 끄는 메뉴는 없습니다. 시작점 편집은 Unity에서 합니다.
- 시작점은 Unity 편집용입니다. 게임에 Collider·PhysBone·Contact를 더하지 않고, 인게임 계산도 늘지 않습니다.
- 공을 바꾸면 그 의상의 젖음 계산을 다시 준비합니다. 미리보기가 잠시 이전 모습을 보일 수 있습니다.
