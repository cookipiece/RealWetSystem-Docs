# RealWetSystem

<ProductName /> is a tool that adds a wet color, gloss and see-through effect to the clothes on VRChat PC avatars. You preview the wet look in Unity, and you adjust the wetness amount from the **Wet** menu in VRChat.

:::info[Documented version]
These docs are written for **<ProductName /> v1.0.1**. They describe a new install. An avatar you updated may still have settings from an earlier version.
:::

## What it does

- Clothes get wet naturally, starting where you sweat or where they touch the body.
- Wet areas take on a deeper version of their original color, with a watery gloss along the folds.
- Thin clothes turn see-through where they are wet. On the chest and groin, **See-Through Protection** blocks only the see-through. Protected areas still get wet like everywhere else.
- The wet look changes with the fabric type (cotton · knit · denim, polyester · satin · swimwear, or latex · vinyl · enamel).
- You adjust the wetness amount, gloss, see-through strength and see-through protection right from the **Wet** menu in VRChat. Turn on **Whole Area** and the whole garment gets wet evenly, as if in the rain.
- lilToon clothes and Poiyomi clothes (locked materials included) get wet with the same look.
- What you see in the preview is what gets uploaded. It works with shaders only, so it adds no particles, PhysBones or Contacts.

<ProductName /> works on its own. Use it with RealSweatSystem and the clothes get wet to match the sweat level on the skin. Use it with RealRainSystem and the rain-wet look is drawn on the same clothes too.

### How is it different from RealSweatSystem? {/* #vs-realsweat */}

- RealSweatSystem makes the **skin** sweat. <ProductName /> makes the **clothes** wet.
- With both, the clothes get wet on their own as you sweat. A new install starts with **Link RealSweat** on.
- Each one also works alone. For details, see [Using it with RealSweatSystem](./advanced.mdx#realsweat).

## Before you start

<ProductName /> needs the following.

| Item | Supported |
| --- | --- |
| Editor | The Unity Editor on Windows. Purchase activation works only on Windows. |
| Unity | Unity 2022.3 project for VRChat |
| VRChat Avatars SDK | 3.10.0 or later, below 4.0 |
| NDMF | 1.13.1 or later, below 2.0 |
| Modular Avatar | 1.14.0 or later, below 2.0 |
| Shaders | lilToon 2.3.0 or later, or Poiyomi Toon / Pro (9, 10 or 11), to match your outfits |
| VRCFury (if used) | 1.1436.0 or later |
| Avatar | A Humanoid avatar. PC only; Quest and mobile are not supported. |
| Purchase activation | [Purchase activation](./license-activation.mdx), done once per PC |

For the full details, see [Compatibility](./compatibility.mdx).

:::note[You may need to adjust it to your avatar]
It is made to work on many avatars, but depending on the body shape, the automatically placed wet start points and see-through protection regions may not fit. In that case, please adjust their position and range yourself. [Wet spots or protection don't fit the avatar](./troubleshooting.mdx#placement-mismatch)
:::

## There are three places to set things up

| What you want to change | What to select |
| --- | --- |
| Adding and removing outfits; where and how much the whole avatar gets wet; start points and protection regions; the in-game menu | The **RealWet** object in the Hierarchy |
| The wet look of one outfit, such as a shirt or a skirt | **This Outfit's Settings** on the outfit root |
| Within one outfit, making only the ribbon less wet or only the top see-through | **Outfit Part Settings** on that mesh |

These docs call them **RealWet**, **This Outfit's Settings** and **Outfit Part Settings**. **RealWet** has the **Outfit Management**, **Wetness Settings**, **In-Game Menu** and **Status** tabs.

:::info[Builds never stop]
<ProductName /> never stops a build or an upload. Only the parts it could not apply wetness to are uploaded with their original dry materials, and everything else gets wet as usual. For each part uploaded dry, the NDMF results window shows a warning with the outfit name and the reason.
:::

:::warning[Back up first]
Please back up your avatar and project before you install or update.
:::

:::warning[Uninstall from the setup window]
To remove <ProductName />, don't delete the `RealWet` object yourself. Please use the **Uninstall** tab in **CookiTools > RealWetSystem > Setup／Uninstall**. See [Uninstalling](./troubleshooting.mdx#uninstall).
:::
