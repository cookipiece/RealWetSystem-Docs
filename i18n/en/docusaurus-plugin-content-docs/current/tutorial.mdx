# Beginner tutorial

This page is a guide for people using <ProductName /> for the first time. Follow it in order and you will learn what the setup window options mean, how to choose outfits, and what to press in VRChat. If you want to finish quickly, following only [Quick start](./quick-start.mdx) is fine too.

:::tip[Keep the defaults at first]
The setup window defaults are chosen to suit most avatars. You can change every setting after installing, so please install with the defaults first, then change things one at a time while you watch the preview.
:::

## Terms used on this page

| Term | Meaning |
| --- | --- |
| **Outfit Root** | The top object of one outfit. The meshes worn together, such as a shirt, a skirt and a ribbon, are under it. |
| **Part** | One mesh inside an outfit, such as a ribbon, a lining or a top. |
| **RealWet object** | The `RealWet` object created under the avatar when you install. The settings for the whole avatar are here. |
| **Wet start point** | A sphere that marks where sweat starts. Start points sit in places such as the armpits, chest and back. |
| **See-through protection region** | A sphere, capsule or box that keeps clothes from showing through even when wet. By default, they go on the chest and groin. |
| **Synced parameters** | The budget VRChat uses to send menu values to other people. One avatar can use up to 256 bits. |

## 1. Prepare and activate your purchase

1. Back up your avatar and project.
2. In **Manage Project** in VCC, check **VRChat Avatars SDK** (3.10.0 or later), **NDMF** (1.13.1 or later) and **Modular Avatar** (1.14.0 or later). If you use **VRCFury**, check that it is 1.1436.0 or later.
3. Check that the shaders your outfits use are there. lilToon outfits need lilToon 2.3.0 or later, and Poiyomi outfits need the Poiyomi they use (9, 10 or 11). Poiyomi 8.x and earlier are not supported.
4. Import the <ProductName /> `.unitypackage` and wait until importing and compiling finish.
5. Open **CookiTools > RealWetSystem > Purchase Activation**, enter your BOOTH order number (or Gumroad license key), then press **Activate**.

{/* SHOT U02: Purchase Activation window */}
[![The Purchase Activation window, not activated yet](/img/guide/U02-en.png)](/img/guide/U02-en.png)

- Activation is done once per PC. You need the internet when you activate, and at least once every 3 weeks for automatic renewal.
- The only thing that needs activation is pressing **Install** on a new avatar. Adding outfits, changing settings, updating and uninstalling don't need it.
- If you upload from a PC that is not activated, the clothes look wet in the preview and in Play, but the effects are left out of the uploaded avatar. For details, see [Purchase activation](./license-activation.mdx).

## 2. Open the setup window

1. **Save** the scene that contains your avatar. In a new scene that has never been saved, installing may not work.
2. In the Hierarchy, select the **avatar's top-level object**. It must be the avatar in the scene, not a prefab in the Project window.
3. From the Unity menu bar, open **CookiTools > RealWetSystem > Setup／Uninstall**.

{/* SHOT U01: Unity top menu CookiTools > RealWetSystem */}
[![The RealWetSystem items in the Unity top menu](/img/guide/U01-en.png)](/img/guide/U01-en.png)

*<small>The Unity top menu. **CookiTools > RealWetSystem** has **Setup／Uninstall**, **Purchase Activation** and **Add or Update Clothing**. **Add or Update Clothing** adds or updates the outfit selected in the Hierarchy.</small>*

At the top of the window are the **Install** / **Uninstall** tabs and the **Avatar** field. If the Avatar field is empty, press **Detect** or drag the avatar in. The current status appears on one line below the Avatar field.

| Status | Meaning |
| --- | --- |
| **Not Installed** | This avatar doesn't have <ProductName /> yet. The button at the bottom is **Install**. |
| **Installed** | It is already installed. The button at the bottom is **Update**, and the saved settings are loaded. |
| **Repair Needed** | Part of the install is missing. You can fix it with **Update**. |
| **Duplicate Error** | One avatar has two or more `RealWet` objects. Please keep only one. |

- Opening the setup window alone does not change your avatar. Your choices are applied when you press **Install** or **Update**.
- <ProductName /> can be newly installed only on **Humanoid avatars**. If the avatar is not Humanoid, `This avatar is not a Humanoid avatar, so RealWetSystem cannot be installed.` appears. Please change **Rig > Animation Type** in the model's import settings to **Humanoid**, then install again.
- If you haven't activated your purchase on this PC, a notice and an **Open activation window** button appear right below the Avatar field.

## 3. Setup window options {/* #setup-options */}

From the top, the Install tab has four cards, **1. Body meshes**, **2. How far should it get wet?**, **3. Where should wetness start?** and **4. How new outfits look when wet**. The **Install** button sits right below them. The folded **Linking & in-game menu** and **Advanced settings** sections are below the button. This is the same order as in the RealSweatSystem and RealRainSystem setup windows.

{/* SHOT U03: Setup window, new install, defaults */}
[![The whole Setup window](/img/guide/U03-en.png)](/img/guide/U03-en.png)

### 3.1 Body meshes {/* #body */}

Sets the **skin meshes** and the **breast bones** used to calculate wetness. The skin meshes are used to work out how close the clothes are to the skin and in what order to draw layered clothes. The breast bones are used to place the wet start points around the chest and the recommended chest protection regions.

{/* SHOT U04: card 1. Body meshes */}
[![Card 1, body registration](/img/guide/U04-en.png)](/img/guide/U04-en.png)

| Option | Meaning | Default |
| --- | --- | --- |
| **Skin Body** | The avatar's body mesh. | The body found automatically |
| **Auto Find Body** | Finds the body mesh again. If RealSweatSystem is installed, it picks the body registered in RSS first. | — |
| **Additional skin meshes (0)** | On avatars whose torso, hands and feet are separate meshes, add the other skin meshes here. If there is only one body, leave it empty. | Empty |
| **Add mesh** | Adds one more additional skin mesh field. | — |
| **Import from RealSweat** | Brings in the skin candidates registered in RealSweatSystem. Please check that they are skin you actually use. | — |
| **Left breast anchor**, **Right breast anchor** | This avatar's left and right breast bones. The fields hold the bones found automatically. If they are wrong, drag the avatar's breast bones into the fields. | The bones found automatically |
| **Auto Find Breast Bones** | Clears the bones you chose and finds both breast bones again. | — |

- Don't add outfits, hair, or meshes made for showing sweat.
- Meshes you add yourself are used in the calculation even when they are turned off. Don't add spare bodies you don't use.
- After installing, you can edit the same list in **RealWet > Wetness Settings > Body Meshes**.
- One line under the breast bone fields shows their current state (for example, **Breast bones: found automatically**). On an avatar without breast bones, leave the fields empty and the torso is used as the reference.
- If you choose a bone that the body mesh has no skin weights on (an outfit's bone, for example), a notice appears under the fields. Please choose the avatar's own breast bones, not an outfit's bones.
- When you change the breast bones on an avatar that is already installed, the **Move the chest start points and chest protection to the new bones** checkbox appears (off by default). If you check it and press **Update**, only the positions of the wet start points around the chest and of the recommended chest protection regions move to the new bones. Sizes, other start points and regions you made yourself stay as they are. If you leave it unchecked, only the bone choice is saved and the saved positions don't move.

### 3.2 How far should it get wet? {/* #range */}

{/* SHOT U05: card 2. How far should it get wet? */}
[![Card 2, how far it gets wet](/img/guide/U05-en.png)](/img/guide/U05-en.png)

| Option | Meaning | Default |
| --- | --- | --- |
| **Maximum Wet Range (%)** | Sets how far clothes get wet when sweat (the wetness amount) is at 100%. When **Reduce Outfit Differences** is on, roughly this share of the area water can reach gets wet. At 40%, that is roughly 40% of the reachable area. | **40%** |
| **Reduce Outfit Differences** | Makes the wet area of tight clothes and loose clothes similar. It slows down clothes that get wet fast and speeds up clothes that get wet slowly. | **On** |
| **Add Chest & Groin See-Through Protection Regions** | Adds 4 recommended protection regions fitted to this avatar's body (chest left and right, groin front and back) and the in-game **Private Area Protection** toggle (+1 bit). Protection regions get wet just the same; they block only the see-through. | **Checked** |

- Even at 100%, areas that sweat doesn't reach stay dry. That's why this value is not a share of the whole clothing area.
- Levels such as **Narrow**, **Standard**, **Wide** and **Maximum** are chosen after installing, in **RealWet > Wetness Settings > Wetness Preset**.
- If you turn off **Add Chest & Groin See-Through Protection Regions**, neither the protection regions nor the in-game toggle are added. Synced parameters drop by 1 bit and the shaders get a little lighter. If you wear see-through clothes, we recommend keeping it on. For details, see [See-through protection](./usage/see-through-protection.mdx).
- When you update an avatar that is already installed, **Turn Sensitive-Area See-Through Protection On from the Start** appears here instead. When it is checked, protection starts on in game. Updating does not create or change protection regions.

### 3.3 Where should wetness start? {/* #start-mode */}

Press one of the three large buttons, each with a description.

{/* SHOT U06: card 3. Where should wetness start? */}
[![Card 3, where wetness starts](/img/guide/U06-en.png)](/img/guide/U06-en.png)

| Option | What you see | Choose it when |
| --- | --- | --- |
| **From Sweat Spots (Recommended)** | Wetness spreads out from sweat points (wet start points) such as the armpits, chest and back. | You are installing for the first time, or you want a sweat-soaked look |
| **From Where It Touches the Body** | The parts of the clothes that sit against the skin get wet first. | You want to bring out how tight clothes cling to the body |
| **Both** | Wetness starts at the sweat points and spreads along the areas that touch the body. | You want to combine both methods |

- The new install default is **From Sweat Spots (Recommended)**.
- The breast bones are not chosen on this card. They are in the **1. Body meshes** card; see [3.1 Body meshes](#body).
- To make the whole garment wet evenly, as if in the rain, don't choose it here: turn on **Whole Area** in the in-game menu. See [Whole Area](./usage/in-game-menu.mdx#whole-area).
- You can move the start points after installing, in [Wet start points](./usage/wet-start-points.mdx).

### 3.4 How new outfits look when wet {/* #new-outfit-look */}

Sets how the outfits you add from now on get wet. Outfits you already registered don't change.

{/* SHOT U07: card 4. How new outfits look when wet, popup open */}
[![Card 4, the wet look of new outfits](/img/guide/U07-en.png)](/img/guide/U07-en.png)

| Option | Choices | Default |
| --- | --- | --- |
| **See-through when wet** | **No See-Through (All)**: No part shows through; only the color and gloss change.<br />**See-Through (All)**: Every part shows through naturally when wet.<br />**Outerwear Only (Not Underwear) (Recommended)**: Clothes worn underneath and clothes that are hard to judge don't show through; only clothes that are clearly worn on the outside do. | **Outerwear Only (Not Underwear) (Recommended)** |
| **Fabric · strength** | Press **Change** to open the fields for choosing the fabric type and the wet look strength. The fabrics are **Cotton · Knit · Denim (Recommended)**, **Polyester · Satin · Swimwear**, **Latex · Vinyl · Enamel** and **In Between**. The strengths are **Subtle Appearance**, **Standard Appearance** and **Strong Appearance**. | **Cotton · Knit · Denim (Recommended)**, **Standard Appearance** |

- Hair and parts worn on the head, such as hats and glasses, are never made see-through automatically, whatever you choose. To make one see-through, please choose it on that part yourself.
- **No See-Through** turns off only the see-through that <ProductName /> adds. It does not fill the holes in lace that was transparent to begin with.
- [Wetness settings](./usage/wet-settings.mdx#look) explains the differences between fabrics and strengths, with pictures.

### 3.5 Linking & in-game menu {/* #menu-options */}

The folded **Linking & in-game menu** section sits below the **Install** button. Press it to open it. Here you choose the items to put in the VRChat menu. In a new install, the recommended set is already checked, so you don't need to change anything. If you change something, please do it before you press **Install**.

{/* SHOT U08: Linking & in-game menu expanded */}
[![Integrations and in-game menu](/img/guide/U08-en.png)](/img/guide/U08-en.png)

| Option | Meaning | New install default |
| --- | --- | --- |
| **Starting input** | Appears only when RealSweatSystem is installed. The current state shows as, for example, **RealSweatSystem detected · Linked**. With **Follow RealSweat sweat level** on, the clothes get wet following the sweat on the skin. With it off, you control them with the <ProductName /> wetness amount alone. | Follow |
| **Turn On All Recommended Items** | Checks every recommended item in the list below. It leaves **Reduce Outfit Differences (menu toggle)** as it is. In the setup window, the checks apply when you press **Install** or **Update**. | — |

The list uses the same names and the same order as the in-game **Wet** menu. It is grouped by menu page, and a number such as **[8 bit]** in front of an item is the sync cost that item adds when it is on.

**Wet (main page)**

The grey line at the top (for example, **[9 bit] Show Clothing Wetness · Wetness Amount (always included)**) is the basic controls, which are always included. With RealSweatSystem linked, it reads **Link RealSweat · Wetness Amount (Unlinked)**.

| Item | Meaning | New install default | Sync cost |
| --- | --- | --- | --- |
| **Show Clothing Wetness** | A toggle that shows or hides the wet look of every outfit. | Checked | 1 bit (included in the basic controls when you use it without RealSweatSystem) |
| **Whole Area** | A toggle that makes the whole garment wet evenly when on. | Checked | 1 bit |
| **Fast Dry** | A toggle that, while on, takes no new sweat and makes the clothes almost dry in about 4 seconds. | Checked | 1 bit |
| **Hold Current State (For Photos)** | A toggle that freezes the current wet look. | Checked | 1 bit |
| **Only Visible to Me** | A toggle that, when on, makes the wet look of the clothes visible only to you. It is listed only when you use RealWet without RealSweatSystem. | Checked | 1 bit |

**Wet > See-Through Protection**

| Item | Meaning | New install default | Sync cost |
| --- | --- | --- | --- |
| **Private Area Protection** | A switch that turns the protection regions' see-through blocking on and off. If you turn off **Add Chest & Groin See-Through Protection Regions**, this switch and the two dials below it stay locked off. | Checked | 1 bit |
| **See-Through Protection Range (50% = Standard)** | A dial that changes how wide an area the protection regions block. | Checked | 8 bits |
| **See-Through Protection Strength (100% = Full Block)** | A dial that changes how strongly the protection regions block. | Checked | 8 bits |
| **Wet Clothes Only Visible to Me** | A toggle that, while on, makes other players see the clothes dry. It is listed only when you also use RealSweatSystem. If the menu has no **See-Through Protection** page, it goes on the main page. | Checked | 1 bit |

**Wet > Wet Tuning**

| Item | Meaning | New install default | Sync cost |
| --- | --- | --- | --- |
| **Maximum Wet Range (%)** | A dial that changes the range from 3.2 above in game. | Checked | 8 bits |
| **Wet Appearance (Default 50%)** | A dial that changes the strength of the wet color, saturation and see-through. | Checked | 8 bits |
| **Wet Gloss (Default 50%)** | A dial that changes only the gloss <ProductName /> adds. | Checked | 8 bits |
| **See-Through Strength (Default 50%)** | A dial that changes only the see-through caused by wetness. | Checked | 8 bits |
| **Wet See-Through Mode** | A menu for choosing **As Configured** / **Force See-Through When Wet** / **No See-Through**. | Checked | 8 bits |
| **Wet Edge: Sharp to Soft** | A dial that changes the edge between dry and wet areas. | Checked | 8 bits |
| **Soften Wet Shadows** | A toggle that turns on and off the feature that reduces dark shading behind see-through clothes. | Checked | 1 bit |
| **Reduce Outfit Differences (menu toggle)** | A toggle that turns the feature from 3.2 above on and off in game. | Unchecked | 1 bit |
| **Spread Wetness Wider (Advanced)** | A dial that spreads light wetness farther at the same wetness amount. | Checked | 8 bits |

- The menu checks **add buttons**. That is not the same as whether the feature is on from the start. For example, the **Reduce Outfit Differences** feature itself is on, but its in-game button is not added by default.
- Check the total in the **Runtime Parameter Cost** line below the list. Press the line to open the cost of each item. Before you install, no outfit has been added yet, so **Wet See-Through Mode** (8 bits) is not in the total, and it shows 79 bits. After the outfits are added, the recommended set is **87 bits**, and with every item including the outfit visibility groups, it is 94 bits. An avatar that also uses RealSweatSystem uses 1 bit more for **Wet Clothes Only Visible to Me** (80 bits, **88 bits**, 95 bits). VRChat's limit is 256 bits for the whole avatar.
- The **Wet** menu goes into the avatar's main menu, separate from the RealSweatSystem menu. After installing, you can change its location in the **MA Menu Installer** on the `RealWet` object.
- You can also change the menu layout after installing, in **RealWet > In-Game Menu**. [In-game menu](./usage/in-game-menu.mdx) explains what each button does.

### 3.7 Other avatar tools {/* #other-tools */}

If the avatar has settings from another tool that could remove the wetness, an **Other avatar tools** card appears between the four cards and the **Install** button. If there is nothing to report, this card doesn't appear.

- For example, if a d4rk Avatar Optimizer setting that rewrites shaders is on, a short notice and a **Show d4rk Settings** button appear. The button only selects and shows the d4rk component; it doesn't change any settings.
- For details, see [Compatibility](./compatibility.mdx#optimizers).

### 3.8 Install

Press **Install** below the four cards. While it installs, a progress bar shows the current step (for example, **Placing the chest & groin see-through protection regions**). When the **Installation Complete** message appears, press **OK**.

{/* SHOT U12: Installation Complete dialog */}
[![Installation Complete dialog](/img/guide/U12-en.png)](/img/guide/U12-en.png)

- On a large avatar, placing the protection regions can take a few seconds. The progress bar has no Cancel button, so that no half-finished installation is left behind.
- Installing creates a `RealWet` object under the avatar. This object holds the settings for the whole avatar.
- The first install, uninstalling and creating the in-game menu cannot be undone with Ctrl+Z. Settings you change after installing can be undone with Ctrl+Z.
- If PCSS4VRC (lilToon) or lilSSRT is on this PC, the first install asks once whether to turn on the experimental feature. If you're not sure, you can choose **Don't Use**. You can change it later in **Advanced settings > Experimental**.

## 4. Choose the outfits that should get wet {/* #outfit-chooser */}

When you close the install message, the **RealWet: Choose Outfits** window opens. It lists the outfits found on the avatar.

{/* SHOT U14: outfit chooser */}
[![The outfit chooser](/img/guide/U14-en.png)](/img/guide/U14-en.png)

| Button | What it does |
| --- | --- |
| **Add Recommended (N)** | Adds, in one go, only the outfits <ProductName /> is sure are outfits. Outfits that need a check are not added. |
| **Choose Yourself** | Check the outfits that should get wet in the list. Outfits RealWet is sure about are already checked, and outfits that need a check are listed unchecked, with a short reason. |
| **Find** | On each row. Selects and shows that outfit in the Hierarchy. |
| **Add Selected Outfits** | Adds the outfits you checked. |
| **Later** | Closes the window without adding anything. |

Outfits that need a check come with reasons like these.

| Reason | Meaning |
| --- | --- |
| Body or face meshes may be mixed in. | There may be a body or face mesh under that object. |
| An accessory named like the body or face. | An accessory whose name has a body or face word in it. If it is an outfit, please tick it. |
| Several outfits may be grouped together. | It may be an empty object that holds several outfits. It's better to add them one at a time. |
| Looks like an accessory. / It may not be clothing. | It may be a prop that doesn't need to get wet. |

- This window doesn't block Unity. You can look at the Hierarchy and the Scene while it is open.
- One Ctrl+Z undoes every outfit you added.
- To add more outfits later, use **Find Now** (it opens the same window) or **Add Outfit Manually** in **RealWet > Outfit Management**. See [Outfit settings](./usage/outfit-settings.mdx).
- If the clothes the avatar comes with are separate meshes, each mesh is added as its own outfit. To group them into one outfit, see [Group an avatar's base clothes into one outfit](./usage/outfit-settings.mdx#group-base-clothes).

:::warning[Keep outfits outside the body meshes]
Don't put an outfit root inside a body or face mesh object. We recommend placing outfits directly under the avatar, or under an empty object that is separate from the body meshes. An outfit placed inside a mesh used as the face may not be registered.
:::

## 5. Check with the preview {/* #preview */}

1. In the Hierarchy, select an outfit root. **This Outfit's Settings** appears in the Inspector.
2. Press **Start Whole Outfit Wetness Preview**. The first time, it starts after the preparation steps finish.
3. Try changing the preview wetness slider to **0% → 50% → 100%**. Press the ▶ button to play the clothes slowly getting wet.
4. To see the whole garment wet evenly, check **Whole Area (in-game menu)** below the slider. It is used only for the preview and doesn't change your saved settings.
5. When you're done, press **Stop Whole Outfit Preview**.

{/* SHOT U19: outfit inspector with the preview running */}
[![The outfit's own settings](/img/guide/U19-en.png)](/img/guide/U19-en.png)

*<small>Right after a new install. An outfit added with **Outerwear Only (Not Underwear) (Recommended)** has a different see-through for each part, so **See-Through When Wet** shows **Separate per Part**.</small>*

{/* SHOT R01: dry · 50 % · 100 %, default mode */}

What to check:

- Look from the **front, side and back** to check that the wet areas look natural. Clothes get wet starting from the sweat spots, so at 40% it's normal for sleeve ends and skirt hems to stay dry.
- For see-through clothes, check at **100%** that the chest and groin don't show through. See-through protection regions get wet too, but they don't show through.
- If clothes get less wet than you expected, check **Maximum Wet Range** in [Wetness settings](./usage/wet-settings.mdx#range). If the wet spots look odd, check [Wet start points](./usage/wet-start-points.mdx).

:::note[If the preview doesn't start]
Please check that **Tools > NDM Framework > Enable Previews** is turned on in the Unity menu bar, and that you are not in Play Mode. You don't need to press the start button again and again. The Inspector shows the current step.
:::

The preview shows the look in the current pose. Please check movement and the in-game menu in Build & Test.

### Wet > Wet Tuning

{/* SHOT M02: Wet Tuning page */}
[![The Wet Tuning page](/img/guide/M02-en.png)](/img/guide/M02-en.png)

| Dial | What it does in VRChat | Starting value |
| --- | --- | --- |
| **Maximum Wet Range (%)** | Sets how far the clothes get wet. It starts at the value from the setup window. | 40% |
| **Wet Appearance (Default 50%)** | The strength of the wet color, saturation and see-through. 50% is the look you set in Unity. | 50% |
| **Wet Gloss (Default 50%)** | Changes only the gloss <ProductName /> adds. 0% adds no gloss, and 100% doubles it. | 50% |
| **See-Through Strength (Default 50%)** | Changes only the see-through caused by wetness. 0% means no see-through, and 100% makes it show through strongly on purpose. | 50% |
| **Wet See-Through Mode** | Choose from **As Configured**, **Force See-Through When Wet** and **No See-Through**. | As Configured |
| **Wet Edge: Sharp to Soft** | The edge between dry and wet areas. 0% makes it sharp, and 100% makes it wide and soft. | 50% |
| **Soften Wet Shadows** | Reduces dark shading behind see-through clothes. | On |
| **Spread Wetness Wider (Advanced)** | Spreads light wetness farther at the same wetness amount. 0% keeps your settings as they are. | 0% |

### Wet > See-Through Protection

{/* SHOT M03: See-Through Protection page */}
[![The See-Through Protection page](/img/guide/M03-en.png)](/img/guide/M03-en.png)

| Button | What it does in VRChat | Starting value |
| --- | --- | --- |
| **Private Area Protection** | Turns the see-through blocking of protection regions, such as the chest and groin, on and off at once. When it is off, those areas show through too. It isn't saved, so it goes back to its starting value when the avatar reloads. | On |
| **See-Through Protection Range (50% = Standard)** | How wide an area protection blocks. 50% is exactly the size you see in Unity, 0% blocks almost nothing, and 100% blocks a wider area. | 50% |
| **See-Through Protection Strength (100% = Full Block)** | How strongly protection blocks. 100% blocks fully, at 50% about one third of the unblocked see-through shows, and 0% doesn't block. | 100% |
| **Wet Clothes Only Visible to Me** | Appears when you also use RealSweatSystem. While it is on, other players see the clothes dry, and you still see them wet, also in mirrors and photos. | Off |

- Most dials and toggles are saved, so the last value you chose is used the next time you join. **Fast Dry**, **Hold Current State (For Photos)** and **Private Area Protection** are not saved; they go back to their starting values every time the avatar loads.
- Button names use the <ProductName /> language (English / 한국어 / 日本語) set when the menu was created. VRChat's language setting doesn't change them.
- For details, see [In-game menu](./usage/in-game-menu.mdx) and [See-through protection](./usage/see-through-protection.mdx).

## 7. Upload and check in VRChat

1. Save the scene.
2. Run **Build & Test** or upload from the VRChat SDK. Outfits that are not prepared yet are prepared automatically when you build. During the upload, a `RealWet: …` progress bar appears.
3. In VRChat, try setting **Wet > Wetness Amount** to 0%, 50% and 100%. If you use RealSweatSystem too, change the sweat % instead.
4. For see-through clothes, also try moving the dials in **Wet > See-Through Protection**.

:::note[The first build takes a long time]
On the first build, RealWet creates the wet shaders and Unity compiles them, so it can take tens of minutes with the window barely moving. Even if it looks frozen, please wait as long as the CPU is busy. See [The first build takes a long time](./troubleshooting.mdx#long-first-build).
:::

:::info[Builds never stop]
Only the outfits RealWet could not apply wetness to are uploaded dry, and the NDMF results window shows a warning with the reason. The other outfits get wet as usual. See [NDMF warnings](./troubleshooting.mdx#ndmf-warnings).
:::
