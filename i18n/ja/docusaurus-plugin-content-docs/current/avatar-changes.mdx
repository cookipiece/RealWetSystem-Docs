# このツールがアバターで変えるもの

<ProductName />は、プレビュー画面とアップロード用のアバター複製（NDMFビルド）の中で濡れた見た目を作ります。このページでは、そのときに何を変え、何を変えないかをまとめます。

## マテリアル

- 濡らす衣装の欄のマテリアルを、<ProductName />が作った濡れ用コピーに置き換えます。プレビューとアップロードで同じです。
- 元のマテリアル（`.mat`）と元のシェーダーは変更しません。
- 濡れシェーダーは、購入者のPCに入っているPoiyomi・lilToonをもとに、そのPCで作ります。作ったファイルは`Assets/CookiTools/RealWetSystem/Generated`に置きます。パスが長すぎる場合は`Assets/RWGen`を使います。
- 計算キャッシュは`Library/RealWet`、アバターごとのメニューファイルは`Assets/CookiTools/Generated/RealWet`に置きます。消えても必要なときに作り直します。

## レンダーキュー（描画順） {/* #render-queue */}

レンダーキューは描画の順番を決める数字です。小さい値が先に、大きい値が後に描かれます。

- 濡れ用コピーのレンダーキューだけを変えます。元のマテリアル、ボディ、RealSweatの汗のレンダーキューは変えません。

| 元のキュー | 濡れ用コピーのキュー |
| --- | --- |
| 2500以下（不透明・カットアウトなど） | 「ボディ・肌の汗のキュー + 1」から2499の間 |
| 2501〜2999（半透明） | 同じ範囲の中でだけ後ろへ |
| 3000〜3099（半透明） | 同じ範囲の中でだけ後ろへ |
| それ以外（2500、3100以上など） | そのまま |

- たとえばRealSweatSystem 2.0.0の汗が2350なら2351〜2499、ボディだけで2000なら2001〜2499です。
- <ProductName />が濡らさないパーツに2460より低いキューがあれば、そのパーツより後ろから始めます。
- ボディのキューを読めないときは、従来の初期値2460〜2499を使い、お知らせします。
- 不透明と半透明の境界を越えて動かしません。入れる余地が足りないときは動かさず、NDMFの結果ウィンドウでお知らせします。
- 実験機能PCSS4VRC（lilToon）を使うパーツは、PCSSの影を保つため2499を超えません。

### 重ね着の順序

- 1つの衣装の中では、実際の重なり方を見て、内側の服を先に、上着を後に描きます。
- アップロード時にOFFで、ゲーム内でONにするパーツも、同じ順序になります。
- 自分で決めた順序はそのまま使います。一覧でのドラッグ、**手動: 描画優先度を指定**（0〜39）、**直接: レンダーキューを指定**、**マテリアルのRender Queueを維持**がこれにあたります。自動のパーツは、自分で決めた番号を避けます。
- 別々の衣装どうしの順序は決めません。衣装ごとに同じ開始番号から数えます。

:::tip[別に登録した上着が内側の服より先に描かれるとき]
上着の欄に大きい手動の番号（例：20）を付けるか、上着を下の服と同じ衣装としてまとめて登録してください。詳しくは[重ね着の順序](./usage/outfit-settings.mdx#layer-order)をご確認ください。
:::

## メッシュ

- 濡れるパーツはメッシュのコピーを作り、濡れのデータを加えます。元のメッシュ・FBXとそのインポート設定は変更しません。
- 濡れのデータは、TEXCOORD2・TEXCOORD3（設定画面のUV3・UV4）のうち空いている方に書きます。使用中のチャンネルは上書きしません。両方とも使用中なら、UVの代わりにテクスチャに入れます。
- RealRainSystemと一緒に使うと、雨を受けるパーツにTEXCOORD6の頂点番号を加えます。すでにTEXCOORD6を使っているメッシュは、そのパーツの雨だけをOFFにしてお知らせします。
- <ProductName />が保存するメッシュは圧縮しません。FBXでMesh CompressionをONにした衣装は、そのメッシュだけ非圧縮のサイズでアップロードされます。

## 深度・影

- 濡れて透ける部分は、透ける分だけ深度（Depth）の描画から外れます。そのため、透ける衣装の後ろの体にSSAOなどの黒い陰が残りにくくなります。
- 透ける欄ごとに、深度だけの描画が最大1回増えることがあります。乾いた衣装はそのままです。
- ゲーム内の**SSAO・影の軽減**（初期ON）をOFFにすると、<ProductName />が加えた軽減だけがOFFになります。元のシェーダーのSSAO・影の設定は変えません。

## アバターとアニメーター

- シーンには次のものを加えます。
  - アバターの下の**RealWet**オブジェクト：設定、開始点・保護範囲の表示、**MA Parameters**、**MA Menu Installer**
  - 新規インストールで**胸・股の透け保護領域を入れる**にチェックを入れると（初期設定）、胸・股のおすすめの保護範囲4つ。開始点と保護範囲はUnityでの編集用で、アップロードにオブジェクトを加えません。
  - 衣装ルートの**この衣装の設定**、個別に調整したパーツの**衣装パーツ設定**コンポーネント
- これらのRealWetコンポーネントはアップロードに含まれません。
- アップロード時、FXに`Cooki Clothing Wetness/`で始まるレイヤーを加えます。レイヤー数は、選んだメニュー項目によって変わります。
- MA Merge Animatorは使いません。アバターの他のFXレイヤーと元のコントローラーは変更しません。
- 同期パラメータ（名前は`Cooki/ClothWet…`）は、選んだメニュー項目の分だけ使います。新規インストールのおすすめメニューは87ビットです。詳しくは[同期容量](./usage/in-game-menu.mdx#sync-cost)をご確認ください。
- インストール後にアバターへ新しく入れた衣装は、自動で登録されます。**RealWet > 衣装管理 > 新しい衣装を自動検出**でOFFにできます。
- ユーザーが作ったメニュー、MAコンポーネント、ヒエラルキーは、修正も削除もしません。RealWetのメニューを移動したり、MAコンポーネントを外したりした場合は、ユーザーの選択とみなしてそのままにします。
- **この衣装でMA Shape Changerが隠したBodyを再表示**（初期OFF）を自分でONにした衣装だけ、アップロード用の複製でそのボディ非表示を外します。シーンのMA設定は変更しません。

## ビルド

- NDMFプラグイン**RealWetSystem**として動作します。
- 濡れを入れられなかった衣装・パーツだけが元の乾いたマテリアルでアップロードされ、NDMFの結果ウィンドウに衣装ごとに警告が1件残ります。<ProductName />が原因でビルドが止まることはありません。
- **AAO：** 自動メッシュ結合が、一緒に処理できないパーツ同士を結合するときだけ、そのアップロードで片方を結合から外してお知らせします。
- **d4rk Avatar Optimizer：** シェーダーを書き換える設定がONなら、濡れるパーツだけを今回のアップロードの除外リストに入れます。保存されたd4rkの設定は変えません。
- **TexTransTool：** TTTが変えた後のマテリアルを濡らします。

## 実験機能：PCSS4VRC（lilToon）とlilSSRT {/* #experimental */}

どちらも、インストール画面の**詳細設定 > 実験機能**でアバターごとにONにします。初期はOFFです。

- ONにすると、購入者のPCに入っているそのシェーダーのファイルと<ProductName />のファイルから、濡れ用シェーダーをそのPCのGeneratedフォルダーに作ります。このシェーダーはエクスポートしたり、ほかの人に配ったりしないでください。
- <ProductName />のパッケージに、PCSS4VRCやlilSSRTのコードは含まれません。そのシェーダーのファイルと元のマテリアルは変更しません。
- これらのパーツには、RealRainSystemの雨は降りません。
- **PCSS4VRC（lilToon）：** 10.1.5で確認しました。このパーツのレンダーキューは2499を超えません。機能がOFFのときは、PCSS4VRCが置き換えるパーツはアップロードで濡れず、プレビューの上とNDMFの結果ウィンドウでお知らせします。
- **lilSSRT：** 1.4.3のlilSSRT、lilSSRT/RTAO、lilSSRT/GTAOシェーダーと、AOをONにしたときに使うAOTessellationシェーダーに対応します。確認したバージョン以外では、lilSSRTのパーツは濡れないままビルドされ、ビルドは止まりません。レンダーキューは通常のlilToonの衣装と同じです。
- RealWetとlilSSRTを組み合わせて起きた問題は、lilSSRTの作者ではなくRealWetにお問い合わせください。lilSSRT ©MeltzzZ

## 髪

- 髪と、帽子・メガネのように頭に着けるパーツは、新しい衣装の初期値や、複数の欄にまとめて適用する透け設定では透けるようにしません。
- そのパーツの欄で透け方を自分で選べば、透けるようにできます。

## 変えないもの

- 元のマテリアル・シェーダー・メッシュ・FBX。詳細設定で元を変更する**濡れ透けマテリアル変換**を自分で実行し、確認ウィンドウで承認した場合だけは例外です。この変換はCtrl+Zで元に戻せます。
- ボディとRealSweatSystemのマテリアル、Poiyomiのロックキャッシュ。
- 保存された設定を知らせずに変えることはありません。アップデートで、手を加えていない以前の初期の見た目が新しい初期値に変わるときは、**RealWet > 衣装管理**にお知らせと<strong>元に戻す…</strong>が表示されます。
