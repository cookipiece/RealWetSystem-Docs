# RealWetSystem

<ProductName />は、VRChatのPCアバターの服に、濡れた色・光沢・透けを加えるツールです。Unityで濡れた見た目をプレビューし、VRChatの**濡れ**メニューで濡れ量を調整します。

:::info[ドキュメントの対象バージョン]
このドキュメントは、**<ProductName /> v1.0.1**をもとに書いています。新規インストールを前提に説明します。更新したアバターには、以前の設定が残っている場合があります。
:::

## できること

- 服が、汗をかく所や体に触れる所から自然に濡れていきます。
- 濡れた部分は元の色が深くなり、しわに沿って水の光沢が出ます。
- 薄い服は、濡れた部分が透けます。胸と股は、**透け保護**が透けだけを防ぎます。保護した所も、ほかの所と同じように濡れます。
- 生地の種類（綿・ニット・デニム、ポリエステル・サテン・水着、ラテックス・ビニール・エナメル）によって、濡れた感じが変わります。
- VRChatの**濡れ**メニューで、濡れ量・光沢・透けの強さ・透け防止をその場で調整します。**全範囲濡れ**をオンにすると、雨に当たったように服全体が均一に濡れます。
- lilToonの服とPoiyomiの服（ロックされたマテリアルを含みます）が、同じ見た目で濡れます。
- プレビューで見た見た目が、そのままアップロードされます。シェーダーだけで動くため、パーティクル・PhysBone・Contactは追加しません。

<ProductName />だけをインストールしても使えます。RealSweatSystemと一緒に使うと、肌の汗の量に合わせて服も濡れます。RealRainSystemと一緒に使うと、雨に濡れる様子も同じ服の上に描かれます。

## 始める前に

<ProductName />には、次のものが必要です。

| 項目 | 対応範囲 |
| --- | --- |
| エディター | WindowsのUnityエディター。購入認証がWindowsでしか動かないためです。 |
| Unity | VRChat用のUnity 2022.3プロジェクト |
| VRChat Avatars SDK | 3.10.0以上、4.0未満 |
| NDMF | 1.13.1以上、2.0未満 |
| Modular Avatar | 1.14.0以上、2.0未満 |
| シェーダー | 衣装に合わせて、lilToon 2.3.0以上またはPoiyomi Toon / Pro（9・10・11） |
| VRCFury（使う場合） | 1.1436.0以上 |
| アバター | Humanoidのアバター。PC専用で、Quest・モバイルには対応していません。 |
| 購入認証 | PCごとに一度行う[購入認証](./license-activation.mdx) |

詳しい対応範囲は、[互換性](./compatibility.mdx)を確認してください。

## 設定する場所は3か所です

| 変えたいもの | 選ぶ場所 |
| --- | --- |
| 衣装の追加・削除、アバター全体の濡れる位置・量、開始点・保護範囲、ゲーム内メニュー | Hierarchyの**RealWet**オブジェクト |
| シャツ・スカートなど1着の濡れた見た目 | 衣装ルートの**この衣装の設定** |
| 1着の中でリボンだけ濡れにくくする、トップスだけ透けさせる | そのメッシュの**衣装パーツ設定** |

このドキュメントでは、それぞれを**RealWet**、**この衣装の設定**、**衣装パーツ設定**と呼びます。**RealWet**には、**衣装管理**、**濡れ設定**、**ゲーム内メニュー**、**状態**のタブがあります。

:::info[ビルドは止まりません]
<ProductName />が原因でビルドやアップロードが止まることはありません。濡れを入れられなかった部分だけが元の乾いたマテリアルでアップロードされ、残りはそのまま濡れます。乾いたままアップロードされた部分は、NDMFの結果ウィンドウに衣装名と理由が警告として残ります。
:::
