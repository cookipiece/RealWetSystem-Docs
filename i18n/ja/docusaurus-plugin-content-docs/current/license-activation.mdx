# 購入認証

<ProductName />は、PCごとに一度、購入認証を行います。Unity上部のメニュー**CookiTools > RealWetSystem > Purchase Activation**で認証ウィンドウを開き、BOOTHの注文番号（Gumroadで購入した場合はGumroadのライセンスキー）を入力してから、**認証する**を押します。<strong>認証が完了しました。</strong>と表示されれば完了です。

{/* SHOT U02: Purchase Activation window */}

- 認証ウィンドウの右上で、English / 한국어 / 日本語 を選べます。選んだ言語は、<ProductName />の画面にも適用されます。
- インターネットは、認証するときと、自動更新のために3週間に一度以上必要です。アバターのビルドとアップロードには必要ありません。
- 購入認証は、WindowsのUnityエディターでだけ動きます。
- Cookiから受け取ったコード（`CKR-`で始まるもの）も、同じ欄に入力します。コードは、ほかの人と共有しないでください。

## 認証が必要なもの {/* #what-is-gated */}

- **新規インストール:** <ProductName />が入っていないアバターで、インストール画面の**インストール**を押すときだけ、認証が必要です。
- 認証せずに**インストール**を押すと、**認証ウィンドウを開く**ボタンのある案内が表示され、アバターは変わりません。

## 制限しないもの {/* #not-blocked */}

- 衣装の追加、設定の変更、**更新**、**アンインストール**
- Unityのプレビューと再生（Play）
- アバターのビルドとアップロード。購入認証が原因でビルドが止まることはありません。
- 長い間インターネットに接続できず、更新できなかった認証でも、アップロードで効果が外れることはありません。インターネットに接続して更新するまで、新しくインストールすることだけができなくなります。

## 認証していないPCからアップロードするとき {/* #uploads */}

認証していないPCからアップロードすると、アップロードしたアバターから<ProductName />の効果が外れます。

- ビルドは失敗せず、ウィンドウも表示されません。Consoleに、`RealWetSystem:`で始まる警告が1行残ります。
- シーンのアバターと、プレビュー・再生は変わりません。認証してからアップロードし直すと、効果が入ります。
- アップロードで効果が外れる状況では、インストール画面のアバターの欄のすぐ下に、案内と**認証ウィンドウを開く**ボタンが表示されます。
- RealRainSystemの雨で服が濡れる様子も<ProductName />が描くため、一緒に外れます。RealRainの天気（雲・雨・雨音）は、RealRainの認証にだけ従います。

確認する方法は、[購入認証せずにアップロードした](./troubleshooting.mdx#not-activated)にあります。

## PCの台数と解除 {/* #pcs */}

- 1つの注文で、個人ライセンスはPC 3台まで、Game & App Integration & Distribution LicenseはPC 10台まで認証できます。
- 1つの注文で新しく登録できるPCの台数には、30日単位の上限もあります。詳しい台数は、共通の案内を確認してください。
- 使わないPCは、認証ウィンドウの**このPCを解除**で枠を空けられます。PCを替えたり、Windowsを再インストールしたりする前に押しておくと、PCの台数を節約できます。
- 購入認証は、ツールごとに別々に行います。RealSweatSystemやRealRainSystemの注文番号は、そのツールの認証ウィンドウに入力してください。

## 認証できないとき

認証ウィンドウの**報告内容をコピー**を押して、Cookiにお問い合わせください。注文番号は、報告内容に含まれません。

## さらに詳しく

認証の方法、PCの台数、PCの解除、オフラインでの利用、エラーコード、個人情報については、CookiToolsの共通の案内にあります。

- **詳しい案内とエラーコード:** [購入認証のご案内](https://cookistudio.com/license/?lang=ja)
- **個人情報:** [プライバシーポリシー（購入認証）](https://cookistudio.com/license/privacy?lang=ja)
- 購入認証の正式な条件は、購入ファイルに含まれるライセンス文書の「購入認証」の条項です。
