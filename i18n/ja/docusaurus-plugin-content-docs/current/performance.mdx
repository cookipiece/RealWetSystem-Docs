# パフォーマンス

<ProductName />は、Unityで濡れを事前に計算し、VRChatの中ではシェーダーがその結果を描画します。このページでは、アップロード容量、ビルド時間、ゲーム内の負荷を順に説明します。

## アップロード容量 {/* #upload-size */}

濡れるマテリアルごとに、濡れ用のシェーダーとデータがアバターに入るため、アップロード容量が増えます。

| 増えるもの | 大きさを決めるもの |
| --- | --- |
| 濡れシェーダー | 濡れるマテリアルの数。マテリアルが多いほど大きくなります。 |
| 濡れデータ（濡れる位置、保護マスク、体に触れる度合い） | 濡れるメッシュの頂点数と保護範囲 |
| ゲーム内メニューのアイコン | メニューに入れた項目の数 |
| RealRainの雨データ | RealRainと併用するときの、雨を受ける服の頂点数 |

- <strong>衣装ごとに均一に濡れて見えるようにする（新しい見た目）</strong>は初期設定でオンになっていて、アップロード容量を少し増やします。
- アバターの容量の上限に近い場合は、濡れる必要のないパーツ（アクセサリー、靴など）の**濡れ機能を使用**をオフにしてください。オフのパーツは、濡れの処理から外れます。

### 測定例

以下は、例のアバター1体で測ったおおよその値です。アップロードに入る濡れるマテリアル枠が約100個（レンダラー145個）で、d4rk Avatar Optimizerをオンにしたアバターを、公開前の<ProductName /> 1.0.0のビルドで測りました。「なし」は、同じビルドから<ProductName />だけを外した結果です。

|  | 非圧縮（VRChat PCの500 MB上限の基準） | 圧縮（LZ4、ダウンロードサイズに近い） |
| --- | --- | --- |
| <ProductName />なし | 380.7 MiB | 162.6 MiB |
| <ProductName />あり | 412.6 MiB | 183.6 MiB |
| 差 | +31.9 MiB | +21.0 MiB |

VRChatは非圧縮サイズをPCの上限と比べます。ほかの人がダウンロードするサイズは圧縮サイズです。

増えた非圧縮31.9 MiBの内訳は次のとおりです。

| 項目 | 増えた量 |
| --- | --- |
| シェーダー | 23.5 MiB（濡れるマテリアル枠1つあたり約0.23 MiB） |
| メッシュ | 4.1 MiB |
| テクスチャ | 3.8 MiB |
| アニメーション | 0.9 MiB |
| マテリアル | -0.4 MiB |

- 衣装1着で増える量は、シェーダーのほかに、その衣装のテクスチャとメッシュによって変わります。
- この値には、<strong>衣装ごとに均一に濡れて見えるようにする（新しい見た目）</strong>（初期設定でオン）と新しいメニューアイコンが含まれています。
- 値は、衣装、シェーダー、併用する最適化ツールによって変わります。
- VRChatのアップロード容量の上限は、<ProductName />だけでなくアバター全体に適用されます。

## ビルド時間 {/* #build-time */}

### 初回ビルドとそれ以降のビルド

| 状況 | かかる時間 |
| --- | --- |
| 初めてビルドするとき、初めてプレビューするとき | 濡れシェーダーを作り、Unityがコンパイルするため、時間がかかります。マテリアルが多いと、数十分かかることがあります。 |
| 同じ設定でビルドし直すとき | 初回ビルドで作ったシェーダーキャッシュを再利用するため、濡れシェーダーのコンパイルをほぼすべて省き、ずっと短く終わります。 |
| シェーダー（Poiyomi・lilToon）や<ProductName />を更新した後 | 変わったシェーダーだけを準備し直します。最初の1回は、また時間がかかることがあります。 |
| 濡れる位置・範囲・衣装の形を変えた後 | 変わった衣装だけを計算し直します。 |

配信や録画などでPCが忙しいときに初回ビルドをすると、さらに時間がかかります。初回ビルドは、PCに余裕があるときに済ませておくのがおすすめです。

- アップロード中は、`RealWet: 衣装の形状を計算中 (3/22) · 衣装名`のように、<ProductName />の段階と順番、衣装名が進行表示に出ます。
- 進行表示が長い間そのままでも、UnityがCPUを使っていれば、シェーダーをコンパイルしている途中です。お待ちください。[最初のビルドに時間がかかる](./troubleshooting.mdx#long-first-build)を確認してください。

### 事前に準備しておく

- **Unityを1分間操作しないと自動で準備**がオンなら、キーボード・マウスの入力が1分間なく、Unityが後ろに回っているときに、必要な衣装を1着ずつ準備します。いま着ている衣装から準備し、`EditorOnly`の衣装は準備しません。
- すぐに準備するには、**RealWet > 衣装管理 > 必要な衣装のみ準備**を押します。準備が終わった衣装と、処理中の衣装はスキップします。
- **Hierarchyで非アクティブな衣装も含める**をオンにすると、ワードローブでオフにしている衣装も事前に準備します。オフにすると、オフの衣装はアップロードするときだけ準備します。

### 準備結果の保存場所

| 保存するもの | 場所 |
| --- | --- |
| 濡れる位置・広がりの計算 | プロジェクトの`Library/RealWet` |
| 濡れシェーダーの準備結果 | `Assets/CookiTools/RealWetSystem/Generated` |

- Unityを起動し直しても、条件が同じなら再利用します。Unityを開き直した直後に、衣装の状態がまだ確認前のように表示されても、キャッシュが消えたという意味ではありません。
- キャッシュがない場合や壊れている場合は、必要な計算をやり直します。キャッシュファイルを手で直したり、先にフォルダーを削除したりする必要はありません。

### 再生（Play）するとき

再生ボタンを押したときに、着ている衣装の中にまだ準備ができていない衣装があると、<ProductName />は再生を少し待たせて、その衣装を準備します。

- 待っている間は、GameウィンドウとSceneウィンドウに<strong>衣装 N 件を準備しています。完了すると自動で再生が始まります。すぐに再生するには、再生ボタンをもう一度押してください。</strong>と表示されます。
- 準備が終わると、再生が自動で始まります。10分たつと、残っている衣装があっても再生を始めます。
- 再生ボタンをもう一度押すと、すぐに始まります。このとき、準備ができていない衣装はその再生でだけ濡れず、再生を終えると、その衣装から準備します。
- Hierarchyでオフにしている衣装（トグルでオンにする髪など）も、再生の前に準備します。着ている衣装を先に準備します。**Hierarchyで非アクティブな衣装も含める**をオフにすると、オフにしている衣装は待ちません。
- このUnityのセッションでまだ描画したことのない濡れシェーダーは、再生の前に2つずつに分けて先にコンパイルします。最初の再生中にシェーダーをまとめてコンパイルしないため、メモリの使用がずっと少なくなります。すでにコンパイルしたシェーダーは、もう一度コンパイルしません。
- 濡れシェーダーは、そのスロットで使わない機能を外してコンパイルします。見た目は同じで、シェーダーが小さくなり、コンパイルも速くなります。

## ゲーム内の負荷

- 濡れは、事前に計算したデータをシェーダーが読み取って描画します。開始点と保護範囲はUnityでの編集用で、ゲーム内にCollider、PhysBone、Contactを追加しません。
- ゲーム内メニューは、選んだ項目の分だけ同期パラメーターを使います。新しくインストールしたおすすめメニューは87ビット、すべての項目をオンにすると94ビットです（VRChatの上限は256ビット）。ダイヤルは8ビット、トグルは1ビットです。詳しい表は[ゲーム内メニュー](./usage/in-game-menu.mdx#sync-cost)にあります。
- **衣装ごとの違いを減らす**をオンにして、<strong>最大の濡れ範囲 (%)</strong>のダイヤルをメニューに入れると、FXに事前計算した補正クリップが増えます。同期ビットとゲーム内の計算は増えません。

## 容量と時間を減らす方法

1. 濡れる必要のないパーツは、**濡れ機能を使用**をオフにします。
2. 使わないゲーム内メニューの項目は、**RealWet > ゲーム内メニュー**で外し、**ゲーム内メニューを適用 / 更新**の後でビルドし直します。
3. 初回ビルドの前に、**必要な衣装のみ準備**で事前に準備しておきます。
4. d4rk Avatar Optimizerを使う場合は、シェーダーを書き換える設定をオフにしておきます。濡れるパーツがd4rkの結合から外れると、マテリアルの数が増えるためです。詳しくは、[互換性](./compatibility.mdx#optimizers)を確認してください。
