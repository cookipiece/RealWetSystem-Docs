# クイックスタート

このページは、おすすめの設定のままインストールしてアップロードするまでの、いちばん短い手順です。各オプションの意味は、[初心者チュートリアル](./tutorial.mdx)で説明します。

:::note[最初の1回は時間がかかります]
初めてプレビューするときや初めてビルドするときは、濡れシェーダーを作ってUnityがコンパイルするため、時間がかかります。衣装が多いと、数十分かかることがあります。2回目からは、ずっと速くなります。詳しくは[パフォーマンス](./performance.mdx#build-time)を確認してください。
:::

## 1. 準備

- アバターとプロジェクトをバックアップします。
- VCCの**Manage Project**で、**VRChat Avatars SDK**、**NDMF**、**Modular Avatar**がインストールされているか確認します。**VRCFury**を使う場合は、1.1436.0以上に更新してください。1.1258以下では、ビルドのときに`SweatAmount`のエラーが出ることがあります。
- 衣装が使うシェーダー（lilToon 2.3.0以上またはPoiyomi Toon / Pro 9以上）がプロジェクトにあるか確認します。Poiyomiの衣装だけを使う場合は、lilToonは必要ありません。
- Consoleに赤いコンパイルエラーがないか確認します。

## 2. パッケージをインポート

<ProductName />の`.unitypackage`をインポートします。Unityのインポートとコンパイルが終わるまで待ってください。

{/* SHOT U01: Unity top menu CookiTools > RealWetSystem */}
[![Unity上部メニューのRealWetSystem項目](/img/guide/U01-en.png)](/img/guide/U01-en.png)

*<small>Unity上部のメニューです。**CookiTools > RealWetSystem**に**Setup／Uninstall**、**Purchase Activation**、**Add or Update Clothing**があります。**Add or Update Clothing**は、Hierarchyで選んだ衣装を追加または更新します。</small>*

## 3. 購入認証

1. Unity上部のメニューから、**CookiTools > RealWetSystem > Purchase Activation**を開きます。
2. BOOTHの注文番号（Gumroadで購入した場合はGumroadのライセンスキー）を入力して、**認証する**を押します。
3. <strong>認証が完了しました。</strong>と表示されれば完了です。

{/* SHOT U02: Purchase Activation window */}
[![購入認証ウィンドウ（未認証）](/img/guide/U02-ja.png)](/img/guide/U02-ja.png)

PCごとに一度だけで済みます。詳しくは[購入認証](./license-activation.mdx)を確認してください。

## 4. インストール

1. アバターを配置したシーンを保存します。
2. Hierarchyで**アバターの最上位オブジェクト**（VRC Avatar Descriptorがあるオブジェクト）を選択します。
3. **CookiTools > RealWetSystem > Setup／Uninstall**を開きます。
4. 何も変えずに、4つの欄の下の**インストール**を押します。インストールしている間は、進行状況バーが表示されます。
5. **インストール完了**の案内が出たら、**OK**を押します。

{/* SHOT U03: Setup window, new install, defaults */}
[![インストール画面の全体](/img/guide/U03-ja.png)](/img/guide/U03-ja.png)

初期値のままインストールすると、次の内容が入ります。

- 汗をかく所（脇・胸・背中など）から濡れ、最大の濡れ範囲は40%です。
- 胸と股に、透け保護の範囲が4つ、体に合わせて入ります。
- 新しく追加する衣装は、上着だけが透け、下着は透けません。生地は綿・ニット・デニム、強さは標準です。
- アバターのメインメニューに、**濡れ**メニューが入ります（おすすめ構成、同期パラメーター87ビット。RealSweatSystemと一緒に使うアバターは88ビット）。

**1. 身体の登録**の**左胸の基準ボーン**・**右胸の基準ボーン**の欄には、自動で見つけたボーンが入っています。胸のボーンが違って検出されたときだけ、このアバターの胸のボーンを欄にドラッグします。[身体の登録](./tutorial.mdx#body)

## 5. 濡らす衣装を追加する

インストールの案内を閉じると、**RealWet 衣装を選ぶ**ウィンドウが開きます。いちばん上の<strong>おすすめどおり追加（N着）</strong>を押します。

{/* SHOT U14: outfit chooser */}
[![衣装選択ウィンドウ](/img/guide/U14-ja.png)](/img/guide/U14-ja.png)

- <ProductName />が衣装だと確信した衣装だけが追加されます。
- 漏れた衣装がある場合は、下の**自分で選ぶ**の一覧でチェックを入れて、**選んだ衣装を追加**を押します。
- 追加した衣装は、Ctrl+Zを1回押すと、すべて元に戻せます。
- アバターに最初から着せてある服がメッシュごとに別々に表示される場合は、[アバターの基本衣装は衣装単位でまとめる](./usage/outfit-settings.mdx#group-base-clothes)を確認してください。

## 6. プレビューで確認する

1. Hierarchyで衣装を1つ（衣装ルート）選択します。
2. Inspectorの**衣装全体の濡れプレビューを開始**を押します。
3. プレビューの濡れを<strong>0% → 50% → 100%</strong>に変えてみます。
4. 終わったら、**衣装全体のプレビューを停止**を押します。

{/* SHOT U19: outfit inspector with the preview */}
[![この衣装の設定](/img/guide/U19-ja.png)](/img/guide/U19-ja.png)

*<small>新規インストール直後の画面です。<strong>上着だけ透ける（下着は透けない）（推奨）</strong>で追加した衣装は、パーツごとに透け方が違うため、**濡れると透ける**が**パーツごとに個別**になっています。</small>*

プレビューが始まらない場合は、Unity上部の**Tools > NDM Framework > Enable Previews**がオンになっているか確認してください。

濡れる場所や透け保護の位置がアバターに合わない場合は、球を自分で動かしてください。[濡れる場所や透け保護の位置がアバターに合わない](./troubleshooting.mdx#placement-mismatch)

## 7. アップロードする

シーンを保存して、VRChat SDKで**Build & Test**またはアップロードを行います。準備ができていない衣装は、ビルドするときに自動で準備します。

VRChatでは、メインのラジアルメニューの**濡れ**を開いて、**濡れ量**を上げます。RealSweatSystemと一緒に使う場合は、汗の量に合わせて服も濡れます。

{/* SHOT M01: in-game main Wet page */}
[![ゲーム内の濡れメニュー](/img/guide/M01-ja.png)](/img/guide/M01-ja.png)

*<small>RealWetSystemだけをインストールしたおすすめ構成のメニューです。RealSweatSystemと連動すると、メインページに**RealSweat連動**と<strong>濡れ量（連動OFF時）</strong>が入ります。</small>*

:::info[ビルドは止まりません]
濡れを入れられなかった衣装だけが乾いたままアップロードされ、残りはそのまま濡れます。このとき、NDMFの結果ウィンドウに衣装名と理由が警告として残ります。[トラブルシューティング](./troubleshooting.mdx#ndmf-warnings)を確認してください。
:::
