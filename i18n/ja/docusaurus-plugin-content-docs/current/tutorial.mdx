# 初心者チュートリアル

このページは、<ProductName />を初めて使う方のための案内です。順番どおりに進めると、インストール画面のオプションが何を意味するか、衣装をどう選ぶか、VRChatで何を押せばよいかがわかります。早く終えたい場合は、[クイックスタート](./quick-start.mdx)だけを進めてもかまいません。

:::tip[最初は初期値のままにしてください]
インストール画面の初期値は、ほとんどのアバターに合うように決められています。インストールした後もすべての設定を変えられるので、最初は初期値のままインストールし、プレビューを見ながら1つずつ変えてください。
:::

## このドキュメントで使う言葉

| 言葉 | 意味 |
| --- | --- |
| **衣装ルート** | 服1着のいちばん上のオブジェクトです。シャツ・スカート・リボンのように一緒に着るメッシュが、その下にあります。 |
| **パーツ** | 衣装の中のメッシュ1つです。リボン、裏地、トップスなどです。 |
| **RealWetオブジェクト** | インストールするとアバターの下にできる`RealWet`オブジェクトです。アバター全体の設定がここにあります。 |
| **濡れの開始点** | 汗が始まる場所を表す球です。脇・胸・背中のような所にあります。 |
| **透け保護範囲** | 濡れても透けないように防ぐ球・カプセル・箱です。初期設定で胸と股に入ります。 |
| **同期パラメーター** | VRChatがほかの人にメニューの値を送るために使う容量です。アバター1体につき256ビットまで使えます。 |

## 1. 準備して購入認証する

1. アバターとプロジェクトをバックアップします。
2. VCCの**Manage Project**で、**VRChat Avatars SDK**（3.10.0以上）、**NDMF**（1.13.1以上）、**Modular Avatar**（1.14.0以上）を確認します。
3. 衣装が使うシェーダーがあるか確認します。lilToonの衣装にはlilToon 2.3.0以上、Poiyomiの衣装にはそのPoiyomiが必要です。
4. <ProductName />の`.unitypackage`をインポートし、インポートとコンパイルが終わるまで待ちます。
5. **CookiTools > RealWetSystem > Purchase Activation**を開き、BOOTHの注文番号（またはGumroadのライセンスキー）を入力してから、**認証する**を押します。

{/* SHOT U02: Purchase Activation window */}

- 認証はPCごとに1回です。インターネットは、認証するときと、自動更新のために3週間に1回以上必要です。
- 認証が必要なのは、新しいアバターで**インストール**を押すことだけです。衣装の追加、設定の変更、更新、アンインストールには必要ありません。
- 認証していないPCからアップロードすると、プレビューと再生（Play）では濡れて見えても、アップロードしたアバターでは効果が外れます。詳しくは[購入認証](./license-activation.mdx)を確認してください。

## 2. インストール画面を開く

1. アバターを配置したシーンを**保存**します。保存していない新しいシーンでは、インストールできない場合があります。
2. Hierarchyで**アバターの最上位オブジェクト**を選択します。Projectウィンドウのプレハブではなく、シーン内のアバターである必要があります。
3. Unity上部のメニューから**CookiTools > RealWetSystem > Setup／Uninstall**を開きます。

{/* SHOT U01: Unity top menu CookiTools > RealWetSystem */}
[![Unity 上部メニューの CookiTools > RealWetSystem](/img/guide/U01-en.png)](/img/guide/U01-en.png)

ウィンドウの上部には、**インストール** / **アンインストール**のタブと、**アバター**の欄があります。アバターの欄が空なら、**検出**を押すか、アバターをドラッグ＆ドロップします。アバターの欄の下に、現在の状態が1行で表示されます。

| 状態 | 意味 |
| --- | --- |
| **未インストール** | このアバターには、まだ<ProductName />がありません。下のボタンは**インストール**です。 |
| **インストール済み** | すでにインストールされています。下のボタンは**更新**で、保存された設定を読み込みます。 |
| **修復が必要** | インストールの一部がなくなっています。**更新**で直せます。 |
| **重複エラー** | 1つのアバターに`RealWet`オブジェクトが2つ以上あります。1つだけ残してください。 |

- インストール画面を開いただけでは、アバターは変わりません。選んだ内容は、**インストール**または**更新**を押したときに適用されます。
- <ProductName />は、**Humanoidのアバター**にだけ新しくインストールできます。Humanoidでない場合は、`ヒューマノイドのアバターではないため、RealWetSystemをインストールできません。`と表示されます。モデルのインポート設定の**Rig > Animation Type**を**Humanoid**に変えてから、もう一度インストールしてください。
- このPCで購入認証をしていない場合は、アバターの欄のすぐ下に、案内と**認証ウィンドウを開く**ボタンが表示されます。

{/* SHOT U10: Setup window notice on a PC that is not activated */}

## 3. インストール画面のオプション {/* #setup-options */}

インストールタブは、上から**1. 身体の登録**、**2. どこまで濡らしますか？**、**3. どこから濡らしますか？**、**4. 新しい衣装の濡れた見た目**の4つの欄と、折りたたまれた**連携とゲーム内メニュー**、**詳細設定**でできています。

{/* SHOT U03: Setup window, new install, defaults */}

### 3.1 身体の登録 {/* #body */}

濡れの計算に使う**肌メッシュ**を決めます。服が肌にどれだけ近いか、重ね着をどの順序で描画するかを計算するときに使います。

{/* SHOT U04: card 1. Body meshes */}

| オプション | 意味 | 初期値 |
| --- | --- | --- |
| **ボディ（肌メッシュ）** | アバターの体のメッシュです。 | 自動で見つけた体 |
| **ボディを自動検出** | 体のメッシュを探し直します。RealSweatSystemがある場合は、RSSに登録した体を優先して選びます。 | — |
| <strong>追加の肌メッシュ（0個）</strong> | 胴体・手・足が分かれているアバターで、残りの肌メッシュを入れます。ボディが1つなら空のままにします。 | 空 |
| **メッシュを追加** | 追加の肌メッシュの欄を1つ増やします。 | — |
| **RSSから取り込む** | RealSweatSystemに登録された肌の候補を取り込みます。実際に使う肌か確認してください。 | — |

- 衣装、髪、汗の表示用に作られたメッシュは入れないでください。
- オフにしているメッシュも、手動で入れると計算に含まれます。使わない差し替え用のボディは入れないでください。
- インストールした後は、**RealWet > 濡れ設定 > 身体メッシュ**で同じ一覧を直せます。

### 3.2 どこまで濡らしますか？ {/* #range */}

{/* SHOT U05: card 2. How far should it get wet? */}

| オプション | 意味 | 初期値 |
| --- | --- | --- |
| <strong>最大の濡れ範囲 (%)</strong> | 汗（濡れ量）が100%のときに、服がどこまで濡れるかを決めます。**衣装ごとの違いを減らす**がオンなら、水が届きうる部分のうち、おおよそこの割合だけ濡れます。40%なら、届く部分のおよそ40%です。 | **40%** |
| **衣装ごとの違いを減らす** | 体に張り付く服とゆったりした服の濡れる広さを、同じくらいにそろえます。早く濡れる服は遅らせ、遅く濡れる服は早めます。 | **オン** |
| **胸・股の透け保護領域を入れる** | このアバターの体に合わせたおすすめの保護範囲4つ（胸の左・右、股の前・後ろ）と、ゲーム内の**大事な部分の透け防止**トグル（+1ビット）を入れます。保護範囲も同じように濡れ、透けだけを防ぎます。 | **チェックあり** |

- 100%に上げても、汗が届かない所は濡れません。そのため、この値は服全体の面積の割合ではありません。
- **狭い**・**標準**・**広い**・**最大**のような段階は、インストールした後に**RealWet > 濡れ設定 > 濡れ具合を選択**で選びます。
- **胸・股の透け保護領域を入れる**をオフにすると、保護範囲もゲーム内のトグルも入れません。同期パラメーターが1ビット減り、シェーダーが少し軽くなります。透ける服を着る場合は、オンのままにすることをおすすめします。詳しくは[透け保護](./usage/see-through-protection.mdx)を確認してください。
- インストール済みのアバターを更新するときは、この場所に**重要部位の透け保護を最初からONにする**が表示されます。チェックを入れると、ゲームで保護がオンの状態で始まります。更新で保護範囲を新しく作ったり、変えたりすることはありません。

### 3.3 どこから濡らしますか？ {/* #start-mode */}

説明の付いた大きなボタン3つのうち、1つを押します。

{/* SHOT U06: card 3. Where should wetness start? */}

| 選択 | 見える結果 | こんなときに選びます |
| --- | --- | --- |
| <strong>汗をかく所から（おすすめ）</strong> | 脇・胸・背中などの汗のポイント（濡れの開始点）から広がります。 | 初めてインストールするとき。汗で濡れた見た目にしたいとき |
| **体に触れる所から** | 服が肌に張り付いている部分から濡れます。 | 体に張り付く服の密着感を出したいとき |
| **両方** | 汗のポイントから始まり、体に触れる所に沿って広がります。 | 2つの方式を併用したいとき |

- 新規インストールの初期値は、<strong>汗をかく所から（おすすめ）</strong>です。
- ボタンの下に、胸の基準ボーンが1行で表示されます（例: **胸の基準ボーン: 自動で見つかりました**）。**変更**を押すと、自分で選べます。胸のボーンがないアバターでは、胴体を基準に置きます。
- 雨に当たったように服全体を均一に濡らしたい場合は、ここで選ぶのではなく、ゲーム内メニューの**全範囲濡れ**をオンにします。[全範囲濡れ](./usage/in-game-menu.mdx#whole-area)を確認してください。
- 開始点の位置は、インストールした後に[濡れの開始点](./usage/wet-start-points.mdx)で動かせます。

### 3.4 新しい衣装の濡れた見た目 {/* #new-outfit-look */}

これから新しく入れる衣装が、どのように濡れるかを決めます。登録済みの衣装は変わりません。

{/* SHOT U07: card 4. How new outfits look when wet, popup open */}

| オプション | 選択肢 | 初期値 |
| --- | --- | --- |
| **濡れると透ける** | **すべて透けない**: どのパーツも透けず、色と光沢だけが変わります。<br />**すべて透ける**: すべてのパーツが、濡れると自然に透けます。<br /><strong>上着だけ透ける（下着は透けない）（推奨）</strong>: 内側に着た服と、判定があいまいな服は透けず、外側に着ていることが確実な服だけが透けます。 | <strong>上着だけ透ける（下着は透けない）（推奨）</strong> |
| **生地・強さ** | **変更**を押すと、生地の種類と濡れた感じの強さを選ぶ欄が開きます。生地は<strong>綿・ニット・デニム（おすすめ）</strong>、**ポリエステル・サテン・水着**、**ラテックス・ビニール・エナメル**、**中間**です。強さは**控えめ**、**標準**、**強め**です。 | <strong>綿・ニット・デニム（おすすめ）</strong>、**標準** |

- 髪と、帽子・メガネのように頭に着けるパーツは、どの選択でも自動では透けるようにしません。透けるようにするには、そのパーツで自分で選んでください。
- **透けなし**は、<ProductName />が加える透けだけをオフにします。もともと透明なレースの穴を埋めることはありません。
- 生地と強さの違いは、[濡れ設定](./usage/wet-settings.mdx#look)で図と一緒に説明します。

### 3.5 連携とゲーム内メニュー {/* #menu-options */}

折りたたまれた**連携とゲーム内メニュー**を押すと開きます。VRChatのメニューに入れるボタンを選びます。新規インストールでは、おすすめ構成に最初からチェックが入っているので、変えなくてもかまいません。

{/* SHOT U08: Linking & in-game menu expanded */}

| オプション | 意味 | 新規インストールの初期値 | 同期容量 |
| --- | --- | --- | --- |
| **開始時の入力** | RealSweatSystemがあるときだけ表示されます。**RSSの汗量に連動**をオンにすると、服が肌の汗に合わせて濡れます。オフにすると、<ProductName />の濡れ量だけで調整します。 | 連動 | — |
| **推奨ゲーム内メニューを復元** | チェックをすべておすすめ構成に戻します。 | — | — |
| **全体の衣装濡れ表示を搭載** | ゲーム内の**衣装の濡れを表示**トグルを入れます。 | チェックあり | 1ビット（単独モードでは基本操作に含まれます） |
| <strong>大事な部分の透け防止を一括ON/OFF</strong> | ゲーム内の**大事な部分の透け防止**トグルを入れます。**胸・股の透け保護領域を入れる**をオフにすると、オフのままロックされます。 | チェックあり | 1ビット |
| <strong>透け防止の範囲（50%=標準）</strong> | 保護範囲が防ぐ広さを変えるダイヤルです。 | チェックあり | 8ビット |
| <strong>透け防止の強さ（100%=完全に防ぐ）</strong> | 保護範囲が防ぐ度合いを変えるダイヤルです。 | チェックあり | 8ビット |
| **濡れ状態固定トグルを搭載** | ゲーム内の<strong>現在の状態を固定（撮影用）</strong>を入れます。今の濡れた見た目を止めます。 | チェックあり | 1ビット |
| <strong>高速乾燥を搭載（+1bit）</strong> | ゲーム内の**高速乾燥**を入れます。オンの間は新しい汗を受け付けず、4秒ほどでほぼ乾きます。 | チェックあり | 1ビット |
| <strong>濡れる範囲を広げる（上級者向け）</strong> | 同じ濡れ量で、薄い濡れをより遠くまで広げるダイヤルです。 | チェックあり | 8ビット |
| <strong>濡れ表現（50%=標準）</strong> | 濡れた色・彩度・透けの強さを変えるダイヤルです。 | チェックあり | 8ビット |
| <strong>濡れ光沢 (50%=標準)</strong> | <ProductName />が加える光沢だけを変えるダイヤルです。 | チェックあり | 8ビット |
| <strong>濡れの境界：くっきり ↔ なめらか</strong> | 乾いた所と濡れた所の境界を変えるダイヤルです。 | チェックあり | 8ビット |
| <strong>透け強度（50%=標準）</strong> | 濡れて生じる透けだけを変えるダイヤルです。 | チェックあり | 8ビット |
| <strong>最大の濡れ範囲 (%)</strong> | 上の3.2の範囲を、ゲーム内で変えるダイヤルです。 | チェックあり | 8ビット |
| **濡れ透けモード** | **設定どおり** / **濡れた部分を強制的に透過** / **透けなし**を選ぶメニューです。 | チェックあり | 8ビット |
| **SSAO・影の軽減** | 透ける服の後ろの黒い陰影を減らす機能を、オン・オフするトグルです。 | チェックあり | 1ビット |
| **全範囲濡れ** | オンにすると、服全体が均一に濡れるトグルです。 | チェックあり | 1ビット |
| **衣装ごとの違いを減らす** | 上の3.2の機能を、ゲーム内でオン・オフするトグルです。 | オフ | 1ビット |
| **単独モードの自分にのみ表示を搭載** | RealSweatSystemなしで使うときだけ、**自分にのみ表示**トグルを入れます。 | チェックあり | 1ビット |

- メニューに入れるチェックは、**ボタンを入れるためのもの**です。その機能を最初からオンにするかどうかとは別です。たとえば**衣装ごとの違いを減らす**は、機能そのものはオンですが、ゲーム内のボタンは初期設定では入れません。
- 下の**最終同期コスト**の概要で、合計を確認します。おすすめ構成は**87ビット**で、衣装別表示のグループまですべて入れると94ビットです。VRChatの上限は、アバター全体で256ビットです。
- **濡れ**メニューは、RealSweatSystemのメニューとは別に、アバターのメインメニューに入ります。場所は、インストールした後に`RealWet`オブジェクトの**MA Menu Installer**で変えられます。
- メニューの構成は、インストールした後に**RealWet > ゲーム内メニュー**でも変えられます。各ボタンの動きは、[ゲーム内メニュー](./usage/in-game-menu.mdx)で説明します。

### 3.6 詳細設定 {/* #advanced-options */}

折りたたまれた**詳細設定**を押すと開きます。ふつうは変える必要はありません。

{/* SHOT U09: Advanced settings expanded */}

| オプション | 意味 | 初期値 |
| --- | --- | --- |
| **Write Defaults** | <ProductName />が作るアニメーションのWrite Defaultsです。**自動**は、アバターのFXを読んで合わせます。アバターの制作者が特定の値を求めるときだけ、ON/OFFを自分で選びます。 | **自動** |
| <strong>新しい衣装を自動検出（推奨）</strong> | インストールした後にアバターへ入れた衣装を見つけて登録します。インストールのときにすでに着せていた衣装は、衣装を選ぶウィンドウで選びます。 | **オン** |
| <strong>透明な濡れ衣装の自然な深度・影遷移（推奨）</strong> | 濡れて透ける服の後ろの体に、SSAOのような黒い陰影が残りにくくします。同期パラメーターは使いません。 | **オン** |
| **実験機能** | このPCにPCSS4VRC（lilToon）かlilSSRTがあるときだけ表示されます。そのシェーダーを使う衣装も濡れるようにします。[高度な機能](./advanced.mdx#experimental)を確認してください。 | **オフ** |
| **インストール前の確認** | 今選んでいる内容（身体、最大の濡れ範囲、濡れの開始、新しい衣装の透け、生地・強さ）をまとめて表示します。 | — |

### 3.7 他のアバターツール {/* #other-tools */}

アバターに、濡れを消してしまう可能性のある他のツールの設定がある場合は、インストールボタンの上に**他のアバターツール**の欄が表示されます。知らせることがなければ、この欄は表示されません。

- 例: d4rk Avatar Optimizerのシェーダーを書き換える設定がオンになっている場合は、短い案内と**d4rk の設定を表示**ボタンが表示されます。ボタンはd4rkのコンポーネントを選択して表示するだけで、設定は変えません。
- 詳しくは[互換性](./compatibility.mdx#optimizers)を確認してください。

### 3.8 インストール

**インストール**を押します。**インストール完了**の案内が表示されたら、**OK**を押します。

{/* SHOT U12: Installation Complete dialog */}

- インストールすると、アバターの下に`RealWet`オブジェクトができます。このオブジェクトに、アバター全体の設定があります。
- 最初のインストールとアンインストール、ゲーム内メニューの作成は、Ctrl+Zで元に戻せません。インストールした後の設定の変更は、Ctrl+Zで元に戻せます。
- このPCにPCSS4VRC（lilToon）かlilSSRTがある場合は、最初のインストールのときに、実験機能をオンにするか一度だけ確認します。よくわからなければ、**使用しない**を選んでもかまいません。あとから**詳細設定 > 実験機能**で変えられます。

## 4. 濡らす衣装を選ぶ {/* #outfit-chooser */}

インストールの案内を閉じると、**RealWet 衣装を選ぶ**ウィンドウが開きます。アバターで見つかった衣装の一覧が表示されます。

{/* SHOT U14: outfit chooser */}

| ボタン | すること |
| --- | --- |
| <strong>おすすめどおり追加（N着）</strong> | <ProductName />が衣装だと確信した衣装だけを、まとめて追加します。確認が必要な衣装は追加しません。 |
| **自分で選ぶ** | 一覧で、濡らす衣装にチェックを入れます。確実な衣装は最初からチェックが入っていて、確認が必要な衣装は短い理由とともに、チェックなしで表示されます。 |
| **探す** | 行ごとにあります。Hierarchyでその衣装を選択して表示します。 |
| **選んだ衣装を追加** | チェックを入れた衣装を追加します。 |
| **あとで** | 何も追加せずに、ウィンドウを閉じます。 |

確認が必要な衣装には、次のような理由が付きます。

| 理由 | 意味 |
| --- | --- |
| 体や顔のメッシュが混ざっている可能性があります。 | そのオブジェクトの下に、体や顔のメッシュがある可能性があります。 |
| 複数の衣装がひとまとめになっている可能性があります。 | 何着も入った空オブジェクトの可能性があります。1着ずつ追加するほうがよいです。 |
| アクセサリーのようです。 / 衣装かどうか確実ではありません。 | 濡らす必要のない小物の可能性があります。 |

- このウィンドウは、Unityの操作を止めません。ウィンドウを開いたまま、HierarchyとSceneを見られます。
- 追加した衣装は、Ctrl+Zを1回押すとすべて元に戻せます。
- あとから衣装を追加するには、**RealWet > 衣装管理**の**今すぐ検索**（同じウィンドウが開きます）または**手動で追加**を使います。[衣装設定](./usage/outfit-settings.mdx)を確認してください。

:::warning[衣装は身体メッシュの外に置いてください]
衣装ルートを、ボディ・顔のメッシュオブジェクトの中に入れないでください。アバターの直下、または身体メッシュとは別の空オブジェクトの下に置く構成をおすすめします。顔として使うメッシュの中に入れた衣装は、登録されないことがあります。
:::

## 5. プレビューで確認する {/* #preview */}

1. Hierarchyで衣装ルートを選択します。Inspectorに**この衣装の設定**が表示されます。
2. **衣装全体の濡れプレビューを開始**を押します。初回は、準備の段階が終わってから始まります。
3. プレビューの濡れスライダーを<strong>0% → 50% → 100%</strong>に変えてみます。▶ボタンを押すと、少しずつ濡れていく様子が再生されます。
4. 服全体が均一に濡れた見た目を見るには、スライダーの下の<strong>全範囲濡れ（ゲーム内メニュー）</strong>にチェックを入れます。プレビューにだけ使われ、保存された設定は変わりません。
5. 終えるときは、**衣装全体のプレビューを停止**を押します。

{/* SHOT U19: outfit inspector with the preview running */}
{/* SHOT R01: dry · 50 % · 100 %, default mode */}

確認すること:

- **前・横・後ろ**から、濡れる所が自然か確認します。汗をかく所から濡れるので、40%では袖やスカートの裾が乾いたまま残るのが正常です。
- 透ける服は、<strong>100%</strong>で胸と股が透けないか確認します。透け保護範囲も濡れますが、透けはしません。
- 思ったより濡れない場合は[濡れ設定](./usage/wet-settings.mdx#range)の**最大の濡れ範囲**を、濡れる場所が不自然な場合は[濡れの開始点](./usage/wet-start-points.mdx)を確認します。

:::note[プレビューが始まらないとき]
Unity上部の**Tools > NDM Framework > Enable Previews**がオンになっているか、Play Modeでないかを確認してください。開始ボタンを何度も押す必要はありません。Inspectorに現在の段階が表示されます。
:::

プレビューは、現在のポーズでの見た目を表示します。動きとゲーム内メニューは、Build & Testで確認してください。

## 6. ゲーム内メニューを知っておく {/* #in-game-menu */}

インストールすると、アバターのメインのラジアルメニューに**濡れ**メニューが入ります。おすすめ構成のメニューは、次のとおりです。

{/* SHOT M01: main Wet page */}

### 濡れ（メインページ）

| ボタン | VRChatでの働き | 最初の値 |
| --- | --- | --- |
| **衣装の濡れを表示** | すべての衣装の濡れた見た目を、表示するか隠します。隠しても、濡れたり乾いたりする状態は進みます。 | オン |
| **濡れ量** | 服がどれだけ濡れるかを決めます。上げると設定した速さで濡れ、下げると少しずつ乾きます。RealSweatSystemなしで使うときに表示されます。 | 0% |
| **RealSweat連動** | RealSweatSystemと一緒に使うときに表示されます。オンにしておくと、服が肌の汗の量に合わせて濡れます。 | オン |
| <strong>濡れ量（連動OFF時）</strong> | RealSweatSystemと一緒に使うときに表示されます。連動をオフにすると、このダイヤルで服だけを別に濡らします。 | 0% |
| **濡れ調整** | ダイヤルがまとまったサブメニューです。下の表を確認してください。 | — |
| **高速乾燥** | オンの間は新しい汗を受け付けず、服を素早く乾かします。また濡れるようにするには、オフにしてください。 | オフ |
| <strong>現在の状態を固定（撮影用）</strong> | 今の濡れた見た目を、そのまま止めます。写真を撮るときに使います。 | オフ |
| **自分にのみ表示** | RealSweatSystemなしで使うときに表示されます。オンにすると、服の濡れた見た目が自分にだけ見えます。 | オフ |
| **透け防止** | 透け防止のスイッチとダイヤルがまとまったサブメニューです。下の表を確認してください。 | — |
| **全範囲濡れ** | オンにすると、雨に当たったように服全体が均一に濡れます。オフにすると、Unityで決めたとおり（汗をかく所からなど）に濡れます。 | オフ |

### 濡れ > 濡れ調整

{/* SHOT M02: Wet Tuning page */}

| ダイヤル | VRChatでの働き | 最初の値 |
| --- | --- | --- |
| <strong>濡れる範囲を広げる（上級者向け）</strong> | 同じ濡れ量で、薄い濡れをより遠くまで広げます。0%は設定どおりです。 | 0% |
| <strong>濡れ表現（50%=標準）</strong> | 濡れた色・彩度・透けの強さです。50%が、Unityで決めた見た目です。 | 50% |
| <strong>濡れ光沢 (50%=標準)</strong> | <ProductName />が加える光沢だけを変えます。0%は追加の光沢なし、100%は2倍です。 | 50% |
| <strong>濡れの境界：くっきり ↔ なめらか</strong> | 乾いた所と濡れた所の境界です。0%はくっきり、100%は広くなめらかになります。 | 50% |
| <strong>透け強度（50%=標準）</strong> | 濡れて生じる透けだけを変えます。0%は透けなし、100%は意図的に強く透けます。 | 50% |
| **濡れ透けモード** | **設定どおり**、**濡れた部分を強制的に透過**、**透けなし**から選びます。 | 設定どおり |
| **SSAO・影の軽減** | 透ける服の後ろの黒い陰影を減らす機能です。 | オン |
| <strong>最大の濡れ範囲 (%)</strong> | 服がどこまで濡れるかを決めます。インストール画面の値で始まります。 | 40% |

### 濡れ > 透け防止

{/* SHOT M03: See-Through Protection page */}

| ボタン | VRChatでの働き | 最初の値 |
| --- | --- | --- |
| **大事な部分の透け防止** | 胸・股などの保護範囲の透け防止を、一度にオン・オフします。オフにすると、その場所も透けます。保存されないため、アバターを読み込み直すと最初の値に戻ります。 | オン |
| <strong>透け防止の範囲（50%=標準）</strong> | 保護が防ぐ広さです。50%はUnityで見える大きさのまま、0%はほとんど防がず、100%はより広く防ぎます。 | 50% |
| <strong>透け防止の強さ（100%=完全に防ぐ）</strong> | 保護が防ぐ度合いです。100%は完全に防ぎ、50%は防がないときの透けの約3分の1が見え、0%は防ぎません。 | 100% |

- ほとんどのダイヤルとトグルは保存され、次に入ったときに、最後に選んだ値が使われます。**高速乾燥**、<strong>現在の状態を固定（撮影用）</strong>、**大事な部分の透け防止**は保存されず、アバターを読み込むたびに最初の値に戻ります。
- ボタン名は、メニューを作ったときの<ProductName />の言語（English / 한국어 / 日本語）で付きます。VRChatの言語設定では変わりません。
- 詳しくは、[ゲーム内メニュー](./usage/in-game-menu.mdx)と[透け保護](./usage/see-through-protection.mdx)を確認してください。

## 7. アップロードしてVRChatで確認する

1. シーンを保存します。
2. VRChat SDKで**Build & Test**またはアップロードを行います。準備ができていない衣装は、ビルドのときに自動で準備します。アップロード中は、`RealWet: …`の進行状況が表示されます。
3. VRChatで**濡れ > 濡れ量**を0%、50%、100%に変えてみます。RealSweatSystemと一緒に使う場合は、汗の%を変えます。
4. 透ける服なら、**濡れ > 透け防止**のダイヤルも動かしてみます。

:::note[初めてのビルドは時間がかかります]
初めてビルドするときは、濡れシェーダーを作ってUnityがコンパイルするため、ウィンドウがほとんど動かないまま数十分かかることがあります。止まったように見えても、CPUを使っているなら待ってください。[最初のビルドに時間がかかる](./troubleshooting.mdx#long-first-build)を確認してください。
:::

:::info[ビルドは止まりません]
濡れを適用できなかった衣装だけが乾いたままアップロードされ、NDMFの結果ウィンドウに理由が警告として残ります。残りの衣装は、そのまま濡れます。[NDMFの警告](./troubleshooting.mdx#ndmf-warnings)を確認してください。
:::
