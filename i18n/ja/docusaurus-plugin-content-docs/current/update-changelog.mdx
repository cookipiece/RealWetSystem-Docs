# 更新履歴

このページでは、<ProductName />のバージョンごとの主な変更を、新しい版から順にまとめています。新しい版に切り替える前に、下の更新の方法を先に確認してください。

## 更新の方法 {/* #how-to-update */}

1. 更新する前に、アバターとプロジェクトをバックアップしてください。
2. `Assets/CookiTools/RealWetSystem`フォルダーは削除しません。新しいパッケージを、その上にそのままインポートしてください。先にアンインストールする必要はありません。
3. インポートすると、<ProductName />が古い版にだけあったファイルをシステムのごみ箱に移し、コンソールに1行で知らせます。手動で入れたファイルと、新しいパッケージが使うファイルには触れません。
4. インポートした直後にConsoleに赤いエラーが残っている場合は、Unityを一度再起動してください。
5. **CookiTools > RealWetSystem > Setup／Uninstall**で、アバターごとに**更新**を押します。保存された開始点の配置が新しいおすすめの配置と違う場合は、**発汗位置をリセット** / **既存の設定を維持**を確認します。よくわからない場合は、**既存の設定を維持**を選んでください。

{/* SHOT U13: update dialog Reset Wet Start Points / Keep Current Settings */}

6. 更新した後、最初にプレビューまたはビルドするときは、濡れシェーダーを準備し直すため、1回だけ余分に時間がかかります。
7. ゲーム内メニューの名前や項目が変わった版では、**更新**か**ランタイムメニューを適用 / 更新**を押してから、ビルドし直してください。アップロード済みのアバターは、アップロードし直すと新しい版が適用されます。

- 保存された設定、開始点、保護範囲はそのまま残ります。新しいおすすめの保護の形を使うには、[更新した後の保護範囲](./usage/see-through-protection.mdx#after-update)を確認してください。
- 手を加えていない以前の標準の見た目だけが、1回だけ新しい標準の見た目に変わります。このとき、**RealWet > 衣装管理**にお知らせと<strong>元に戻す…</strong>が表示されます。インストール画面の**更新時に新しい標準に変更する**をオフにして更新すると、変わりません。
- アバターごとに作るメニューファイルは、パッケージのフォルダーの外にある`Assets/CookiTools/Generated/RealWet`にあるため、パッケージを上書きしても消えません。
- 更新には購入認証は必要ありません。ただし、認証していないPCからアップロードすると効果が外れるため、アップロードするPCで[購入認証](./license-activation.mdx)をしておいてください。

## 1.0.0 — 初公開版 {/* #100 */}

<ProductName />の最初の公開版です。

### 含まれるもの

- **インストール画面:** **CookiTools > RealWetSystem > Setup／Uninstall**で、身体の登録、最大の濡れ範囲、濡れ始める方式、新しい衣装の濡れた見た目を選んで、**インストール**を押します。オプションの意味は、[初心者チュートリアル](./tutorial.mdx#setup-options)にあります。
- **購入認証:** 新しくインストールするときに、PCごとに一度、購入認証が必要です。メニューは**CookiTools > RealWetSystem > Purchase Activation**です。認証していないPCからアップロードすると効果が外れますが、ビルドは止まらず、プレビューと再生ではそのまま表示されます。[購入認証](./license-activation.mdx)
- **衣装を選ぶウィンドウ:** インストールの案内を閉じると、濡らす衣装を選ぶウィンドウが開きます。<strong>おすすめどおり追加（N着）</strong>を1回押すと確実な衣装をすべて追加でき、**自分で選ぶ**で1つずつ選ぶこともできます。このウィンドウはUnityの操作を止めません。
- **濡れ方:** 服は、汗をかく所や体に触れる所から濡れます。濡れた部分は色が深くなり、しわに沿って水の光沢が出て、薄い服は透けます。生地（綿・ニット・デニム、ポリエステル・サテン・水着、ラテックス・ビニール・エナメル、中間）と強さ（控えめ、標準、強め）を選びます。<strong>衣装ごとに均一に濡れて見えるようにする（新しい見た目）</strong>が、初期設定でオンになっています。
- **lilToonとPoiyomi:** lilToon 2.3.0以上と、Poiyomi Toon / Pro（ロックされたマテリアルを含みます）が、同じ見た目で濡れます。
- **透け保護:** 新規インストールでは、胸・股のおすすめの保護範囲4つが、体に合わせて入ります。保護範囲も濡れ、濡れて生じる透けだけを防ぎます。乳首のシェイプキー、胸のボーン、胴体の順に位置を探すため、胸が平らなアバターにも置けます。[透け保護](./usage/see-through-protection.mdx)
- **ゲーム内メニュー:** アバターのメインメニューに、**濡れ**（韓国語は젖음、英語はWet）メニューが入ります。**濡れ量**、**衣装の濡れを表示**、**全範囲濡れ**、**高速乾燥**、<strong>現在の状態を固定（撮影用）</strong>、**濡れ調整**のダイヤル、**透け防止**ページの**大事な部分の透け防止**スイッチと、**透け防止の範囲**・**透け防止の強さ**のダイヤルがあります。おすすめ構成は、同期パラメーター87ビットです。[ゲーム内メニュー](./usage/in-game-menu.mdx)
- **濡れの開始点と保護範囲のエディター:** <strong>濡れ・保護範囲を編集…</strong>で、球を動かし、サイズと広がりを変え、左右ペアを作ります。選んだ球の影響が、体と服に色で表示されます。[濡れの開始点](./usage/wet-start-points.mdx)
- **RealSweatSystemとの連動:** 一緒に使うと、肌の汗の量に合わせて服も濡れます。RealSweatSystemの汗の表示は肌の汗にだけ適用され、衣装の濡れは**衣装の濡れを表示**で隠します。
- **RealRainSystemとの連動:** 一緒に使うと、雨に当たった服も濡れ、雨粒・水の筋が同じ服の上に描かれます。
- **ビルドは止まりません:** 濡れを入れられなかった部分だけが元の乾いたマテリアルでアップロードされ、NDMFの結果ウィンドウに衣装名と理由が警告として残ります。アップロード中は、<ProductName />の段階が進行表示に出ます。
- **最適化ツール:** AAO、d4rk Avatar Optimizer、TexTransTool、VRCFuryと一緒にビルドしても、濡れが残ります。濡れが消えるおそれのある設定は、インストール画面の**他のアバターツール**欄で事前に知らせます。[互換性](./compatibility.mdx#optimizers)
- **実験機能:** PCSS4VRC(lilToon)とlilSSRTを使う衣装も濡らせます。インストール画面の**詳細設定 > 実験機能**で、アバターごとにオンにします（初期値はオフ）。[高度な機能](./advanced.mdx#experimental)
- **編集中に止まりにくく:** 事前の準備は、Unityが後ろに回っているときだけ行います。登録した衣装を編集するときにUnityが数秒ずつ止まらないよう、計算を分けて行います。
- **言語:** 画面とゲーム内メニューの名前は、English / 한국어 / 日本語 から選べます。

### 既知の制限

- PC専用です。Quest・モバイルには対応していません。
- 購入認証は、Windowsでしかできません。Mac・LinuxのUnityからアップロードすると、<ProductName />の効果が外れます。
- 新規インストールは、Humanoidのアバターにだけできます。
- 異なる衣装どうしの重ね着の描画順は決めません。[重ね着の順序](./usage/outfit-settings.mdx#layer-order)を確認してください。
- SeeThroughHairがビルド中にシェーダーを変える半透明の髪のコピーは、濡れません。残りの髪は濡れます。
- アニメーションでレンダラーのメッシュそのものを切り替える構成には、対応していません。

そのほかの制限は、[技術仕様](./technical-specifications.mdx#known-limits)にあります。
