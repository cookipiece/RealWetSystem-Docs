# ゲーム内メニュー

**濡れ**メニュー（韓国語は**젖음**、英語は**Wet**）は、初期設定では、アバターのメインのラジアルメニューに独立して入ります。このページでは、メニューの構成と各ボタンの働き、メニューを変える方法を説明します。

{/* SHOT M01: main Wet page */}

## メニューの構成 {/* #layout */}

おすすめ構成（新規インストール）のメニューは、次のとおりです。選ばなかったボタンは入りません。

| 場所 | 入るもの |
| --- | --- |
| **濡れ**（メインページ） | **衣装の濡れを表示**、**濡れ量**（RealSweatと一緒に使う場合は**RealSweat連動**と<strong>濡れ量（連動OFF時）</strong>）、**濡れ調整**、**高速乾燥**、<strong>現在の状態を固定（撮影用）</strong>、**自分にのみ表示**（単独モード）、**透け防止**、**全範囲濡れ** |
| **濡れ > 濡れ調整** | <strong>濡れる範囲を広げる（上級者向け）</strong>、<strong>濡れ表現（50%=標準）</strong>、<strong>濡れ光沢 (50%=標準)</strong>、<strong>濡れの境界：くっきり ↔ なめらか</strong>、<strong>透け強度（50%=標準）</strong>、**濡れ透けモード**、**SSAO・影の軽減**、<strong>最大の濡れ範囲 (%)</strong> |
| **濡れ > 透け防止** | **大事な部分の透け防止**、<strong>透け防止の範囲（50%=標準）</strong>、<strong>透け防止の強さ（100%=完全に防ぐ）</strong> |
| **濡れ > 衣装別表示** | 衣装グループごとに濡れた見た目を隠すトグル（グループを作った場合のみ） |

- 1ページは8枠です。**濡れ調整**に項目が9個以上ある場合は、7個の後に**次へ**ができ、残りはその中に続きます。
- メインページがすべて埋まっている場合、**全範囲濡れ**は**濡れ調整**の最初の枠に入ります。
- 透け防止のダイヤルを入れない場合は、**透け防止**ページの代わりに、**大事な部分の透け防止**トグルがメインページに直接入ります。

## 各ボタンの働き {/* #items */}

### 濡れ量と連動

| インストールの状態 | 使うボタン |
| --- | --- |
| <ProductName />だけ | **濡れ量**で、服がどれだけ濡れるかを決めます。 |
| RealSweatSystemもあり、**RealSweat連動**がオン | 服が、肌の最終的な汗の量に従って濡れます。 |
| RealSweatSystemもあり、**RealSweat連動**がオフ | <strong>濡れ量（連動OFF時）</strong>で、服だけを別に調整します。 |

- 連動中は、濡れ量のダイヤルがRSSの汗の量に追従します。手で動かしてもRSSの値に戻ります。連動をオフにすると、最後に追従した値から調整できます。
- <ProductName />のダイヤルが、RSSの汗の量を変えることはありません。
- 量を変えても、服は設定された速さで濡れたり乾いたりします。すぐに変わらないのは正常です。

:::tip[RSSの自動モードが0%のときに、服だけを濡らすには]
**RealSweat連動**をオフにして、<strong>濡れ量（連動OFF時）</strong>を上げてください。連動を切り替えても、すでに濡れている状態がすぐに初期化されることはありません。
:::

### メインページのトグル

| ボタン | 働き | 初期値 | 保存 |
| --- | --- | --- | --- |
| **衣装の濡れを表示** | すべての衣装の濡れた見た目を、表示するか隠します。隠しても濡れたり乾いたりする状態は進むため、もう一度オンにすると、残っている濡れが見えます。 | オン | 保存する |
| **高速乾燥** | オンの間は新しい汗を受け付けず、服を約4秒でほぼ乾かします。また濡らすには、オフにしてください。 | オフ | 保存しない |
| <strong>現在の状態を固定（撮影用）</strong> | 今の濡れた見た目を、そのまま止めます。 | オフ | 保存しない |
| **自分にのみ表示** | <ProductName />だけを使うときに表示されます。オンにすると、服の濡れた見た目が自分にだけ見えます。 | オフ | 保存する |
| **全範囲濡れ** | オンにすると、服全体が均一に濡れます。下の[全範囲濡れ](#whole-area)を確認してください。 | オフ | 保存する |

RealSweatSystemの**汗の表示**と**自分にだけ表示**は、肌の汗にだけ適用されます。衣装の濡れは隠さず、ほかの人にも見えます。衣装の濡れを隠すには、**衣装の濡れを表示**か衣装別表示をオフにしてください。

### 濡れ調整のダイヤル {/* #tuning */}

| ダイヤル | 変わるもの | 目安 |
| --- | --- | --- |
| <strong>最大の濡れ範囲 (%)</strong> | 濡れが広がる最大の範囲 | 初期値はUnityの設定です（新規インストールは40%）。服全体の面積の割合ではありません。 |
| <strong>濡れる範囲を広げる（上級者向け）</strong> | 同じ濡れ量で、薄い濡れが広がる距離 | 0%は設定どおり、100%は最大まで広げます。すでに濡れきった所は、それ以上広げません。 |
| <strong>濡れ表現（50%=標準）</strong> | 濡れた色・彩度・透けの強さ | 50%が設定どおりです。光沢は別に調整します。 |
| <strong>濡れ光沢 (50%=標準)</strong> | <ProductName />が加える濡れた反射 | 0%は追加の光沢なし、100%は2倍です。元のマテリアルの反射はそのままです。 |
| <strong>濡れの境界：くっきり ↔ なめらか</strong> | 乾いた所と濡れた所の間の移り変わり | 50%がUnityで決めた境界、0%はずっとくっきり、100%は広くなめらかになります。保護範囲の境界は変わりません。 |
| <strong>透け強度（50%=標準）</strong> | 濡れて加わる透けだけ | 0%は追加の透けなし、100%は意図的に強く透けます（あまり濡れていない所や暗い服も、より早く透けます）。 |

**50%=標準**は、元のマテリアルを50%だけ見せるという意味ではありません。50%が、Unityで設定した見た目です。

{/* SHOT R10: Wet Edge 0 / 50 / 100 % at wetness 50 % */}

:::tip[色は濃く、光沢は弱く]
**濡れ表現**を上げて、**濡れ光沢**を下げてください。光沢だけを変えても、濡れた色・透けや、濡れる位置は変わりません。
:::

### 濡れ透けモード {/* #see-through */}

| 選択 | 結果 |
| --- | --- |
| **設定どおり**（初期値） | パーツごとに決めた透け方を使います。 |
| **濡れた部分を強制的に透過** | 厚手の生地・暗い生地も、濡れた部分が透けるようにします。保護範囲はそのまま防ぎます。 |
| **透けなし** | <ProductName />が加えた透けをオフにします。濡れた色・光沢と、元のマテリアルの透明度は残ります。 |

{/* SHOT R05: As Configured / Force See-Through When Wet / No See-Through */}

もともと透明なレースや、ディゾルブで消えた部分を埋める機能ではありません。**透けなし**モードや保護範囲では、透け強度を上げても透けは出ません。

### SSAO・影の軽減

初期値はオンです。各パーツに設定した、透けた部分の陰影の軽減を使います。オフにすると、<ProductName />が加えた軽減だけがオフになります。元のシェーダーのSSAO・影の設定は変えません。

### 透け防止ページ {/* #protection */}

| ボタン | 働き | 初期値 | 保存 |
| --- | --- | --- | --- |
| **大事な部分の透け防止** | オンにしているすべての保護範囲の透け防止を、一度にオン・オフします。オフにすると、その場所も透けます。 | **ゲーム内で最初から大事な部分の透け防止をONにする**の値（新規インストールはオン） | 保存しない |
| <strong>透け防止の範囲（50%=標準）</strong> | 保護が防ぐ広さです。0%はほとんど防がず、50%はUnityで見える大きさのまま、100%は広く防ぎます。 | 50% | 保存する |
| <strong>透け防止の強さ（100%=完全に防ぐ）</strong> | 保護が防ぐ度合いです。100%は完全に防ぎ、50%は防がないときの透けの約3分の1、0%は防ぎません。 | 100% | 保存する |

詳しくは、[透け保護](./see-through-protection.mdx#dials)を確認してください。

## 全範囲濡れ {/* #whole-area */}

**濡れ > 全範囲濡れ**のトグルです。

| トグル | 結果 |
| --- | --- |
| オフ（初期値） | Unityで決めたとおりに濡れます。**汗をかく所から**、**体に触れる所から**、**両方**のうち、選んだ方式から始まって広がります。 |
| オン | 服全体が均一に濡れます。開始点と広がりは使わず、どれだけ濡れるかは、濡れ量（RealSweat連動なら汗の量）が決めます。 |

{/* SHOT R03: Whole Area OFF / ON */}

- オンにしても、保護範囲はそのまま保護されます。透け・光沢・濡れた色と、濡れる・乾く時間も同じです。
- オンの間は服全体が濡れるため、透ける服は、濡れ量が多いほど服全体が透けます。望まない場合は、**透けなし**モードか保護範囲を使ってください。
- オンの間は、<strong>最大の濡れ範囲 (%)</strong>、**濡れる範囲を広げる**、**衣装ごとの違いを減らす**、**濡れの境界**は効果がありません。どれも濡れる位置を決める調整だからです。ただし、最大の濡れ範囲が0%なら、オンの間も濡れません。
- RealRainの雨粒・水の筋・雨の広がりは、このトグルに関係なくそのままです。
- Unityでは、プレビューの下の<strong>全範囲濡れ（ゲーム内メニュー）</strong>のチェックで、オンにしたときの見た目を事前に確認できます。プレビューにだけ使われ、保存された設定は変わりません。

## メニューに機能を入れる・外す {/* #edit-menu */}

1. Hierarchyで`RealWet`オブジェクトを選択し、**ゲーム内メニュー**タブを開きます。
2. 入れる機能にチェックを入れ、外す機能のチェックを外します。
3. **ランタイムメニューを適用 / 更新**を押します。
4. ビルドし直したアバターで確認します。

{/* SHOT U17: RealWet inspector, In-Game Menu tab */}

- メニューのチェックは、**ボタンを入れるための設定**です。その機能を最初からオンにするかどうかとは別です。たとえば、**衣装ごとの違いを減らす**は、機能そのものはオンですが、ボタンはおすすめ構成に含まれていません。
- チェックを外すと、そのゲーム内の調整が外れるだけで、Unityで保存した見た目・保護の設定はそのままです。ボタンがない機能は、Unityで決めた値で動作します。
- チェックをすべておすすめ構成に戻すには、インストール画面の**推奨ゲーム内メニューを復元**を押します。

### メニューの場所と言語

- **場所:** `RealWet`オブジェクトの**MA Menu Installer**で追加先のメニューを変えると、好きなサブメニューの中に**濡れ**メニューを入れられます。この場所は、メニューを更新しても保たれます。
- **言語:** ボタン名は、メニューを作ったときに選んでいた<ProductName />の言語（English / 한국어 / 日本語）に従います。VRChatの中で自動的に翻訳されることはないため、使いたい言語を選んでメニューを更新してから、ビルドし直してください。
- メニューファイルは、アバターごとに`Assets/CookiTools/Generated/RealWet/RuntimeMenus`に作ります。パッケージのフォルダーを上書きしても消えません。
- メニューを手動で移動したり、別のメニューに置き換えたりした場合、<ProductName />はそのメニューをそのままにします。作り直すには、[メニューが見当たらない](../troubleshooting.mdx#menu-missing)を確認してください。

## 同期容量 {/* #sync-cost */}

**RealWet > ゲーム内メニュー**か、インストール画面の**最終同期コスト**の概要で、現在の選択の合計を確認してください。下の表は<ProductName />が加える容量で、RealSweatSystemや他のツールが使う容量は別です。

| 構成 | 追加の同期容量 |
| --- | --- |
| 単独の基本操作（濡れ量 + 衣装の濡れを表示） | 9ビット |
| RSS連動の基本操作（RealSweat連動 + 連動OFF時の濡れ量） | 9ビット |
| 最大の濡れ範囲、範囲の拡張、濡れ表現、濡れ光沢、境界、透け強度、透け防止の範囲、透け防止の強さ | ダイヤルごとに8ビット |
| 濡れ透けモード | 8ビット |
| 全範囲濡れ、状態の固定、高速乾燥、SSAO・影の軽減、衣装ごとの違いを減らす | 項目ごとに1ビット |
| 衣装の濡れを表示 | RSS連動で入れると1ビット（単独モードでは基本操作に含まれます） |
| 衣装別表示のグループ | グループごとに1ビット |
| 大事な部分の透け防止 | 1ビット（保護範囲が複数あっても、トグルは1つ） |
| 自分にのみ表示 | 単独モードで入れると1ビット |

新規インストールのおすすめメニューは、RSS連動でも単独でも**87ビット**です。衣装別表示のグループ6個まで、すべての項目を入れると94ビットです。VRChatの上限は、アバター全体で256ビットです。他のツールと合わせて上限を超える場合は、[メニュー・パラメーターが上限を超える](../troubleshooting.mdx#over-limit)を確認してください。

## Unityとゲーム内で違うとき

- Unityのプレビューは、濡れ設定の初期値を使います。VRChatは、以前に保存されたメニューの値をまた使うことがあります。
- 比べるときは、濡れ量だけでなく、連動、全範囲濡れ、最大の濡れ範囲、衣装ごとの違いを減らす、範囲の拡張、境界、透けモード・強度、透け防止の範囲・強さ、表現、光沢、高速乾燥と状態の固定もそろえてください。
- 範囲の拡張の初期値は0%、境界・濡れ表現・濡れ光沢・透け強度・透け防止の範囲は50%、透け防止の強さは100%、透けモードは**設定どおり**です。
- メニューの構成や言語を変えた場合は、**ランタイムメニューを適用 / 更新**の後で、ビルドし直してください。すでに入っているダイヤルをゲーム内で動かすのに、ビルドし直す必要はありません。
- 開始点の球を1つずつゲーム内でオン・オフするメニューはありません。開始点の編集はUnityで行います。
