# 透け保護

薄い服は、濡れると透けます。**透け保護**は、胸や股のように透けてはいけない所で、その透けだけを防ぐ機能です。このページでは、保護範囲とは何か、どのように置かれるか、どのように整えるか、ゲームの中でどのように調整するかを説明します。

{/* SHOT S03: Scene, the four recommended protection capsules, front */}

## 保護範囲の働き {/* #what-it-does */}

- 保護範囲は、球・カプセル・箱の形をした場所です。Unityでだけ使う表示で、ゲームにオブジェクト・Collider・PhysBoneを加えません。
- <strong>保護範囲も、ほかの所と同じように濡れます。</strong>濡れた色・光沢・広がり・濡れるまでの時間はそのままです。<ProductName />が濡れによって**加える透けだけ**を防ぎます。
- 元のマテリアルの時点で透明な部分（レース、穴、ディゾルブ）は埋めません。元の透明度はそのままです。
- 透けない服（<strong>透けなし（厚手の生地）</strong>）や、透けをオフにした状態では、防ぐ透けがないため、保護があってもほかの所と同じに見えます。
- ゲーム内の**濡れた部分を強制的に透過**と**全範囲濡れ**をオンにしても、保護範囲はそのまま保護されます。

## グローバル保護範囲と衣装ごとの保護範囲 {/* #global-and-per-outfit */}

| 種類 | ある場所 | 適用される範囲 |
| --- | --- | --- |
| **グローバル保護範囲**（アバター共通） | **RealWet > 濡れ設定 > 重要部位の透け保護**と、**濡れ・保護範囲エディター**の**透け保護**タブ | このアバターのすべての衣装に適用されます。ゲーム内の**大事な部分の透け防止**スイッチとダイヤルに従います。新規インストールの推奨範囲4つが、ここに入ります。 |
| **衣装ごとの保護範囲**（旧方式） | **RealWet > 濡れ設定 > 追加設定 > 旧方式の衣装の互換性** | その衣装にだけ適用されます。以前に衣装ごとに別に作った範囲です。ゲーム内のスイッチに関係なく、常に適用されます。 |

- 新しく作る保護範囲は、すべてグローバル保護範囲です。普段は、グローバル保護範囲だけを使えば十分です。
- 衣装ごとの保護範囲は、旧方式のエディターで<strong>アバター共通の保護範囲へ移動…</strong>を押すと、グローバルに移せます。確認ウィンドウを読んでから実行してください。Ctrl+Zで元に戻せます。

## 推奨の保護範囲4つ {/* #recommended */}

新しくインストールするときに、インストール画面の**胸・股の透け保護領域を入れる**にチェックが入っていると（初期設定）、<ProductName />がこのアバターの体に合わせて、次の4つを作ります。

| 名前 | 覆う所 |
| --- | --- |
| <strong>胸の透け保護（左）</strong> / <strong>胸の透け保護（右）</strong> | 乳輪とその周り |
| <strong>股の透け保護（前）</strong> / <strong>股の透け保護（後ろ）</strong> | 股の中央 |

{/* SHOT S04: Scene, recommended capsules, side view */}

- どれも、アバターの前を向いた**小さなカプセル**です。正面から見ると丸い場所です。内側はすべて防ぎ、縁は服のしわに関係なく、濡れた境界のようにやわらかく自然なまだらになってほどけます。胸は広く、股は少し狭くほどけます。
- 胸のカプセルは前後に深く届くので、ゆったりしたトップスも覆います。股の前のカプセルは、股の前に着ているいちばん外側の服（スカートなど）まで届きます。
- サイズは、わざと小さくしています。透けが多い服でもっと広く防ぎたい場合は、ゲーム内の**透け防止の範囲**を上げるか、エディターでサイズを大きくしてください。

### 自動で置く方法 {/* #placement */}

胸の保護範囲は、次の順番で場所を探します。前の方法を使えないときだけ、次の方法を使います。

1. **乳首のシェイプキー:** 身体メッシュに乳首のシェイプキーがあれば、そのキーが動かす2か所を使います。2か所が小さく、左右対称で、胸の前側にあるときだけ使います。衣装用の縮小・非表示のキーは使いません。
2. **胸のボーン:** キーがなければ、胸のボーンが動かす肌のうち、いちばん前の部分を使います。胸のボーンがあれば、保護範囲はそのボーンに合わせて動きます。
3. **胴体:** 胸のボーンもなければ、胴体から場所を探します。
   - 胸が前に出ている場合（お腹の前より胴体の高さの10%以上前）は、左右それぞれ、いちばん前に出ている胸の肌に置きます。胸のボーンも乳首のシェイプキーもないアバターは、このように置かれます。
   - 本当に平らな胸（男性型など）は、腰から肩までの高さの70%の位置で、腕を除いた胴体の幅と前側の肌から場所を決めます。

{/* SHOT S05: flat-chest avatar, torso fallback placement */}

- 服の下の体を削除して胸の肌がない身体メッシュでは、着ている衣装の胴体の層（いちばん内側といちばん外側）の間の中央に置きます。
- 確かさが低い方法ほど、保護範囲を少し大きくします。
- 股の保護範囲は、身体メッシュのボーンウェイトで見つけた脚の付け根のしわと、股の肌に合わせます。見つからない場合は、Hipsボーンを基準に置きます。
- 身体メッシュを読み取れない場合は、ボーンを基準に置きます。

:::tip[自動配置は出発点です]
自動配置はほとんどのアバターで合いますが、体の形によっては少しずれることがあります。インストールした後に一度は、透ける服を100%でプレビューして、前・横・後ろから確認してください。
:::

## 保護範囲を編集する {/* #editing */}

1. **RealWet > 濡れ設定 > 重要部位の透け保護**を開きます。
2. <strong>保護範囲を編集…</strong>を押します。**濡れ・保護範囲エディター**が**透け保護**タブで開きます。衣装の画面の<strong>保護範囲を編集…</strong>も、同じエディターを開きます。
3. 上の**選択範囲**で範囲を選ぶか、**一覧・検索**を開いて探します。Sceneの名前ラベルを押してもかまいません。
4. SceneでWを押して移動し、Eで回転し、Rでサイズを変えます。

### プロパティ

| 項目 | 意味 |
| --- | --- |
| **名前** | 一覧・Scene・Hierarchyに表示される名前です。空にすると、自動の名前に戻ります。 |
| **この保護範囲を使う** | オフにすると、この範囲は服を保護しません。範囲は残ります。 |
| **形** | **球**、**カプセル**、**箱**から選びます。球には回転がなく、カプセルはローカルY軸の方向に伸びます。 |
| <strong>半径 (cm)</strong> | 球とカプセルの半径です。その内側を防ぎ、表面の近くから縁がやわらかくほどけます。 |
| <strong>全高 (cm)</strong> | カプセルの両端の丸い部分まで含めた長さです。 |
| <strong>箱のサイズ (cm)</strong> | 箱の幅・高さ・奥行きです。 |
| <strong>縁をやわらかく (cm)</strong> | 保護が少しずつ消えていく幅です。0〜5 cmです。広いほど、保護した所が目立ちにくくなります。 |
| <strong>縁のまだら (%)</strong> | 上げると、保護の中心はそのままで、縁が自然なまだらのようにほどけます。推奨範囲は0%です。 |
| <strong>詳細設定（座標・接続）</strong> | **基準Transform**（範囲が追従するボーン）、<strong>ローカル位置 (m)</strong>、**ローカル回転**、**対称の相手**を直接変更します。 |

- サイズはどの画面でもcm、割合は%で表示されます。
- **縁のまだら**が0%でも、縁には濡れ開始点の不規則な模様と同じまだらが少し入ります。そのため、保護した所は丸い縁取りではなく、濡れた境界のようにほどけます。このまだらは範囲ごとに決まっているので、動いても揺れず、服のしわを横切る縞模様もできません。
- 新しく追加した範囲は、**球**、半径4 cm、**縁をやわらかく**1.2 cm、**縁のまだら**65%で始まります。
- 球、カプセル、箱のどれも、同じ方法で透けを防ぎます。別に選ぶ保護方式はありません。

### 作成・複製・削除

| ボタン | すること |
| --- | --- |
| **+ 保護範囲を追加** | 選んだ範囲の隣に、新しい範囲を作ります。 |
| **+ 左右ペアを追加** | 左右の鏡像の位置に、互いにつながった範囲を2つ作ります。 |
| **反対側を作成** | ペアのない片側の範囲の反対側を、同じ設定で作ってつなげます。 |
| **左右対称** | オンにすると、片側を動かしたり変えたりしたときに、反対側も一緒に変わります。エディターとSceneパネルのスイッチは、同じものです。 |
| **複製・削除・初期化 > この範囲を複製** / **左右ペアを複製** | 選んだ範囲（またはペア）を複製します。 |
| <strong>削除…</strong>またはDeleteキー | 確認ウィンドウを経て削除します。ペアの場合は、**この範囲のみ**か**左右2個を削除**を選びます。Ctrl+Zで元に戻せます。 |

### 初期化ボタン {/* #reset */}

**複製・削除・初期化**を開くと、初期化ボタンがあります。

| ボタン | 元に戻すもの |
| --- | --- |
| **位置を初期化** | 位置と回転だけを戻します。 |
| **サイズを初期化** | 半径・高さ・箱のサイズと、**縁をやわらかく**を戻します。ぼかしの幅はサイズに含まれるため、位置の初期化だけでは変わりません。 |
| **位置＋サイズ** | 両方を戻します。 |
| **今の位置を既定値として保存…** | 今の位置とサイズを、この範囲の既定値にします。後で初期化すると、この位置とサイズに戻ります。 |

- 推奨範囲は、今の体からもう一度探した推奨配置に戻ります。自分で作った範囲は、作ったときに保存された位置とサイズに戻ります。
- **左右対称**がオンなら、つながった両側が、それぞれの既定値に戻ります。
- どの初期化も、Ctrl+Zで元に戻せます。

### 足りない推奨範囲を作り直す {/* #add-missing */}

{/* SHOT U26: create regions hint and add-missing button */}
[![胸・股の透け保護領域を作る と 不足している推奨領域を追加](/img/guide/U26-ja.png)](/img/guide/U26-ja.png)

- 推奨範囲の一部を削除した場合は、**RealWet > 濡れ設定 > 重要部位の透け保護**の**不足している推奨グローバル領域を追加**を押します。足りないものだけを作り直し、残っている範囲はそのままにします。4つすべてある場合、ボタンはグレーになります。
- ゲーム内のスイッチはあるのに保護範囲が1つもない場合は、同じ場所に<strong>胸・股の透け保護領域がありません。</strong>と、**胸・股の透け保護領域を作る**ボタンが表示されます。押すと、推奨範囲を4つ作ります。Ctrl+Zで元に戻せます。

## ゲーム内で最初からオンにする {/* #start-value */}

**RealWet > 濡れ設定 > 重要部位の透け保護**の**ゲーム内で最初から大事な部分の透け防止をONにする**は、アバターを読み込んだときに保護がオンになっているかを決めます。

- 新規インストールではオンです。
- ゲーム内の**大事な部分の透け防止**スイッチは、選択を保存しません。アバターを読み込むたびに、この値で始まります。
- ゲーム内メニューにスイッチがない場合、保護はこの値のままです。
- この設定は、保護範囲を作ったり消したりしません。Unityのプレビューも、同じ値に従います。
- 値を変えると、<ProductName />が自分のゲーム内メニューの初期値をすぐに直します。アップロードに反映するには、ビルドし直してください。

## ゲーム内のダイヤル：範囲と強さ {/* #dials */}

新規インストールとおすすめ構成には、**濡れ > 透け防止**ページが入っています。ページの中に、**大事な部分の透け防止**スイッチと、ダイヤルが2つあります。

{/* SHOT M03: See-Through Protection page */}
[![透け防止ページ](/img/guide/M03-ja.png)](/img/guide/M03-ja.png)

### 透け防止の範囲（50%=標準） {/* #range-dial */}

保護が防ぐ**広さ**を変えます。

| 値 | 結果 |
| --- | --- |
| **0%** | ほとんど防ぎません。完全に防ぐ所がなく、範囲の中央にだけかすかに残ります。 |
| <strong>50%</strong>（初期値） | Unityで表示される保護範囲のとおりに防ぎます。 |
| **100%** | 範囲の外側まで広く防ぎます。**縁をやわらかく**の幅の0.8倍（推奨の胸の範囲は約1.4倍）外側まで完全に防ぎ、2.9倍で消えます。透けが多い服に使います。 |

{/* SHOT R06: protection range 0 / 100 %, chest close-up */}
[![透け防止の範囲0%と100%の比較。100%では胸のまわりが透けないように守られます。](/img/compare/R06-ja.webp)](/img/compare/R06-ja.webp)

- その間の値は、なめらかにつながります。
- **縁をやわらかく**が0の範囲は、100%でも広くなりません。

### 透け防止の強さ（100%=完全に防ぐ） {/* #strength-dial */}

保護が防ぐ**度合い**を変えます。

| 値 | 結果 |
| --- | --- |
| <strong>100%</strong>（初期値） | 完全に防ぎます。 |
| **50%** | 防がないときの透けの、約3分の1だけが見えます。 |
| **0%** | 防ぎません。スイッチをオフにしたのと同じです。 |

{/* SHOT R07: protection strength 0 / 100 %, chest close-up */}
[![透け防止の強さ0%と100%の比較。100%では胸が透けません。](/img/compare/R07-ja.webp)](/img/compare/R07-ja.webp)

- 強さは、直線ではなく曲線で変わります。防ぐ量を半分に減らすと、透けは半分よりずっと多く戻るため、50%で約3分の1になるように合わせました。

### 2つのダイヤルに共通すること

- 2つのダイヤルは、保護範囲が防ぐ透けだけを変えます。濡れた色・光沢・濡れ方は変えません。
- **大事な部分の透け防止**スイッチをオフにすると、ダイヤルの値に関係なく保護しません。
- 2つのダイヤルは保存・同期され、それぞれ8ビットです。
- ダイヤルを入れていないアバターと、初期値（範囲50%、強さ100%）では、配置した保護範囲のとおりに防ぎます。範囲の内側はすべて防ぎ、縁はやわらかくほどけます。Unityのプレビューも、この初期値を使います。
- 保護範囲もスイッチもないアバター（インストール画面で**胸・股の透け保護領域を入れる**をオフにしてインストールした場合）には、ダイヤルを作りません。
- インストール済みのアバターにダイヤルがない場合は、**RealWet > ゲーム内メニュー**で2つの項目をオンにし、**ゲーム内メニューを適用 / 更新**を押してから、ビルドし直してください。

## 更新した後の保護範囲 {/* #after-update */}

- 更新しても、**保存された保護範囲は、位置・サイズ・形がそのまま**です。自分で変えた値もそのままです。
- 新しいバージョンの推奨の形（前を向いた小さなカプセル）を使うには、推奨範囲を1つずつ選んで、**サイズを初期化**を押してください。位置も新しい推奨の場所に移すには、**位置＋サイズ**を押します。左右対称がオンなら、ペアが一緒に変わります。
- 更新では、保護範囲を新しく作りません。ゲーム内のスイッチはあるのに範囲がない場合は、上の[足りない推奨範囲を作り直す](#add-missing)を確認してください。

## 確認する方法 {/* #checking */}

1. 透ける衣装を選び、**衣装全体の濡れプレビューを開始**を押します。
2. プレビューの濡れを<strong>100%</strong>に上げます。
3. <strong>全範囲濡れ（ゲーム内メニュー）</strong>にチェックを入れると、服全体が濡れた、いちばん透ける状態を見られます。
4. 前・横・後ろから、胸と股を確認します。
5. 保護が足りなければ、範囲を動かすか大きくして、もう一度確認します。

- 保護範囲があるアバターでは、**RealWet > 濡れ設定 > 重要部位の透け保護**に灰色の案内が1行表示されます（例：<strong>濡れると透ける可能性のある衣装が3着あります。保護範囲の中は透けません。衣装ごとの確認は任意です。</strong>）。衣装ごとの確認は任意です。
- オンの保護範囲が1つもない場合は、同じ場所に黄色の警告が表示されます。上の[足りない推奨範囲を作り直す](#add-missing)を確認してください。

:::note[ゲームの中では、もっと透けることがあります]
ゲーム内の**透け強度**を100%に上げるか、**濡れた部分を強制的に透過**を選ぶと、Unityのプレビューよりも透けます。そのときも保護範囲は防ぎますが、範囲の外側はより透けて見えます。アップロードした後、ゲームの中でも一度確認してください。
:::
