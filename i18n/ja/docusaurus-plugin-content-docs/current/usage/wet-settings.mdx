# 濡れ設定

アバター全体の基準は**RealWet > 濡れ設定**で決め、1着の濡れた見た目は**この衣装の設定 > 濡れ表現**で決めます。最初は衣装を1つプレビューで表示して、1回に1項目ずつ変えてください。

{/* SHOT U16: RealWet inspector, Wetness Settings tab */}
[![濡れ設定タブ](/img/guide/U16-ja.png)](/img/guide/U16-ja.png)

*<small>例の画像です。テスト用アバターのため、**濡れ具合を選択**が**カスタム**で、**衣装ごとの違いを減らす**がオフになっています。新規インストールでは**衣装ごとの違いを減らす**はオンです。</small>*

このページで扱わないもの:

- 汗が始まる球: [濡れの開始点](./wet-start-points.mdx)
- 胸・股の透けを防ぐ: [透け保護](./see-through-protection.mdx)
- 衣装の登録、パーツ、重ね着の順序: [衣装設定](./outfit-settings.mdx)

## 濡れ始める方式 {/* #start-mode */}

| 選択 | 見える結果 | こんなときに選びます |
| --- | --- | --- |
| <strong>汗をかく所から（おすすめ）</strong> | 脇・胸・背中などの[濡れの開始点](./wet-start-points.mdx)の周りから広がります。新規インストールの初期値です。 | 汗で濡れた見た目にしたいとき |
| **体に触れる所から** | 服が肌に密着している部分から濡れます。 | 体に張り付く服の密着感を出したいとき |
| **両方** | 汗のポイントから始まり、体に触れる所に沿って広がります。 | 2つの方式を併用したいとき |

{/* SHOT R12: Sweat spots / Body contact / Both */}

- 雨に当たったように服全体を均一に濡らすのは、この選択ではなく、ゲーム内の[全範囲濡れ](./in-game-menu.mdx#whole-area)です。
- 衣装ごとに違う方式を使うには、衣装の画面で個別に選べます。インストール画面で方式を選ぶと、すべての衣装が同じ方式を使います。

## どこまで広く濡れるか {/* #range */}

### 最大の濡れ範囲と濡れ量

| 設定 | 決めるもの |
| --- | --- |
| <strong>最大の濡れ範囲 (%)</strong> | 汗（濡れ量）が100%のときに、濡れが**どこまで**広がれるかを決めます。新規インストールでは40%です。 |
| **濡れ量**（ゲーム内） | その範囲の中で、**どれだけしっかり**濡れるかを決めます。範囲が狭くても、量が100%なら範囲内は十分に濡れ、設定した透けまで進みます。 |

- **衣装ごとの違いを減らす**がオンなら、最大の濡れ範囲がM%のとき、濡れ量100%で、各衣装は水が届きうる部分のうち<strong>おおよそM%</strong>が濡れます。50%なら、届く部分のおよそ半分です。
- 汗から遠く、水が届かない部分は、100%に上げても濡れません。そのため、この値は服全体の面積の割合ではありません。
- 範囲を下げても、透けの最大の強さは下がりません。透けだけを弱めるには、ゲーム内の**透け強度**を使います。

{/* SHOT R02: Maximum Wet Range 20 / 40 / 70 / 100 % */}

### 濡れ具合を選択

**濡れ具合を選択**で、**狭い（少し濡れる）**、**標準（バランス）**、**広い（強め）**、<strong>最大（びしょ濡れ）</strong>から1つを選ぶこともできます。

- 段階を選ぶと、範囲と一緒に、濡れるまでの時間、広がる距離、届く距離、重ね着へ伝わる度合いも変わります。
- 範囲だけを変えるには、パーセントを直接入力してください。直接変えると、**カスタム**と表示されます。
- 新規インストールの40%は、段階ではなく、直接決めた値です。

### 衣装ごとの違いを減らす {/* #reduce-differences */}

**衣装ごとの違いを減らす**は、衣装ごとの濡れる広さの差を小さくします。新規インストールではオンになっています。

- 体に密着して早く濡れる衣装は遅らせ、ゆったりしていて遅く濡れる衣装は早めます。
- 衣装1着をまるごと合わせるため、同じ衣装の中のパーツの順序はそのままです。
- 肌から遠すぎて、もともと濡れない部分は広げません。範囲の中の濡れ具合や透けも変えません。
- プレビューで、同じ数値のままオンとオフを見比べてください。補正が必要ない衣装は、差が小さいか、ないこともあります。
- ゲーム内のボタンは、標準のメニューには入っていません。入れるには、**RealWet > ゲーム内メニュー**で選びます。

肌から大きく離れたアウターのように水が届かないパーツは、そのパーツの**フィットプリセット**を**密着**に変えると、水が届く距離が伸びます。初期値は**標準**です。

:::note[広く広げることと、境界をなめらかにすることは違います]
ゲーム内の<strong>濡れる範囲を広げる（上級者向け）</strong>は、同じ濡れ量で、薄い濡れをより遠くまで広げます。<strong>濡れの境界：くっきり ↔ なめらか</strong>は、乾いた所と濡れた所の間の移り変わりだけを変えます。どちらも、濡れが広がっている途中の状態で比べると、違いがわかりやすくなります。
:::

## 身体メッシュ {/* #body-meshes */}

**RealWet > 濡れ設定 > 身体メッシュ**には、濡れの計算に使う肌メッシュを登録します。インストール画面の**1. 身体の登録**と同じ一覧です。

- 基本の身体に胴体・手・足が含まれていない場合は、追加の肌メッシュに入れてください。**RealSweat候補を追加**で、RealSweatSystemに登録されている候補を取り込めます。
- 衣装や髪は入れないでください。
- 手動で登録したメッシュは、オフになっていても計算に含まれます。使わない差し替え用のボディは入れないでください。
- 追加した身体は、肌への近さによる濡れ、SSAOの軽減、重ね着の順序の計算にも使われます。元の身体メッシュを結合したり、変更したりはしません。

## 透け {/* #see-through */}

### 新しい衣装の初期の透け

**新しい衣装の濡れた見た目**の透けは、**すべて透けない**、**すべて透ける**、<strong>上着だけ透ける（下着は透けない）（推奨）</strong>から選びます。新規インストールは**上着だけ透ける**です。新しい衣装を登録するときに、その衣装の中の実際の内外関係を1回確認します。

- 一番内側のパーツ、単独のパーツ、オフのパーツ、判定があいまいなパーツは、**透けなし**で始まります。
- 他のパーツより外側にあることが確実なパーツは、**自然に透ける**で始まります。
- 髪と、帽子・メガネのように頭に着けるパーツは、どの初期値でも透けるようにしません。透けるようにするには、そのパーツの欄で自分で選んでください。
- 登録済みの衣装と元のマテリアルは変更しません。

### 衣装の透けの設定

**この衣装の設定 > 濡れ表現 > この衣装の濡れた見た目**の**濡れると透ける**で選びます。

| 設定 | 結果 |
| --- | --- |
| **透けなし（厚手の生地）** | 濡れた色と光沢だけを加えます。 |
| **自然に透ける** | 濡れが深くなるにつれて、少しずつ透けます。黒い生地は比較的透けにくくなります。 |
| **暗い色も透ける** | 暗い柄や黒い生地も、よく透けます。新しく選ぶと、**透け具合**は60%から始まります（他の方式は35%）。 |
| **パーツごとに個別** | パーツごとに保存した透け方と透け具合を、そのまま使います。 |
| <strong>透け具合 (%)</strong> | 十分に濡れたときに、どれだけ透けるかを決めます。 |
| <strong>暗い部分の透け (%)</strong> | **自然に透ける**で黒い部分が透けすぎるときに下げます。 |

[![Tシャツの背中を、透けなしと自然に透けるで比べた様子](/img/booth/booth-see-through.jpg)](/img/booth/booth-see-through.jpg)

*<small>濡れ100%のTシャツの背中を、<strong>透けなし（厚手の生地）</strong>と**自然に透ける**で比べました。</small>*

- **透けなし**は、<ProductName />が加える透けだけをオフにします。もともと透明なレースの穴を埋めることはありません。
- ゲームの中では、**透け強度**のダイヤルと**濡れ透けモード**で透けを変えられます。[ゲーム内メニュー](./in-game-menu.mdx#see-through)を確認してください。
- 胸・股の透けは、[透け保護](./see-through-protection.mdx)が防ぎます。

{/* SHOT R04: See-Through Strength 0 / 50 / 100 % */}

## 濡れた見た目 {/* #look */}

### 衣装ごとに均一に濡れて見えるようにする

**RealWet**の<strong>衣装ごとに均一に濡れて見えるようにする（新しい見た目）</strong>は、白い服、マットキャップが強い服、体に張り付く透ける服も、他の服と同じように濡れて見えるようにします。汗とRealRainの雨による濡れの両方に使われます。

- すべてのアバターで、初期設定でオンになっています。
- 以前の見た目がよければ、**RealWet > 濡れ設定 > 濡れ具合**でオフにしてください。一度オフにすると、その後もオフのまま残ります。
- オンにすると濡れシェーダーを新しく作るため、最初のプレビューやビルドで、1回だけ余分に時間がかかります。
- 色のある服と髪は、濡れて暗くなっても彩度を保ち、灰色にくすみません。

### 「この衣装の濡れた見た目」カード

衣装ルートの**この衣装の設定 > 濡れ表現**を開きます。**この衣装の濡れた見た目**カードには、上から**生地の種類** → **濡れた感じの強さ** → **濡れると透ける** → **重要部位の透け保護**が並んでいます。選んだ値はすぐに保存され、オンになっているパーツ全体に反映されます。Ctrl+Zで元に戻せます。

{/* SHOT U19: outfit inspector, wet look card */}
[![この衣装の設定](/img/guide/U19-ja.png)](/img/guide/U19-ja.png)

*<small>例の画像です。パーツごとに透け方を手で設定してあるため、**濡れると透ける**が**パーツごとに個別**になっています。</small>*

濡れた部分は、元の色がより深く濃くなり、メインライト側のしわに沿って、広くやわらかな水の光沢が出ます。光沢が、そのシーンの白より明るくなることはありません。lilToonの服とPoiyomiの服は、同じ見た目で濡れます。

### 生地の種類

服に近いものを選んでください。下の表の濃くなる順番は、暗い色の服を基準にしたものです。

| 生地の種類 | 濡れた見た目 |
| --- | --- |
| <strong>綿・ニット・デニム（おすすめ）</strong> | 水を含む布です。暗い服では色がいちばん濃くなり、光沢は控えめです。 |
| **ポリエステル・サテン・水着** | なめらかな布です。少し濃くなり、しわに沿って、広く明るい水の光沢がよく見えます。 |
| **ラテックス・ビニール・エナメル** | 水がしみ込まない素材です。色の変化はいちばん小さく、表面に薄い水の膜のような光沢が出ます。 |
| **中間** | 迷ったときに選びます。ポリエステル・サテンと同じくらい少し濃くなり、光沢は綿とポリエステルの中間です。 |

{/* SHOT R08: fabric types */}

明るい色の服では、この順番が変わることがあります。明るい服は名前だけで判断せず、プレビューで比べて選んでください。

### 濡れた感じの強さ

| 選択 | 濡れ色の濃さ | 色の鮮やかさ | 水の光沢 |
| --- | --- | --- | --- |
| **控えめ** | 63% | 50% | 40% |
| **標準**（新規インストール） | 100% | 100% | 100% |
| **強め** | 129% | 143% | 200% |

{/* SHOT R09: Subtle / Standard / Strong */}

**強め**は光沢が2倍になるため、なめらかな生地では、画面上でより暗くは見えないことがあります。

### 見た目の詳細設定

カードの下の**見た目の詳細設定**を開くと、すべての数値が表示されます。色・光沢の3つの値は、100%が**標準**の強さです。

| 設定 | 働き |
| --- | --- |
| <strong>濡れ色の濃さ (%)</strong> | 濡れた部分の色を濃くします。 |
| <strong>色の鮮やかさ (%)</strong> | 上げるほど、色味が鮮やかになります。白・グレーの服では差が小さくなります。 |
| <strong>水の光沢 (%)</strong> | 濡れた光沢の強さです。0%では光沢がなくなり、色の変化だけが残ります。 |
| <strong>遅れて濃くなる (%)</strong> | 上げるほど、薄い濡れが先に広がり、濃い濡れが内側から遅れてついてきます。 |
| <strong>薄い→濃いのつながり (%)</strong> | 濡れた所の中で、薄い部分と濃い部分をつなぐ幅です。帯のように分かれて見えるときは上げてください。 |
| <strong>まだら具合 (%)</strong> | 濡れた境界がどれだけまだらになるかを決めます。0%はなめらかです。 |
| **濡れ斑の密度** | 低いと大きなまだら、高いと小さく細かいまだらになります。 |
| <strong>濡れ境界のやわらかさ (%)</strong> | 乾いた所と、薄く濡れた所の間のやわらかさです。 |
| <strong>すべての素材の濡れ表現 (%)</strong> | オンになっているマテリアル全体の、濡れた色・光沢・透けをまとめて弱めます。0%は濡れた表現を隠します。 |

- 複数のパーツで値が違う場合は、数値欄に`—`が表示されます。値を変えると、その項目だけが、オンになっているパーツ全体に同じ値で入ります。
- 黒い服の光沢が広すぎたり明るすぎたりする場合は、<strong>水の光沢 (%)</strong>を下げてみてください。ビニールのようにギラついて見える場合は、**生地の種類**を<strong>綿・ニット・デニム（おすすめ）</strong>に変えてみてください。

### 初期値に戻す

| 対象 | ボタン |
| --- | --- |
| 衣装全体 | カードの一番下の**この衣装の見た目を初期値に…** |
| マテリアル1つ | パーツ画面のスロットカードの**詳細設定 > このスロットの見た目を初期値に…** |
| 1つのパーツのすべてのスロット | パーツ画面の**このパーツの見た目を初期値に…** |
| すべての衣装 | **RealWet > 衣装管理**の**全衣装の見た目を新しい標準に…** |

- 変わるのは、生地の種類、濡れた感じの強さ、まだら・境界の値です。
- 透け、保護、最大の濡れ範囲、重ね着の順序、元のマテリアルはそのままです。
- 間違えて押した場合は、Ctrl+Zを1回押すと元に戻せます。

## 変更した後にすること

- 色・光沢などの見た目の数値は、オンになっているプレビューにすぐ反映されます。
- 透け方のように準備が必要な設定は、準備が終わってから表示します。しばらくの間、前の見た目が表示されることがあります。
- Unityで変えた設定は、アップロード済みのアバターには自動で反映されません。確認してから、もう一度ビルド・アップロードしてください。
