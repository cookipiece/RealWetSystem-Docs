# 濡れ開始点

**濡れ開始点**は、汗が始まる場所を表す球です。以前の版では発汗位置と呼んでいました。脇・胸・背中のように汗をかきやすい所に置かれていて、服はこの球の周りから濡れ始め、外側へ広がります。

{/* SHOT S01: Scene, default start points, one selected with influence colours, front */}

## いつ使われますか？ {/* #when */}

| 濡れ始める方式 | 開始点 |
| --- | --- |
| <strong>汗をかく所から（おすすめ）</strong> | 使います。球の周りから濡れます。 |
| **両方** | 使います。球から始まり、体に触れる所に沿って広がります。 |
| **体に触れる所から** | 使いません。球を動かしても、濡れる場所は変わりません。 |

ゲーム内の**全範囲濡れ**をオンにしている間も、開始点は使いません。服全体が均一に濡れます。

## 濡れの広がり方 {/* #spread */}

1. 汗（濡れ量）が上がると、球の内側に触れる服が先に濡れます。この場所を**開始領域**と呼びます。
2. 汗がさらに上がると、濡れが開始領域の外へ、服に沿って広がります。
3. どこまで遠く広がるかは、球ごとの**開始領域の外側に濡れる距離**と、アバター全体の<strong>最大の濡れ範囲 (%)</strong>が一緒に決めます。

### 最大の濡れ範囲との関係 {/* #max-range */}

<strong>最大の濡れ範囲 (%)</strong>（新規インストールでは40%）は、汗が100%のときに、濡れが開始点からどこまで遠く進めるかを決めます。

- **衣装ごとの違いを減らす**がオンなら（新規インストールの初期設定）、最大の濡れ範囲がM%のとき、汗100%で、各衣装は<strong>開始点から水が届きうる部分のうち、おおよそM%</strong>が濡れて見えます。40%なら届く部分のおよそ40%、100%なら届く部分のすべてです。
- 開始点から遠すぎて水が届かない部分は、100%に上げても濡れません。そのため、この値は服全体の面積の割合ではありません。
- 違いを減らす機能をオフにすると、この値は面積の割合ではなく、広がれる限度になります。服と体の間の距離によって、見え方が変わります。
- 袖やスカートの裾が濡れない場合は、範囲を上げるか、その近くに開始点を足すか、ゲーム内の**全範囲濡れ**を使います。

## 自動配置 {/* #auto-layout */}

新しくインストールすると、<ProductName />がこのアバターの体に合わせて開始点を置きます。

- 首の後ろ、背中（上・中央・下）、胸と胸の谷間・胸の下、脇、二の腕の内側、ひじの内側、お腹、股、お尻、太もも（内側）、ひざの裏・ふくらはぎ、足などに置かれます。
- ボーンで部位と向きを決め、登録した身体メッシュの肌の表面を探して球を置きます。肌のすぐ内側に少し入るのは正常です。球の範囲が肌に触れるようにするためです。
- 胸・脇・二の腕の内側・ひじの内側・太ももの内側・股・ひざの裏は、身体メッシュの**ボーンウェイト**で場所を探します。たとえば、胸のボーンのウェイトの下の境界を胸の下のしわとし、二の腕と胴体のウェイトが混ざるいちばん低い所を脇とします。
- 胸のボーンがない**平らな胸**（男性型など）では、胸筋の下のラインに球を置きます。このラインは乳首の高さ（胴体の70%）より胴体の高さの10%下にあり、乳首の高さを越えません。
- 腕のボーンが胴体の内側にあるちびキャラ体型や、メッシュが粗い体でも、脇と体の横のラインを探して球を肌の上に置きます。
- この規則を使うのは、新規インストール、**標準の発汗分布に配置…**、初期化のときだけです。保存済みの開始点は変わりません。
- ウェイトで確認できなかった部位、左右の片方だけ見つかった部位、服の下で体を削除した境界にかかった部位は、その部位だけをボーン基準の以前の配置で置きます。確認が必要な開始点は、インストール結果に名前が表示されます。
- MA Merge Armatureで結合したキメラのボディは、ボーン名でつないで判断します。
- 隠すためにサイズを0にした指・あごなどのボーンは、配置の妨げになりません。球を付けるボーンやその親が0スケールの場合は、そのボーンを知らせて、その球は作りません。

## エディターを開く {/* #editor */}

1. Hierarchyで`RealWet`オブジェクトを選択します。
2. **濡れ設定**タブで<strong>濡れ・保護範囲を編集…</strong>を押します。衣装の画面にある同じボタンからも開けます。
3. **濡れ・保護範囲エディター**が開いたら、**濡れ開始点**タブを選びます。

{/* SHOT U22: region editor, start point tab, armpit selected */}
[![濡れ開始点の編集](/img/guide/U22-ja.png)](/img/guide/U22-ja.png)

- 上の**選択範囲**で球を選ぶか、**一覧・検索**を開いて探します。Sceneの名前ラベルや点を押してもかまいません。
- 選んだ球の影響が、体と服に色で表示されます。青は弱い影響で、シアン・黄色を経て、赤は強い影響です。球をドラッグしている間も、すぐに変わります。
- **表示設定**で、**ボディの影響度・標準**、**衣装の影響度**、**ボディ＋衣装**を選び、**全ポイントの名前**と**色の不透明度**を変えます。
- 色は、**球1つが届きうる、いちばん広い範囲**です。現在の汗の量での最終的な濡れではありません。実際の濡れた見た目は、エディターの下にある<strong>実際の濡れを確認…</strong>で**衣装プレビューを開始**を押して確認します。戻るには、<strong>← 範囲編集に戻る</strong>を押します。
- Sceneでは、Wを押して移動し、Rでサイズを変えます。Sceneの中の小さなパネルは、タイトルバーをドラッグして動かします。

## 球のプロパティ {/* #properties */}

右側のプロパティは、**範囲・強さ**、**広がり・模様**、**詳細**に分かれています。

### 範囲・強さ

| 項目 | 意味 | 範囲 |
| --- | --- | --- |
| **この発汗ポイントを使う** | オフにすると、この球は服を濡らしません。球は残ります。 | — |
| <strong>ポイントの半径 (cm)</strong> | 開始領域の大きさです。球の中に触れる服が、先に濡れます。 | 0.5〜15 cm |
| <strong>開始領域の外側に濡れる距離 (cm)</strong> | 開始領域の外側へ、濡れが広がれる距離です。広げると、より遠くまで濡れます。 | 0.5 cm〜2 m |
| <strong>中心への集中度 (%)</strong> | 上げると、球の近くがより濃く濡れ、外側は薄くなります。影響が届く端はそのままです。 | 0〜100% |
| <strong>濡れの強さ (%)</strong> | この球から出る濡れの強さです。100%が標準です。 | 0〜200% |
| <strong>濡れ始める汗 (%)</strong> | 汗がこの値を超えると、この球が濡れ始めます。0%なら最初から濡れます。 | 0〜90% |

### 広がり・模様

| 項目 | 意味 | 範囲 |
| --- | --- | --- |
| **横の広がり** / **縦の広がり** | アバターを基準にした、横・縦方向に広がる距離の倍率です。球のサイズは変えません。例: 脇からわき腹へ長く広げるには、縦を上げます。 | 0.25〜2倍 |
| <strong>広がりの回転 (度)</strong> | 横・縦の広がりの向きを、アバターの前方向の軸を中心に回します。斜めに広げたいときに使います。 | -180〜180度 |
| <strong>広がりの進行（遅い / 速い）</strong> | 同じ汗の量で、この球の濡れがどれだけ速く広がるかです。 | 0.25〜2倍 |
| <strong>外側の広がりの不規則度 (%)</strong> | 広がる縁をまだらにします。0%はなめらかです。 | 0〜100% |
| <strong>不規則模様のサイズ (cm)</strong> | まだら1つの大きさです。 | 2〜30 cm |

**濡れの強さ**と、広がり・模様の値は、**このポイントの濡れをカスタム**がオンのときに、その球に使われます。オフなら、標準の値（強さ100%、広がり1倍、不規則度0%、回転0度）で濡れます。横・縦の広がりや回転を直接変えると、カスタムが自動でオンになります。推奨配置の一部の球（脇など）には、最初からカスタムの値が入っています。

<strong>項目を選択 ▾</strong>で、項目を1つずつ標準の値（強さ100%、広がりの進行1倍、不規則度0%、模様8 cm、中心50%、濡れ始める汗0%、横・縦1倍、回転0度）に戻せます。

### 形: 球・直線・曲線 {/* #shape */}

**形・模様の調整**の**形**で選びます。

{/* SHOT U23: Shape = Curve, Advanced coordinates with Start / End / Middle */}
[![曲線の開始点](/img/guide/U23-ja.png)](/img/guide/U23-ja.png)
{/* SHOT S06: curve start point handles */}

| 形 | 意味 |
| --- | --- |
| **球** | 1つの点を中心にした球です。標準の形です。 |
| **直線** | **始点**と**終点**の2点を結ぶ太い棒（カプセル）です。半径は球のサイズと同じです。わき腹のように、長く濡れる場所に使います。 |
| **曲線** | 直線に**中点**を足して曲げた棒です。胸の下のように、丸く濡れる場所に使います。 |

- 直線や曲線を選ぶと、球が長さ約10 cmの線になります。Sceneで始点・終点（曲線は中点も）を動かして、形を作ります。
- 始点と終点には、それぞれ追従する関節（ボーン）があります。<strong>詳細設定（座標・接続）</strong>で、**基準Transform**と、**始点** / **終点** / **中点**の位置を数値で変更できます。
- もう一度**球**を選ぶと、その形の中央にある球1つに戻ります。

### 詳細

| 項目 | 意味 |
| --- | --- |
| **名前** | 一覧・Scene・Hierarchyに表示される名前です。空にすると、自動の名前に戻ります。自動で作った開始点の名前は、エディターの一覧、名前の欄、Sceneの名札で、選んだ言語で表示されます（例：**M1 · 首の後ろ**）。保存された名前とHierarchyのマーカー名はそのままで、手動で変えた名前は入力したとおりに表示されます。 |
| **対称の相手** | 左右のペアになる球です。**左右対称**がオンなら、片側を変えると相手も変わります。 |
| **発汗ポイントの方式** | **発汗の集中**は、球の近くに濡れを集めます。<strong>中心への集中度 (%)</strong>は、この方式でだけ使われます。**従来の範囲拡散**は以前の方式です。以前の方式の球は、<strong>既存ポイントを発汗集中に変換…</strong>で変えられます。 |

## 球の作成・複製・削除 {/* #create */}

| ボタン | すること |
| --- | --- |
| **+ ポイント追加** | 選んだ球の隣に、新しい球を作ります。狭いウィンドウでは、<strong>+ 範囲追加</strong>と表示されます。 |
| **+ 左右ペアを追加** | 左右の鏡像の位置に、互いにつながった球を2つ作ります。 |
| **反対側を作成** | ペアのない片側の球の反対側を、同じ設定で作ってつなげます。中央にある球は、ペアがなくてもかまいません。 |
| <strong>体の部位から ▼</strong> | ひじ・ひざ・胸などの部位を選ぶと、その骨に開始点を作ります。すでにある部位は、<strong>（追加済み）</strong>と表示されます。Humanoidアバターでだけ表示されます。 |
| **複製・削除・初期化 > このポイントを複製** / **左右ペアを複製** | 選んだ球（またはペア）を複製します。 |
| <strong>削除…</strong>またはDeleteキー | 確認ウィンドウを経て削除します。ペアの場合は、**このポイントのみ**か**左右2個を削除**を選びます。 |

追加・複製・削除は、どれもCtrl+Zで元に戻せます。

| ボタン | すること |
| --- | --- |
| **位置** / **サイズ** / **位置＋サイズ** | 選んだ球（左右対称ならペア）の位置やサイズを、既定値に戻します。サイズには、広がりの距離も含まれます。 |
| **今の位置を既定値として保存…** | 今の位置とサイズを、この球の既定値にします。後で初期化すると、ここに戻ります。 |
| **濡れの項目を初期化** | 強さ・広がり・まだらなどの、濡れの項目を戻します。 |
| **全ポイントの初期化** | すべての球の位置・サイズ・項目を、まとめて戻すメニューです（<strong>すべての位置…</strong>、<strong>すべてのサイズ…</strong>、<strong>すべての位置＋サイズ…</strong>、<strong>全ポイントの濡れの項目を初期化…</strong>）。 |
| **標準の発汗分布に配置…** | 今の球をすべて、今のバージョンの推奨配置に置き換えます。手動で直した球も変わるため、確認ウィンドウを読んでから実行してください。 |

- どれもCtrl+Zで元に戻せます。
- 保存した球や手動で動かした球は、更新しただけでは動きません。更新するときに、保存された配置が新しい推奨配置と違う場合は、インストール画面が**濡れ開始点をリセット** / **既存の設定を維持**のどちらにするかを尋ねます。

## よく使う調整 {/* #tips */}

| やりたいこと | 方法 |
| --- | --- |
| 脇の汗を、わき腹まで長く | 脇の球の**縦の広がり**を上げるか、形を**直線**に変えて、終点をわき腹まで下ろします。 |
| 背中の中央を、もっと早く濡らす | 背中の中央の球の**濡れの強さ**か**広がりの進行**を上げます。 |
| ある所は、汗を多くかいたときだけ濡らす | その球の<strong>濡れ始める汗 (%)</strong>を上げます（例: 50%）。 |
| 胸の下の濡れを丸く | 胸の下の球を**曲線**に変え、中点で曲げます。 |
| 1か所だけ濡らさない | その球の**この発汗ポイントを使う**をオフにします。削除しないので、後でまたオンにできます。 |
| ゆったりした服が濡れにくい | 球を大きくするより、そのパーツの**フィットプリセット**を**密着**に変えてみてください。体から遠く離れた布まで、水が届きます。 |
| 左右を一緒に直す | **左右対称**をオンにして、片側だけを直します。 |
| 球を動かしたのに違いがない | 濡れ始める方式が**体に触れる所から**になっていないか、ゲーム内の**全範囲濡れ**がオンになっていないかを確認します。 |

{/* SHOT R11: armpit point default vs enlarged / moved */}

:::tip[1回に1つずつ変えてください]
球を1つ直したら、プレビューを50%と100%で確認してから、次の球に進んでください。複数を一度に変えると、どの変更が効いたのかがわかりにくくなります。
:::

- 開始点の球を1つずつゲーム内でオン・オフするメニューはありません。開始点の編集は、Unityで行います。
- 開始点は、Unityで編集するためのものです。ゲームにCollider・PhysBone・Contactを加えず、ゲーム内の計算も増えません。
- 球を変えると、その衣装の濡れの計算を準備し直します。プレビューに、しばらく前の見た目が表示されることがあります。
